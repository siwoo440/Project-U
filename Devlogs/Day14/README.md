# 프로젝트 U 14일차 개발 일지

## 개발 주제

아이템 ID 규칙과 공통 데이터 구조 확장

## 개발 목표

- 제작 재료, 도구, 음식, 장비를 구분하는 공통 아이템 분류 체계 구성
- 저장 데이터와 다른 시스템에서 안전하게 사용할 수 있는 아이템 ID 규칙 확립
- 아이템 설명과 아이콘을 보관할 공통 표시 데이터 추가
- 잘못된 아이템 설정과 중복 ID를 편집기에서 검사하는 검증 기능 구현
- 기존 채집, 도구, 인벤토리 기능과의 호환성 유지

## 구현 내용

### 1. 아이템 분류 확장

`ItemCategory`를 다음 네 종류로 구성했다.

| 분류 | 용도 |
|---|---|
| `CraftingMaterial` | 제작과 건축에 사용하는 재료 |
| `Tool` | 나무와 돌 등의 자원 채집 도구 |
| `Food` | 이후 섭취 기능에서 사용할 음식 |
| `Equipment` | 이후 장착 기능에서 사용할 장비 |

기존 에셋에 저장된 열거형 값이 변경되지 않도록 `CraftingMaterial`과 `Tool`의 숫자값을 유지했다.

### 2. 아이템 공통 표시 데이터 추가

`ItemData`에 다음 정보를 추가했다.

| 필드 | 역할 |
|---|---|
| `Description` | 아이템 설명 |
| `Icon` | 인벤토리와 핫바에 표시할 이미지 |

각 분류를 외부 시스템에서 확인할 수 있도록 제작 재료, 도구, 음식, 장비 판별 속성도 추가했다.

### 3. 분류별 데이터 자동 보정

Inspector에서 데이터가 잘못 설정되는 상황을 줄이기 위해 다음 규칙을 적용했다.

- 도구와 장비의 최대 중첩 수량을 `1`로 고정
- 도구가 아닌 아이템의 `Tool Type`을 `None`으로 초기화
- 아이템 ID, 이름, 설명의 불필요한 앞뒤 공백 제거
- 최대 중첩 수량이 `1`보다 작아지지 않도록 제한

### 4. 아이템 ID 규칙 확립

아이템 ID를 영문 소문자, 숫자, 밑줄만 사용하는 고유 문자열로 통일했다.

| 분류 | 접두사 | 예시 |
|---|---|---|
| 제작 재료 | `resource_` | `resource_wood` |
| 도구 | `tool_` | `tool_axe` |
| 음식 | `food_` | `food_berry` |
| 장비 | `equipment_` | `equipment_cloth_shirt` |

기존 나무, 돌, 도끼, 곡괭이의 ID는 저장 데이터 호환성을 위해 유지했다.

### 5. 아이템 데이터 검증 도구 구현

Unity 상단 메뉴의 `Project U > Data > Validate Item Data`에서 전체 `ItemData`를 검사할 수 있도록 `ItemDataValidator`를 추가했다.

검사 항목은 다음과 같다.

- 비어 있는 아이템 ID
- 허용되지 않은 ID 형식
- 분류와 일치하지 않는 ID 접두사
- 서로 중복된 아이템 ID
- 비어 있는 표시 이름
- 도구의 `Tool Type` 누락
- 도구가 아닌 아이템에 설정된 `Tool Type`
- 도구와 장비의 잘못된 최대 중첩 수량

### 6. 기존 아이템 데이터 정리

기존 아이템 데이터를 새 분류와 표시 데이터 구조에 맞게 정리했다.

| 아이템 | ID | 분류 | 최대 중첩 |
|---|---|---|---:|
| Wood | `resource_wood` | Crafting Material | 20 |
| Stone | `resource_stone` | Crafting Material | 20 |
| Axe | `tool_axe` | Tool | 1 |
| Pickaxe | `tool_pickaxe` | Tool | 1 |

### 7. 확장 분류 테스트 데이터 추가

음식과 장비 분류를 확인하기 위해 다음 데이터를 추가했다.

| 아이템 | ID | 분류 | 최대 중첩 |
|---|---|---|---:|
| Berry | `food_berry` | Food | 20 |
| Cloth Shirt | `equipment_cloth_shirt` | Equipment | 1 |

이번 일차에서는 음식 사용과 장비 장착 기능을 구현하지 않고, 이후 시스템에서 사용할 공통 데이터만 준비했다.

## 테스트 내용

- 정상 아이템 데이터 6종 일괄 검증
- 공백과 대문자가 포함된 잘못된 ID 감지 확인
- 같은 ID를 사용하는 중복 데이터 감지 확인
- 테스트 후 모든 ID와 분류를 정상값으로 복구
- 나무와 돌 획득 및 재료 중첩 확인
- 도끼와 곡괭이 장착 및 대상별 채집 확인
- 잘못된 도구를 사용한 채집 차단 확인
- 인벤토리 드래그와 슬롯 교환 확인
- 이동, 달리기, 점프, 카메라 줌과 벽 충돌 기능 유지 확인
- 데이터 검증 오류 및 Console Error가 없는 상태 확인

## 완료 결과

아이템 데이터를 제작 재료, 도구, 음식, 장비로 확장하고 모든 아이템이 공통 ID 규칙을 따르도록 정리했다. 편집기 검증 기능을 통해 잘못된 형식, 분류별 접두사, 중복 ID와 필수 설정 누락을 개발 중 즉시 확인할 수 있게 되었다.

이번 작업으로 이후 인벤토리 아이콘 표시, 음식 사용, 제작, 장비 장착 기능이 공유할 수 있는 아이템 데이터 기반을 마련했다.
