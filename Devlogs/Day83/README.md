# Project U 개발 일지

## 83일차 : 물고기 출현 조건·끌어올리기 미니게임·낚시 보상 구현

### 1. 개발 목표

82일차에는 찌를 던지고 입질에 챔질하는 흐름까지 만들었지만, 챔질하면 항상 "IT GOT AWAY..."로 끝나 물고기를 얻을 수 없었다.
83일차에는 낚시 콘텐츠(82~83일차)를 마무리하기 위해 어떤 물고기가 무는지 정하고, 끌어올리기 미니게임과 보상을 연결하였다.

이번 일차의 핵심 목표는 다음과 같다.

- 물가·계절·날씨·시각·낚싯대 조건에 따른 물고기 선택
- 출현 가중치와 미끼 효과
- 챔질 후 끌어올리기 미니게임과 HUD
- 성공 시 물고기 지급, 가방이 가득 차면 바닥 드롭
- 잡은 물고기 기록(도감 기초)과 저장
- Play 중 확인용 테스트 메뉴

---

## 2. 물고기 선택

```text
입질 시각 도달
→ 현재 조건 (물가 / 계절 / 날씨 / 시각 / 낚싯대 등급 / 미끼)
→ FishData.CanAppear 통과한 물고기만 후보
→ 출현 가중치로 뽑기 (미끼 사용 시 UNCOMMON 이상 × 1.5)
→ 후보가 없으면 "NOTHING IS BITING..."
```

대표 조건별 확률 (연못, 미끼 사용)

| 조건 | 결과 |
| --- | --- |
| 봄 맑은 아침 | 붕어 57%, 송어 43% |
| 봄 비 오는 아침 | 붕어 52%, 송어 39%, 황금잉어 9% |
| 여름 맑은 밤 | 붕어 63%, 메기 38% |
| 겨울 눈 오는 낮 | 빙어 100% |

- 선택 기능은 `FishSelector`로 분리하여 게임과 검증 도구가 같은 계산을 사용한다.
- 검증 도구에서 모든 물고기가 한 가지 이상의 조건에서 뽑힐 수 있는지 확인한다.

## 3. 끌어올리기 미니게임

```text
[???                          COMMON]
[======   목표 구간   ==|==        ]  ← 왕복하는 표시
[남은 시간 ───────────────        ]
[● ● ○   F - PULL IN THE ZONE   ○ ○ ○]
```

| 항목 | 규칙 |
| --- | --- |
| 입력 | 표시가 목표 구간 안에 있을 때 F |
| 성공 | 필요 성공 횟수 달성 → 물고기 획득 |
| 실수 | 3번 빗나가면 "LINE SNAPPED!" |
| 시간 | 4초 + 성공 1회당 1.2초 + 낚싯대 여유 시간, 초과 시 "IT GOT AWAY..." |
| 난이도 | 표시 속도 0.7~1.7, 목표 폭 32%~16% (난이도에 비례) |
| 진행 | 성공할 때마다 표시 속도 × 1.05, 목표 위치 이동 |
| 취소 | 이동·회피·피격·UI 열림 시 기존 규칙대로 취소, HUD 숨김 |

- F키는 기존 상호작용 입력을 그대로 사용한다. (`FishingController.ReelInput` → 미니게임)
- 처음 보는 물고기는 이름을 "???"로, 잡아 본 물고기는 이름을 보여준다.
- 희귀도는 COMMON / UNCOMMON / RARE / LEGENDARY 색상으로 구분한다.
- 끌어올리는 동안 낚싯줄이 팽팽해지고, 찌가 버둥거리며 진행도만큼 물가로 다가온다.
- 난이도 계산 결과 황금잉어의 입력 가능 시간이 0.07초까지 줄어 너무 어려워, 속도·폭 기본값을 조정하였다.

## 4. 보상과 기록

| 항목 | 내용 |
| --- | --- |
| 지급 | 물고기 아이템 1개 |
| 가방 가득 참 | 발밑에 월드 아이템으로 드롭, "BAG FULL - DROPPED" |
| 알림 | "CAUGHT CRUCIAN CARP!" (희귀도 색), 처음 잡은 종류는 "NEW!" |
| 기록 | 종류별 잡은 횟수, 처음 잡은 날짜 |

- 농사 수확물과 물고기가 같은 바닥 드롭 기능(`WorldItemDropUtility`)을 사용하도록 정리하였다.

저장 데이터

```text
hasFishingData
fishing.catches[] { fishId, caughtCount, firstCaughtDay }
```

- 83일차 이전 저장 파일은 잡은 기록이 없는 상태로 불러온다.
- 빈 ID, 중복 ID, 잘못된 횟수·날짜는 저장 검사에서 오류로 처리한다.

## 5. 생성 도구와 테스트 메뉴

```text
Tools > Project U > Fishing > 1. Build Fishing Content (Data + Prefabs + Pond + Scene)
```

- 출현 조건·보상 참조 연결 (Registry, 낮밤·계절·날씨, 기록, 드롭)
- 플레이어에 잡은 기록과 미니게임 컨트롤러 추가
- 상호작용 안내 위에 미니게임 HUD 생성
- 물고기별 제한 시간 안에 끝낼 수 있는지 검증

```text
Tools > Project U > Fishing > Debug (Play Mode) >
  Bite Now / Win Minigame Now / Log Current Fish Chances
  Force Next Fish > (물고기 선택)
  Weather > Clear / Rain / Storm
```
