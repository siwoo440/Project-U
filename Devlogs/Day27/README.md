# 프로젝트 U 27일차 개발 일지

---

## 1. 개발 목표

설치만 가능했던 모닥불에 연료 소비, 음식 조리, 결과물 회수 기능을 추가했다. 기존 인벤토리·상호작용·건축물 철거 시스템과 연결하여 모닥불 하나에서 조리 과정 전체가 이어지도록 구현했다.

---

## 2. 주요 구현 내용

### 2.1 모닥불 조리 기능

- 설치한 모닥불을 바라보고 `F`를 눌러 조리 시작
- 나무 1개와 사과 1개 소비
- 5초 동안 조리 진행
- 조리 중 남은 시간을 상호작용 안내 문구에 표시
- 조리 완료 후 구운 사과 1개 보관
- 완성된 구운 사과를 `F`로 회수
- 설치된 모닥불마다 조리 상태와 남은 시간을 독립적으로 관리

### 2.2 구운 사과 아이템

- `ItemData_BakedApple` 아이템 데이터 생성
- 아이템 ID를 `food_baked_apple`로 설정
- 표시 이름을 `BAKED APPLE`로 설정
- 음식 분류와 최대 중첩 수량 10 적용
- 섭취 시 허기 40 회복
- 임시 아이콘으로 기존 사과 아이콘 사용

### 2.3 상태별 상호작용 안내

- 대기 상태: `F - COOK APPLE`
- 재료 부족: `NEED 1 APPLE + 1 WOOD`
- 조리 진행: `COOKING - n SEC`
- 조리 완료: `F - TAKE BAKED APPLE`
- 인벤토리 공간 부족: `INVENTORY FULL`
- 동일한 모닥불을 계속 바라보는 중에도 상태 문구 실시간 갱신

### 2.4 불꽃과 조명 연출

- 모닥불 프리팹에 `FireVisualRoot` 추가
- 조리 중 불꽃 파티클과 Point Light 활성화
- 조리 완료 시 불꽃과 조명 비활성화
- 조리하지 않는 모닥불은 연출이 꺼진 상태로 유지

### 2.5 철거 시스템 연동

- 건축물별 철거 제한을 처리하는 `IBuildRemovalGuard` 추가
- 조리 중인 모닥불 철거 차단
- 완성된 음식이 남아 있는 모닥불 철거 차단
- 조리 중 철거 시 `COOKING IN PROGRESS` 표시
- 결과물 미회수 상태에서 철거 시 `COLLECT COOKED FOOD` 표시
- 결과물 회수 후 기존 철거 방식으로 제거 및 재료 반환

### 2.6 예외 처리

- 연료 또는 조리 재료가 부족하면 조리 시작 차단
- 조리 중 `F` 재입력에 의한 중복 조리 차단
- 인벤토리가 가득 차면 결과물 회수 차단
- 회수 실패 시 완성된 음식을 모닥불에 유지
- 재료 제거가 일부만 성공하면 제거된 재료 복구
- 필수 아이템이나 불꽃 오브젝트 참조가 누락되면 오류 출력 후 기능 비활성화

## 4. 테스트 내용

- 나무 1개와 사과 1개가 있을 때 조리 시작 확인
- 조리 시작 시 재료가 정확히 1개씩 감소하는지 확인
- 5초 동안 남은 시간이 안내 문구에 갱신되는지 확인
- 조리 중 불꽃과 조명이 활성화되는지 확인
- 조리 완료 시 불꽃과 조명이 꺼지는지 확인
- 구운 사과 회수와 허기 40 회복 확인
- 사과 또는 나무 부족 시 조리 차단 확인
- 조리 중 중복 입력 차단 확인
- 인벤토리 공간 부족 시 결과물 보존 확인
- 조리 중 및 결과물 미회수 상태의 철거 차단 확인
- 결과물 회수 후 모닥불 철거 가능 여부 확인
- 여러 모닥불의 조리 상태가 독립적으로 작동하는지 확인
- Console 오류가 발생하지 않는지 확인

---

## 5. 완료 결과

장식물 역할만 하던 모닥불이 자원 소비와 음식 획득을 연결하는 생존 설비로 변경됐다. 플레이어는 채집한 나무와 사과를 사용해 더 높은 허기 회복량을 가진 구운 사과를 만들 수 있으며, 조리 상태에 따라 상호작용과 철거 가능 여부가 일관되게 제어된다.
