## 34일차 : 인벤토리·핫바·장비 저장 및 복원

### 개발 목표

33일차에 구현한 플레이어 상태 및 게임 시간 저장 시스템을 확장하여 인벤토리, 핫바, 장비 상태를 저장하고 다시 불러올 수 있도록 구현했다.

아이템 에셋 자체를 저장 파일에 기록하지 않고 각 `ItemData`의 고유한 `Item ID`를 저장한다. 불러오기 시 `ItemDatabase`에서 ID와 일치하는 아이템 데이터를 찾아 기존 슬롯과 장비 상태를 복원하도록 구성했다.

### 주요 구현 내용

- 전체 아이템을 ID 기준으로 조회하는 `ItemDatabase` 구현
- 빈 아이템 참조와 중복 `Item ID` 검사 기능 추가
- 인벤토리 슬롯 번호, 아이템 ID, 수량 저장
- 저장된 인벤토리 슬롯 위치와 수량 복원
- 핫바 1~8번 슬롯 내용 저장 및 복원
- 현재 선택된 핫바 번호 저장 및 복원
- 장비 슬롯 종류와 장착 아이템 ID 저장
- 머리, 몸, 가방 등 장비 상태 복원
- 가방 장착으로 증가한 인벤토리 슬롯 용량 복원
- 장비의 방어력, 최대 체력, 이동 속도, 허기·갈증 감소 효과 재적용
- 등록되지 않은 아이템 ID와 잘못된 저장 데이터 검사
- 기존 플레이어 상태 및 게임 시간 저장 기능과 통합

### 추가 및 수정 파일

| 파일 | 작업 내용 |
|---|---|
| `ItemDatabase.cs` | 아이템 ID 조회와 데이터베이스 유효성 검사 |
| `PlayerInventory.cs` | 불러오기 전 슬롯 초기화와 지정 슬롯 복원 기능 |
| `PlayerEquipment.cs` | 장비 초기화와 저장 장비 직접 복원 기능 |
| `InventorySaveBridge.cs` | 인벤토리·핫바·장비 데이터 수집 및 복원 |
| `GameplaySaveController.cs` | 아이템 저장 연결 검사, 저장 수집, 불러오기 순서 통합 |
| `ItemDatabase.asset` | 프로젝트에서 사용하는 전체 `ItemData` 등록 |

### 저장 데이터 구성

인벤토리는 빈 슬롯을 제외하고 다음 정보를 저장한다.

- 실제 슬롯 번호
- 아이템 고유 ID
- 아이템 수량
- 현재 선택된 핫바 번호

장비는 빈 슬롯을 제외하고 다음 정보를 저장한다.

- 장비 슬롯 종류
- 장착 아이템 고유 ID

저장 파일에는 Unity 에셋 참조를 직접 기록하지 않는다. 따라서 저장 파일을 불러올 때 `ItemDatabase`에 해당 ID가 등록되어 있어야 한다.

### 불러오기 처리 순서

1. 저장 데이터와 아이템 데이터베이스 검사
2. 기존 인벤토리 슬롯 초기화
3. 기존 장비와 가방 추가 용량 초기화
4. 저장된 장비 복원
5. 가방의 추가 슬롯 용량 적용
6. 저장된 인벤토리와 핫바 슬롯 복원
7. 저장 당시 선택한 핫바 번호 적용
8. 장비 능력치 재계산
9. 플레이어 체력과 생존 상태 적용
10. 게임 시간과 플레이어 위치 적용

장비가 최대 체력을 변경할 수 있으므로 장비를 먼저 복원한 뒤 저장된 현재 체력을 적용하도록 순서를 구성했다.

### 오류 방지 처리

- `ItemDatabase`의 빈 항목 차단
- 중복 `Item ID` 차단
- 등록되지 않은 아이템 ID 불러오기 차단
- 인벤토리 슬롯 번호 범위 검사
- 동일 인벤토리 슬롯 중복 저장 차단
- 아이템 최대 중첩 수량 초과 차단
- 장비 슬롯 번호 유효성 검사
- 동일 장비 슬롯 중복 저장 차단
- 장비 슬롯과 아이템 장비 종류 불일치 차단
- 핫바 선택 번호 범위 검사

### Scene 설정

`20_Gameplay` Scene의 `=== SaveSystem ===` 오브젝트에 `InventorySaveBridge`를 추가하고 다음 참조를 연결했다.

| 필드 | 연결 대상 |
|---|---|
| `Player Inventory` | `Player`의 `PlayerInventory` |
| `Player Equipment` | `Player`의 `PlayerEquipment` |
| `Item Database` | `ItemDatabase.asset` |
| `Inventory Save Bridge` | 같은 오브젝트의 `InventorySaveBridge` |
