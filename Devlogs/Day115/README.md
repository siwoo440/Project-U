# Project U 개발 일지

## 115일차 : 35명 통합 점검 · 남은 문제 정리 (예정했던 115 · 116일차를 하루에)

### 1. 개발 목표

섬 이웃 35명이 모두 들어온 뒤 처음으로 **전체를 한 번에 재 보고**, 그동안 쌓인 **남은 문제를 정리**했다.

- 35명일 때 프레임 비용 · 저장 크기 · 광장 붐빔 · 보상 균형을 잰다.
- 아이템 영어 이름, 적이 동료를 무시하는 문제, 말풍선, 지도 밝기, 갈림목 표지판, 관계 없는 이웃, NPC가 나무를 지나가는 문제를 고친다.

이번에도 메뉴 없이 자동 적용으로 넣었다.

## 3. 남은 문제 정리

### 3-1. NPC 자리 (`NpcLocationPoint` · `NpcManager`)

- 한 자리에 다섯 명이 넘으면 **뒤에 엇갈려 한 줄 더** 선다 (광장 12명 : 13.2m 한 줄 → 5.6m 무리).
- 가까운 두 위치(광장 · 카페 등)의 자리가 0.9m보다 가까우면 **다음 자리**로 옮긴다. 벽 · 나무 안의 자리는 길 위로 옮긴 뒤 비교한다.
- 4계절 × 7요일 × 맑음 · 비 × 하루 15시간(840번) 모두 자리 사이 1.2m 이상.

### 3-2. 아이템 한글 이름 (`ItemKoreanNames.csv` → `ItemData.KoreanName`)

- 아이템 62개에 한글 이름을 붙였다 (송어 · 빙어 · 붕어 · 황금 잉어 · 산딸기 · 약초차 …).
- **NPC가 말하거나 NPC 창에 보이는 곳**은 한글 : 동료 채집 말풍선 ("송어 찾았다냥! 너 줄게냥."), 의뢰 진행 · 보상 ("버섯 꼬치 0/2 · 산딸기 0/5" · "붕대 x3"), 선물 창, 대화 창 보상.
- 가방 · 제작 · 상점처럼 영어로 된 화면은 그대로 영어 이름.

### 3-3. 적이 동료도 공격 · 동료 기력 (`NpcCompanionVitality` · `EnemyCombatController`)

- 동료에게 **기력**이 생겼다 (전투형 160 · 치유형 110 · 채집형 100). 6초 동안 맞지 않으면 초당 4씩 찬다.
- 적은 플레이어보다 2m 넘게 가까운 동료를 노린다. 동료가 때리면 그 동료를, 플레이어가 때리면 플레이어를 4초 동안 노린다. 적의 화살 · 투사체도 동료를 맞힌다.
- 기력이 다 떨어지면 동료가 **지쳐서 집으로** 돌아가고, 그날은 "오늘은 너무 지쳤어요. 내일 다시 함께 가요."라며 함께 가지 않는다 (저장됨).
- 화면 왼쪽 아래 동료 표시에 **기력 %**가 보인다 (35% 아래면 붉은색).

### 3-4. 말풍선 (`NpcAgent.BalanceLines` · `WorldTextLayering` · TMP 설정)

- 긴 대사를 띄어쓰기에서 **비슷한 길이의 줄**로 나눈다 (한 줄 20자 기준).
- 한글이 낱말 중간("만들었는 / 데")에서 끊기지 않게 TMP 한글 줄바꿈을 띄어쓰기 기준으로 바꿨다.
- 점검 중 찾은 문제 : 한글 글꼴은 글자판이 여러 장이라 따로 그려지는데, 어두운 바탕(`<mark>`)과 그리는 순서가 섞여 **일부 글자가 흐리거나 사라졌다** (표지판 "깊은 숲 →"이 안 보이고 "110m"만 보이는 경우). 한글 묶음을 항상 바탕 다음에 그리게 했다.

### 3-5. 전체 지도 밝기 (`MinimapCameraController`)

- 지도 카메라가 그리는 동안만 햇빛 · 환경광을 한낮 값으로 바꾸고, 다 그리면 되돌린다.
- 한낮 0.522 · 폭풍 0.522 · 새벽 1시 0.521 · 비 오는 밤 0.521 (전에는 밤 0.066). 게임 화면의 밤은 그대로 어둡다.

### 3-6. 흙길 갈림목 표지판 (`WorldZoneBuilder.RefreshJunctionSigns`)

| 자리 | 표지판 |
| --- | --- |
| 큰길이 구역에 닿는 곳 6곳 | "마을 → 750m"(해안) · 390m(폐허) · 290m(숲) · 260m(설산) · 470m(사막) · 350m(습지) |
| 서쪽 해변 갈림길이 갈라지는 숲 큰길 | "깊은 숲 → 110m" · "마을 → 170m" |
| 석호 갈림길이 갈라지는 사막 큰길 | "붉은 사막 → 400m" · "마을 → 60m" |

- 다른 표지판과 4m 넘게 떨어지게 세운다.

### 3-7. 관계 없던 이웃 12명 (`NpcRelations.csv` 6쌍 추가 → 21쌍, 35명 모두 관계)

| 관계 | 짝 | 만나는 날 (56일 중) |
| --- | --- | --- |
| 짝꿍 | 세레나 · 세이라 (도서관 고서 연구) | 56 |
| 친구 | 아라크네 · 체스카 (상자 안에 깔 천) | 53 |
| 스승과 제자 | 베로나 · 피피 (흙을 기다리는 법) | 52 |
| 친구 | 미레유 · 리제 (양털 온도 38.9도) | 25 |
| 짝꿍 | 리첼 · 드라비아 (광석 감정) | 24 |
| 친구 | 밀키 · 미루 (우유 거품) | 3 |

- 모두 48줄. 처음으로 **스승과 제자** 관계가 쓰였다.

### 3-8. NPC가 나무를 지나가는 문제 (`WorldZoneBuilder.RebakeNavMesh`)

- Terrain 나무는 NavMesh 굽기에 들어가지 않았다. 굽는 동안만 충돌체가 있는 나무 · 바위 4,629개 자리에 같은 크기의 기둥을 세워 길에서 빼고, 다 구우면 지운다.
- 흙길 가까운 나무 411그루 : 줄기 자리가 길인 것 411 → 0. NPC 위치 62곳 모두 마을 광장까지 그대로 갈 수 있다.
- NavMesh 1.7MB → 5.2MB, 삼각형 10,727 → 57,280개, 굽는 시간 1.5초.
- 길이 촘촘해져 섬 끝에서 끝까지는 한 번에 길을 다 못 찾으므로, NPC 일정 검사도 게임 속 NPC처럼 **길 끝에서 이어서 다시 찾아** 끝까지 가는지 본다 (최대 6번).

### 3-9. 자동 적용

- `ProjectUAutoContent`에 `115-integration-polish`를 추가했다 : 한글 줄바꿈 · 아이템 한글 이름 · 관계 21쌍 · 갈림목 표지판 · NavMesh 다시 굽기.
- 전체 콘텐츠 검사에 "아이템 한글 이름" · "115일차 통합 점검"(한글 줄바꿈 · 관계 없는 이웃 · 의뢰 보상 · 표지판 · 나무와 NPC 길)을 넣었다.

점검 중 고친 것

- 표지판 · 말풍선에서 한글이 어두운 바탕에 덮여 안 보이던 문제 (글자판이 여러 장이라 그리는 순서가 섞임) → 한글 묶음을 바탕 다음에 그림
- 자리 겹침을 막을 때 벽 · 나무 안의 자리는 길 위로 옮겨진다는 걸 빼먹어, 도서관에서 두 명이 0.63m까지 붙었다 → 옮긴 자리로 비교
- 나무 자리가 빠져 길 조각이 많아지자, 섬 끝에서 끝까지 한 번에 길을 못 찾아 일정 검사가 오류를 냈다 → 게임 속 NPC처럼 이어서 다시 찾게 함 (점검 도구도 같이 고침)

## 5. 남은 문제

- 가방 · 제작 · 상점 화면은 아직 영어다 (아이템 설명도 영어).
- 실제 화면 프레임(그리기 비용)은 창이 있는 실행에서 재야 한다 (알파 빌드에서 확인).
- 밀키 · 미루는 만나는 날이 적다 (56일 중 3일).
