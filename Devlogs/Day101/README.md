# Project U 개발 일지

## 101일차 : 2차 NPC 7명 등장 (상인 · 제작형)

### 1. 개발 목표

100일차에 준비한 특수 체형 모델과 새 구역을 써서, 2차 NPC 7명이 실제로 섬에 **살게** 했다. 7명은 선물 반응만 있고 집 · 하루 일정 · 대사가 없었다. 오늘은 집 · 일터 · 일정 · 대사 · 초상 · 배치까지 넣고, 가게 · 제작 기능은 102일차로 넘긴다.

| NPC | 종족 · 직업 | 집 | 일터 |
| --- | --- | --- | --- |
| 벨라모르타 | 서큐버스 연금술사 | 마을 서쪽 연금술 공방 | 공방 약병 카운터 |
| 아라크네 | 아라크니아 디자이너 | 폐허 지하 유적 문 (오른쪽) | 무너진 도서관 |
| 미루 | 슬라임 | 습지 웅덩이 속 | 마을 연못 선착장 |
| 카스미 | 여우족 무녀 | 설산 사당 옆 집 | 산기슭 사당 |
| 세이라 | 라미아 독 연구가 | 폐허 지하 유적 문 (왼쪽) | 무너진 도서관 |
| 피피 | 고블린 폐품 기술자 | 마을 동쪽 폐품 작업장 | 작업장 작업대 |
| 사피라 | 스콜피온 독 조제사 | 사막 천막 안 | 사막 천막 앞 |

- 이번 일차는 두 세션이 나눠 작업했다. 먼저 다른 세션이 등장 차수 · 집 위치 · 새 건물 · 초상 구도 · 배치 도구를 만들었고, 그 세션을 멈춘 뒤 이 세션이 이어받아 일정 · 대사 · 선물 · 이동 시간 검사 · 19번 메뉴를 더하고 검증했다.

---

## 2. 등장 차수 (`NpcCharacterData` · `NpcDatabase`)

- `NpcProfileExtras.csv`의 **AlphaCast(참/거짓) 칸을 CastWave(차수) 칸**으로 바꿨다. 0 = 아직 없음, 1 = 알파 7명, 2 = 2차 7명. 예전 AlphaCast 칸도 계속 읽는다.
- `IsPlaced`(섬에 배치) · `GetPlacedCast()`(배치된 모든 NPC) · `GetCastWave(n)`을 추가했다.
- **1차(알파)만** 의뢰 · 하트 이벤트 · 상점을 모두 갖춘 NPC로 검사한다. 2차 상점은 102일차에 붙인다.
- 배치 · 초상 · 대화 · 선물 · 대사 검사는 배치된 모든 NPC에 적용한다 (싫어하는 선물 1개 이상, 인사 2줄 · 잡담 3줄 이상 등).
- NPC 검사 인원 기준을 "알파 7명"에서 **차수별 7명**으로 바꿨다.

## 3. 집 · 새 건물 · 위치

- `NpcLocations.csv`에 **Home(집) 칸**을 추가했다. 집 위치는 밤(21시~6시)에 NPC가 안으로 들어가 보이지 않는다. 마을 · 새 구역 모두 이 값을 쓴다.
- 새 위치 9곳 (모두 41곳)
  - 마을 : 벨라모르타의 연금술 공방(집) · 공방 카운터 · 피피의 폐품 작업장(집) · 작업대
  - 폐허 : 세이라의 지하 거처 · 아라크네의 지하 공방 (지하 유적 문 양옆)
  - 습지 : 미루의 웅덩이 (물가 · 집)
  - 설산 : 카스미의 사당 집
  - 사막 : 사피라의 천막
- 새 건물 3채 (저폴리 모델)

| 건물 | 자리 | 모양 |
| --- | --- | --- |
| 연금술 공방 | 마을 서쪽 | 보랏빛 뾰족 지붕 · 초록 연기 굴뚝 · 둥근 창 · 약병 카운터 · 가마솥 · 간판 |
| 폐품 작업장 | 마을 동쪽 | 함석벽 열린 창고 · 기울어진 지붕 · 작업대와 바이스 · 고철 더미 · 풍차 안테나 |
| 사당 집 | 설산 사당 옆 | 돌 기단 · 툇마루 · 붉은 기둥 · 장지문 · 눈 덮인 검은 지붕 · 금줄 · 붉은 등불 |

- 8번 메뉴(NPC 마을 배치)가 새 구역 위치도 위치 목록대로 다시 만들고, 새 건물을 넣은 뒤 NavMesh를 다시 굽는다.

## 4. 하루 일정 (`NpcSchedules.csv`)

한 명당 **평소 · 특별한 날 · 궂은 날** 3가지 일정이다 (게임 1시간 = 현실 25초). 새 구역에 사는 NPC는 마을까지 걸어서 1~3.5시간이 걸리므로 이동 시간을 넉넉히 두었다.

| NPC | 평소 하루 | 특별한 날 | 궂은 날 |
| --- | --- | --- | --- |
| 벨라모르타 | 공방 물약 → 광장 비밀 거래 → 카페 홍차 → 공방 손님 → 유적 산책 → 잠 | 일요일 : 재고 정리 · 도서관 금서 | 증류 · 카페 · 재료 말리기 |
| 아라크네 | 지하 문 실 잣기 → 도서관 도안 → 해 질 녘 광장 옷차림 구경 → 잠 | 여름 : 밝은 낮을 피해 유적에만 | 거미줄 수리 · 자수 |
| 미루 | 습지 연잎 → 마을 연못 물놀이 → 광장 구경 → 잠 | 여름 : 연못 물놀이 길게 | 빗방울 마시기 · 웅덩이 춤 |
| 카스미 | 사당 기도 → 광장 소문 → 카페 → 늑대족 야영지 → 석등 → 잠 | 토요일 : 광장 점괘 | 빗속 기도 · 부적 쓰기 |
| 세이라 | 도서관 → 광장 햇볕 → 숲 가장자리 독초 → 도서관 연구 → 잠 | 겨울 : 카페에서 몸 녹이기 | 해독제 연구 · 지하 수로 |
| 피피 | 폐품 분해 → 광장 흥정 → 대장간 고철 → 발명 → 카페 수입 계산 → 잠 | 화요일 : 해변 표류물 줍기 | 지붕 수리 · 설계도 |
| 사피라 | 오아시스 약초 → 천막 조제 → 광장 길 안내 → 천막 → 오아시스 → 잠 | 여름 : 새벽 · 저녁에만 움직임 | 모래주머니 · 천막 안 |

## 5. 대사 · 선물

- `NpcDialogue.csv`에 7명의 대사 **127줄**을 추가했다. 캐릭터 시트의 말투를 따랐다 (벨라모르타의 느린 관찰, 미루의 "~" 물결 말투, 카스미의 "후후", 피피의 빠른 흥정, 사피라의 짧은 말 등).
  - 첫 만남 · 단계별 인사 2줄 · 잡담 3줄 · 계절 4줄 · 날씨 3줄 · 선물 반응 4~5줄 · 생일
  - 시트의 인사 · 잡담 · 호감도 반응 · 이벤트 대사가 자동으로 더해져 한 명당 27줄
- `NpcGifts.csv`에 선물 반응 16개를 보강했다 (시트의 선호 물건을 게임 아이템으로 : 벨라모르타 약초 차 · 광석, 아라크네 천, 카스미 붉은 딸기, 피피 장비 부품 등).

## 7. 생성 도구 · 검사

- **19번 메뉴** `Tools > Project U > Build Content > 19. Island NPC Cast (Zones + Village + Portraits)`
  - 18번(새 구역 · 구역 안 집) → 8번(NPC 마을 배치 · Prefab · NavMesh) → 9번(초상 · 대화 창)을 순서대로 실행하고 게임 Scene을 저장한다. 새 차수를 넣을 때 이 메뉴 하나만 실행하면 된다.
- **섬 NPC 차수 검사** (`Validate All Content`에 추가) : 차수마다 집('집' 표시) · 일정 · 대사 20줄 이상 · 초상 · 체형 규칙에 맞는 Prefab · Scene 배치를 확인하고, 상점 준비 수를 보여 준다.
- **일정 이동 시간 검사** (NPC 배치 검사에 추가) : 일정 칸마다 실제 걷는 속도와 NavMesh 길 길이로 이동 시간을 계산해, 다음 일정 전에 도착하지 못하면 오류로 알린다.

## 9. 남은 문제

- 2차 7명은 아직 가게 · 제작 · 의뢰 · 하트 이벤트가 없다 (상점 0/7). 대화 창에 거래 · 의뢰 버튼이 나오지 않는다.
- 미루는 느려서 습지와 마을 사이를 오가는 데 하루의 절반을 쓴다.
- 새 건물 이름표 · NPC 이름표는 에디터 캡처에서는 뒤집혀 보이지만 게임에서는 카메라를 바라본다.
- 섬 NPC가 14명으로 늘었지만 프레임은 창 없는 점검에서만 확인했다. 실제 화면에서 확인이 필요하다.
