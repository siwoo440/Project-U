개발 내용
플레이어 외형의 높이를 보정했다.
상호작용 입력을 E 키 길게 누르기에서 F 키 한 번 누르기로 변경했다.
Interactable Layer를 추가해 상호작용 대상만 탐지하도록 구성했다.
전방 SphereCast 기반의 PlayerInteractor를 구현했다.
상호작용 가능 대상 접근·주시 시 안내 UI가 표시되도록 구현했다.
F 입력으로 동작하는 공통 상호작용 기반과 테스트 Cube를 추가했다.
테스트 Cube가 상호작용 시 회색·초록색으로 전환되도록 구현했다.
커서가 해제된 상태에서는 상호작용이 실행되지 않도록 처리했다.
메인 메뉴와 게임플레이 Scene 왕복 및 Console 오류 여부를 점검했다.
