# Project U 개발 일지

## 85일차 : 요리법·조리 칸·요리 창과 음식 효과 구현

### 1. 개발 목표

84일차 전까지 모닥불은 사과 1개를 넣어 구운 사과 1개를 만드는 기능만 있었다.
85일차에는 농사·낚시로 얻은 재료를 쓰는 요리 콘텐츠를 만들고, 요리 창과 음식 효과까지 연결하였다.

이번 일차의 핵심 목표는 다음과 같다.

- 요리법 데이터와 요리 음식 6종
- 모닥불·돌 모닥불의 시설 등급과 여러 조리 칸
- 요리 창 (요리법 목록 · 상세 · 조리 칸)
- 모닥불 위 진행 고리와 생존 게이지 아래 음식 효과 표시
- 음식 보조 효과 (스태미나 · 보온 · 이동 속도 · 포만감)
- 조리 칸·음식 효과 저장과 이전 저장 파일 호환

## 2. 요리법과 음식

| 요리 | 재료 (+ 나무 1) | 시설 | 시간 | 효과 |
| --- | --- | --- | --- | --- |
| 구운 사과 | 사과 1 | 모닥불 | 5초 | 허기 +40 |
| 구운 감자 | 감자 1 | 모닥불 | 6초 | 허기 +30, 체력 +5 |
| 버섯 꼬치 | 버섯 2 | 모닥불 | 5초 | 허기 +25, 허기 감소 -30% (4분) |
| 생선구이 | 붕어 1 또는 송어 1 | 모닥불 | 8초 | 허기 +35, 스태미나 회복 +30% (3분) |
| 호박 수프 x2 | 호박 1, 물병 1 | 돌 모닥불 | 12초 | 허기 +40, 갈증 +20, 추위 -50% (5분) |
| 토마토 스튜 x2 | 토마토 2, 감자 1, 물병 1 | 돌 모닥불 | 14초 | 허기 +50, 갈증 +15, 체력 +15, 허기 감소 -40% (5분) |
| 황금잉어 정식 | 황금잉어 1, 겨울무 1, 토마토 1 | 돌 모닥불 | 18초 | 허기 +70, 체력 +30, 이동 속도 +12% (5분) |

- `CookingRecipeData` : 요리법 ID, 필요 시설, 재료, 결과 음식·수량, 조리 시간
- 여러 개를 한 번에 조리하면 추가 1개당 시간의 60%만 더 걸린다. (호박 수프 x2 묶음 = 19.2초)
- `ItemData`의 음식 항목에 갈증·체력 회복과 보조 효과(종류·세기·시간)를 추가하였다.
- 새 음식 6종의 저폴리 모델(접시·그릇 요리)과 아이콘, 바닥용 Prefab, 손에 든 외형을 84일차 도구로 만들었다.

## 3. 모닥불 조리 칸

```text
F 입력
→ 완성된 요리가 있으면 먼저 가방으로 꺼냄
→ 꺼낼 것이 없거나 가방이 가득 차면 요리 창 열기
→ 요리법 선택 · 수량 선택 · COOK
→ 빈 칸에서 조리 시작 (재료 + 나무 1 사용)
→ 시간이 지나면 READY → TAKE 또는 F로 꺼내기
```

| 시설 | 등급 | 조리 칸 | 만들 수 있는 요리 |
| --- | --- | --- | --- |
| 모닥불 | Campfire | 2칸 | 5종 |
| 돌 모닥불 | StoneCampfire | 3칸 | 8종 전부 |

- 한 칸에 최대 5묶음까지 넣을 수 있다.
- 조리 중이거나 완성 요리가 남은 모닥불은 철거할 수 없다.
- 조리 중에만 불꽃과 주변 열기가 켜진다.
- 재료를 빼다 실패하면 이미 뺀 재료를 되돌린다.

## 4. 요리 창

```text
[STONE CAMPFIRE COOKING            3 SLOTS · 1 WOOD / COOK   ESC]
[RECIPES          ] [아이콘  PUMPKIN SOUP                      ]
[BAKED APPLE  READY] [       HUNGER +40  THIRST +20  WARM 5:00  ]
[...               ] [INGREDIENTS  PUMPKIN 2/2  WATER 3/2  WOOD  ]
[GRILLED TROUT MISS] [0:20  STONE CAMPFIRE   - x2 +   [COOK x4] ]
[FIRE SLOTS  3 COOKING · 0 READY · 0 EMPTY          알림 문구   ]
[칸 1 진행 막대    ] [칸 2              ] [칸 3                  ]
```

| 영역 | 내용 |
| --- | --- |
| 요리법 목록 | 조리 가능 → 칸 부족 → 재료 부족 → 시설 부족 순서로 정렬, 상태 색 표시 |
| 상세 | 큰 아이콘, 설명, 효과 알약, 재료 보유/필요 (충분하면 청록, 부족하면 빨강) |
| 수량 | 수량에 따라 필요 재료와 조리 시간 변경 |
| 조리 버튼 | COOK / ALL SLOTS BUSY / ONLY x3 POSSIBLE / NEEDS STONE CAMPFIRE |
| 조리 칸 | 진행 막대와 남은 시간, 완성되면 청록 테두리와 TAKE 버튼 |

- 공통 팝업 관리자(`GameUIManager`)에 요리 창 종류를 추가하였다.
- ESC로 닫고, I 키·일시정지·전체 지도를 열면 요리 창이 닫힌다.
- 모닥불이 사라지면 (철거·불러오기) 창이 자동으로 닫힌다.

## 6. 음식 효과

| 효과 | 적용 위치 |
| --- | --- |
| 스태미나 회복 | `PlayerStamina` 회복량 × (1 + 세기) |
| 보온 | `PlayerTemperature` 추위 × (1 - 세기) |
| 이동 속도 | `PlayerMovement` 이동 속도 × (1 + 세기) |
| 포만감 | `PlayerHunger` 허기 감소 × (1 - 세기) |

- 핫바 음식은 허기·갈증·체력·보조 효과 중 하나라도 적용되면 먹는다.
  - 배가 불러도 효과가 있는 요리는 먹을 수 있고, 효과가 없는 음식은 먹지 않는다.
- 같은 효과를 다시 먹으면 남은 시간을 새로 채우고 더 강한 세기를 유지한다.

## 7. 저장

```text
placedStructures[].campfire.hasSlotState
placedStructures[].campfire.slots[] { recipeId, batchCount, remainingSeconds, readyAmount }
hasFoodBuffData
foodBuffs[] { buffType, strength, remainingSeconds, durationSeconds }
```

- 85일차 이전 모닥불 저장(한 칸 구운 사과)은 첫 조리 칸의 구운 사과로 바꿔 불러온다.
- 85일차 이전 저장 파일은 음식 효과가 없는 상태로 불러온다.
- 저장 검사 : 없는 요리법, 시설보다 많은 칸, 조리 중이면서 완성인 칸, 중복 효과를 오류로 처리한다.

## 10. 남은 문제

- 요리 목록이 8개를 넘으면 창 높이를 넘으므로, 요리가 더 늘어나면 스크롤이나 분류 탭이 필요하다.
- 인벤토리 팝업의 장비 칸·제작 목록 글자가 겹치는 문제는 그대로 남아 있다.
