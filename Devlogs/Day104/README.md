# Project U 개발 일지

## 104일차 : 3차 NPC 가게 · 상점 없는 제작 창 · 3차 의뢰와 하트 이벤트

### 1. 개발 목표

103일차에 섬에 들어온 3차 NPC 7명에게 가게 · 제작 · 이야기를 붙였다.

- **마리엘** : 해산물 · 진주 가게 "파도 소리 가게"
- **알리우네** : 상점이 없는 치유 제작 NPC. 대화 창에서 바로 여는 **제작 전용 창**을 새로 만들었다. 1차 루네트도 같은 경우라 함께 붙였다.
- **7명 모두** : 게시판 의뢰 · 특별 의뢰 · 하트 이벤트 3개

이제 1 · 2 · 3차 21명이 모두 가게(상인) · 제작(제작 역할) · 의뢰 · 하트 이벤트를 갖췄다.

---

## 2. 상점 없는 제작 창 (`NpcCraftVendor` · `NpcCraftStations.csv`)

- 대화 창의 거래 버튼이 상점 없는 제작 NPC에게는 **"제작"** 버튼이 된다. 작업 시간이 아니면 "제작 (닫힘)"으로 바뀌고, 누르면 다음 작업 시각을 알려 준다.
- 제작 창은 102일차 상인 창의 제작 탭을 그대로 쓴다. 사기 · 팔기 탭과 TAB 안내를 숨기고, 제작 탭을 첫 칸으로 옮긴다.
- 작업 시간은 일정 데이터로 정한다 (주인이 작업 위치에 있을 때).

| NPC | 작업장 | 작업 위치 | 봄 월요일 작업 시간 |
| --- | --- | --- | --- |
| 알리우네 | 치유 온실 | 숲 가장자리 · 농장 밭 | 09:00 ~ 19:00 |
| 루네트 | 약초 오두막 | 숲 가장자리 · 마을 광장 | 08:00 ~ 12:00, 14:00 ~ 20:00 |

- 수수료 할인은 가게와 같은 단계별 할인율(신뢰 5% · 애정 10% · 사랑 15%)을 쓴다.
- 코드 정리
  - 상점과 작업장이 같은 영업 시간 계산을 쓰도록 `INpcWorkplace`(주인 · 영업 위치)를 추가했다.
  - 제작 주문 처리를 상점이 아니라 **주문서** 기준으로 바꿨다. 상점 기준 호출도 그대로 쓸 수 있다.

  - 영업 : 갯바위 · 마을 연못 (06~10시, 13~20시)

## 5. 3차 의뢰 · 하트 이벤트

- 이야기 차수(`StoryReadyWave`)를 3으로 올렸다.
- 의뢰 28개 : 한 명당 게시판 의뢰 3개(모든 계절에 하나 이상) + 특별 의뢰 1개(신뢰 + 신뢰 이벤트 뒤)
  - 특별 의뢰 보상 : 세레나 약초 차, 리리엘 겨울무 씨앗, 체스카 · 마리엘 진주, 루미나 딸기 씨앗, 네리 지렁이 미끼, 알리우네 꽃잎 연고
- 하트 이벤트 21개 : 호기심 · 신뢰 · 애정, 장소 · 시간은 일정상 그 NPC가 있는 곳
  - 예 : 세레나 "잊혀진 시 한 줄"(도서관), 체스카 "빼앗긴 보물"(지하 문), 마리엘 "연못의 진주"(마을 연못), 네리 "빗속 개골 합창"(비 오는 새벽 습지)
