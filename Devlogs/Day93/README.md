# Project U 개발 일지

## 93일차 : 마을 게시판과 NPC 의뢰(받기·전달·기한·특별 의뢰) 구현

### 1. 개발 목표

92일차까지 NPC와 대화하고, 선물하고, 사고팔 수 있게 됐다. 이번에는 NPC가 플레이어에게 **부탁(의뢰)** 을 하게 만들었다. 광장 게시판(90일차)에 의뢰 쪽지가 붙고, 물건을 모아 의뢰한 NPC에게 가져다주면 코인과 호감도를 받는다.

- NPC 7명의 의뢰 데이터 (게시판 의뢰 · 관계가 깊어지면 열리는 특별 의뢰)
- 광장 게시판 창 : 오늘의 의뢰 받기 · 진행 중 의뢰 포기
- 대화 창의 의뢰 전달 버튼과 보상 (코인 · 호감도 · 아이템)
- 기한 · 하루마다 바뀌는 게시판 · 동시에 받을 수 있는 수 제한
- NPC 머리 위 의뢰 표시와 화면의 진행 중 의뢰 표시
- 저장 · 생성 메뉴(11번) · 검사

## 2. 의뢰 데이터

원본 `Data/Npc/Source/NpcQuests.csv` 한 개로 만든다. 생성 도구가 NPC마다 `Data/Npc/Quests/NpcQuests_이름.asset`(`NpcQuestBook`)을 만들고, 캐릭터 데이터의 `questGroupId`(`quest_mio` 등)와 연결한다.

| 칸 | 내용 |
| --- | --- |
| 종류 | 게시판(Board) : 여러 번 나옴 / 특별(Special) : 한 번만 |
| 필요한 물건 | 1~3종 (`resource_fish_crucian:3`) |
| 보상 | 코인 · 호감도 · 아이템 |
| 기한 | 받은 날부터 며칠 안에 전달 (2~5일) |
| 계절 · 관계 단계 | 게시판에 나오는 계절, 필요한 관계 단계 |
| 대사 | 의뢰 대사(게시판 쪽지) · 감사 대사(전달할 때) |

### 의뢰 29개 (게시판 22 · 특별 7)

| NPC | 게시판 의뢰 | 특별 의뢰 ('신뢰' 단계부터) |
| --- | --- | --- |
| 루네트 | 숲 버섯 4 · 열매 6 · 사과 4 | 버섯 꼬치 2 + 열매 5 → 붕대 3 |
| 베로나 | 감자 5(봄) · 토마토 5(여름) · 호박 2(가을) · 겨울무 4(겨울) | 구운 감자 4 → 호박 씨앗 6 |

| 미레유 | 사과 5 · 달걀 3 · 식물 섬유 10 | 따뜻한 우유 2 + 섬유 10 → 사료 10 |
| 밀키 | 우유 3 · 딸기 6(봄) · 호박 2(가을) | 황금 잉어 + 우유 2 → 따뜻한 우유 2 |
| 드라비아 | 철광석 5 · 돌 20 · 나무 20 | 철광석 10 + 구운 생선 2 → 철 도끼 |

- 보상 코인은 판매 상자 값보다 조금 많게 정하고, 호감도는 +3~5 (특별 의뢰 +10~12)이다.

## 3. 의뢰 관리자 (`NpcQuestManager`)

| 규칙 | 내용 |
| --- | --- |
| 게시판 | 날짜가 바뀌면 하루 3장, 한 사람당 1장, 같은 날이면 항상 같은 의뢰 |
| 게시 조건 | 계절 · 관계 단계가 맞고, 그 NPC의 의뢰를 진행 중이 아닐 것 |
| 특별 의뢰 | 조건이 맞으면 먼저 붙고 (하루 1장), 끝내면 다시 나오지 않음 |
| 받기 | 동시에 3개까지, 받은 의뢰는 게시판에서 빠짐 |
| 포기 | 진행 중 목록에서 버튼을 두 번 눌러 포기 |
| 전달 | 필요한 물건을 가방에서 빼고 코인 · 호감도 · 아이템 지급, 보상 받을 자리가 없으면 막음 |
| 기한 | 마감 날이 지나면 사라지고 알림 |

- 호감도 보상은 91일차 관계 관리자로 올려서, 단계가 오르면 대화 창에 단계 알림이 함께 나온다.
- 완료 · 만료 · 게시판 변경을 이벤트로 알린다 (94일차 이후 이벤트 · 도감에서 사용 예정).

## 4. 화면

### 광장 게시판 창 (`NpcQuestBoardPopup`)

```text
[아이콘] 마을 게시판                          오늘의 의뢰 3 · 진행 중 1/3   [ESC]
[초상] 약초사의 사과   루네트 · 3일 안에      | [초상] 루네트 약초사
[초상] 봄 감자 수확    베로나 · 3일 안에      |        약초사의 사과
[초상] 저녁 반찬 붕어  미오 · 2일 남음 [진행 중] |  "사과를 말려서 차에 넣으려고요…"
                                             | 필요한 물건 [APPLE 0 / 4]
                                             | 보상 코인 25 · 호감도 +3
                                             | 받은 날부터 3일 안에 전달   [ 의뢰 받기 ]
```

- 목록은 오늘의 의뢰 다음에 진행 중 의뢰를 보여 주고, `특별` · `진행 중` · `전달 가능` 표시를 붙인다.
- 받을 수 없으면 버튼에 이유를 보여 준다 (`의뢰는 3개까지 받을 수 있어요.`).
- 게시판에서 6m 넘게 멀어지면 창을 닫는다.
- `GameUIManager`에 게시판 창 종류(`QuestBoard`)를 추가했다.

### 광장 게시판 상호작용 (`QuestBoard`)

- 90일차 게시판 건물에 상호작용 충돌체를 달았다 (상호작용 레이어).
- 안내 문구 : `F - 마을 게시판 | 새 의뢰 3 · 진행 중 1/3`

### 대화 창 의뢰 버튼

- 대화 창 버튼을 한 칸 40px로 줄이고 `의뢰 전달` 버튼을 넣었다 (대화하기 · 선물하기 · 의뢰 · 거래 · 닫기).
- 그 NPC에게 받은 의뢰가 있을 때만 보인다.
  - 물건이 모자라면 `의뢰 (0/4)`, 누르면 `APPLE 4개가 더 필요해요.`와 남은 날
  - 다 모았으면 `의뢰 전달`, 누르면 감사 대사와 `의뢰 완료 · 코인 +25 · 호감도 +3`

### NPC 머리 위 표시 · 진행 중 의뢰 표시

- 이름표 위에 `?`(진행 중) · `!`(전달 가능)를 띄운다. 가방이 바뀌면 바로 갱신된다.
- 화면 왼쪽 음식 효과 아래에 진행 중 의뢰를 보여 준다.

```text
의뢰 2/3
루네트  약초사의 사과
APPLE 4/4 · 전달 가능!
베로나  봄 감자 수확
POTATO 0/5 · 3일 남음
```

- 완료 · 기한 만료 알림을 6초 동안 함께 보여 준다.
- 처음에는 화면 오른쪽 시간 표시 아래에 두었는데, 주변 아이템 창(75일차)과 같은 자리라서 왼쪽으로 옮겼다.

## 5. 저장 (`NpcQuestSaveBridge`)

```text
hasNpcQuestData
npcQuests { boardDay, board[], active[] { questId, acceptedDay, deadlineDay },
            records[] { questId, completedCount, lastCompletedDay }, totalCompleted, totalExpired }
```

- 관계 복원 뒤에 복원한다 (특별 의뢰 조건이 관계 단계를 보기 때문).
- 같은 날 저장이면 게시판을 그대로, 다른 날이면 그날 게시판을 새로 붙인다.
- 데이터에서 사라진 의뢰 ID는 버린다.
- 93일차 이전 저장 파일은 의뢰 없이 그날 게시판으로 시작한다.
- 검사 : 의뢰 ID(`quest_`), 게시판 · 진행 중 중복, 마감 날짜, 완료 기록, 개수 상한

## 6. 생성 도구 · 테스트 메뉴

- `Tools > Project U > Build Content > 11. NPC Quests (Board + Requests + Delivery)`
  - 원본 CSV → 의뢰 묶음 7개 → 한글 글꼴 확인 → 의뢰 관리자 → 게시판 상호작용 → 게시판 창 → 진행 중 의뢰 표시 → 대화 창 다시 생성(의뢰 버튼) → 검사
  - 여러 번 실행해도 결과가 같다.
- 9번 메뉴(NPC 대화)도 의뢰 버튼이 있는 대화 창을 만들도록 바꿨다.
- `Debug (Play Mode) > NPC` : Log NPC Quests · Refresh Quest Board (Today) · Accept Board Quests · Give Items For Active Quests
- `Validate All Content`에 **NPC 의뢰** 검사를 추가했다.
  - NPC 7명의 의뢰 묶음 · 퀘스트 역할 · 의뢰 상호작용
  - 의뢰 ID · 대사 · 필요 물건(1~3종, 중복) · 보상 호감도 · 기한(1~7일)
  - 작물 · 물고기는 나오는 계절에 얻을 수 있는지 (그 계절에 파는 NPC 상점이 있으면 허용)
  - 게시판 의뢰 보상이 필요 물건을 상점에서 사는 값보다 크지 않은지 (사서 전달하는 반복 이익 방지)
  - 계절마다 NPC별 게시판 의뢰가 있는지, NPC마다 특별 의뢰가 있는지
  - 한글 글꼴, Scene 연결 (관리자 · 게시판 · 창 · 의뢰 표시 · 대화 창 버튼)
  - 생활 연결 검사 : 의뢰에 필요한 물건을 게임 안에서 구할 수 있는지

## 8. 남은 문제

- 의뢰는 "물건 가져오기" 한 종류뿐이다 (잡기 · 만들기 · 찾아가기 의뢰는 없음).
- 의뢰를 포기하거나 기한이 지나도 호감도는 줄지 않는다.
- 게시판 건물 모델에 쪽지가 붙는 모습은 따로 바뀌지 않는다.
- 아이템 이름은 영어, 의뢰 문구는 한국어로 섞여 보인다.

## 9. 다음 개발

94일차에는 NPC 이벤트(하트 이벤트)를 만든다. 호감도 단계가 오르면 그 NPC의 짧은 이야기 장면(대사 여러 줄 · 선택지)이 열리고, 선택에 따라 호감도가 달라진다. 본 이벤트를 저장한다.
