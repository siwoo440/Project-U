# Project U 개발 일지

---

## 46일차 : 환경 생존 수직 슬라이스 통합 점검

### 개발 목표

지금까지 구현한 환경과 생존 기능을 하나의 플레이 흐름으로 연결해 점검한다. 계절과 날씨 변화부터 젖음·체온, 모닥불, 수면, 사망과 부활, 저장과 이어하기까지 각 시스템이 충돌하지 않고 정상적으로 연동되는지 확인한다.

### 구현 내용

#### 1. 환경 통합 테스트 도구 추가

- 환경 상태를 빠르게 변경할 수 있는 `EnvironmentSliceTestController` 추가
- 봄 마지막 날과 계절 변경 경계 상태 준비 기능 추가
- 겨울 폭풍과 저체온 상태 준비 기능 추가
- 여름 맑은 날과 열사병 상태 준비 기능 추가
- 현재 날짜·시간·계절·날씨·젖음·체온·체력을 Console에 출력하는 기능 추가
- 테스트 상태 저장·불러오기 기능 추가
- 부활 테스트를 위한 플레이어 사망 실행 기능 추가

#### 2. 계절과 날씨 진행 점검

- 28일에서 29일로 넘어갈 때 봄에서 여름으로 변경되는지 확인
- 수면으로 건너뛴 시간만큼 날씨 지속 시간이 처리되는지 확인
- 기존 날씨 종료 후 다음 날씨가 정상적으로 적용되는지 확인
- 날씨 남은 시간이 음수가 되지 않는지 확인
- 비와 폭풍의 HUD·파티클·안개·조명·환경음 적용 확인

#### 3. 젖음과 체온 상태 점검

- 비와 폭풍 속 야외 활동 시 젖음 증가 확인
- 지붕 아래에서 젖음 증가 중단과 감소 확인
- 계절·날씨·젖음에 따른 체온 변화 확인
- 저체온과 열사병 상태의 이동·스태미나·생존 불이익 확인
- 모닥불 열기 범위에서 체온 회복과 저체온 피해 중단 확인

#### 4. 모닥불과 수면 연동 점검

- 모닥불 연료와 조리 재료 사용 확인
- 악천후 중 조리 진행과 완성 음식 회수 확인
- 조리 중 모닥불 철거 차단 확인
- 침낭 수면 후 날짜와 시간 변경 확인
- 수면 후 체력 회복과 허기·갈증 소비 확인
- 사용한 침낭의 부활 지점 등록 확인
- 기상 완료 후 자동 저장과 입력 상태 복구 확인

#### 5. 사망과 부활 점검

- 환경 피해에 의한 플레이어 사망 처리 확인
- 사망 화면의 부활 버튼 작동 확인
- 등록한 침낭 위치로 이동하는지 확인
- 부활 후 체력·허기·갈증·체온·젖음 초기화 확인
- 이동·점프·카메라·상호작용 복구 확인
- Scene을 다시 불러오지 않고 환경 시스템이 계속 진행되는지 확인

#### 6. 저장과 이어하기 점검

- 날짜·시간·계절·날씨와 날씨 남은 시간 저장·복원 확인
- 젖음·체온과 관련 상태 효과 복원 확인
- 플레이어 위치와 설치한 모닥불·침낭 복원 확인
- 침낭 부활 지점 복원 확인
- 메인 메뉴 이어하기 후 환경 연출과 음향 복원 확인
- 중복 관리자·환경음·파티클 생성 여부 확인

### 개발 결과

계절·날씨·젖음·체온·모닥불·수면·부활·저장 시스템의 통합 동작을 점검했다. 계절 경계와 악천후에서도 플레이어 상태와 환경 연출이 정상적으로 유지되며, 저장·불러오기와 메인 메뉴 이어하기 이후에도 기존 환경 상태가 복원되는 것을 확인했다.
