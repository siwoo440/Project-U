# 50일차 개발 일지

---

## 개발 목표

플레이어가 소형·대형 보관함을 열어 인벤토리의 아이템을 자유롭게 이동하고, 보관함 데이터를 게임 저장 파일에 함께 저장할 수 있도록 구현한다.

---

## 구현 내용

* 소형·대형 보관함 데이터 구조 구현
* 보관함마다 독립적인 식별자와 슬롯 데이터 적용
* 보관함 팝업 UI 구성
* 플레이어 인벤토리와 보관함 슬롯 동시 표시
* 플레이어 인벤토리와 보관함 사이 드래그 이동 구현
* 보관함 내부 슬롯 간 아이템 이동 구현
* 같은 아이템 중첩 및 최대 중첩 수량 처리
* 서로 다른 아이템의 슬롯 교환 처리
* 보관함 데이터 저장·불러오기 기능 연결
* 소형·대형 보관함 저장 데이터 분리
* 이전 버전 저장 파일에서 보관함을 빈 상태로 초기화하도록 처리
* 저장 또는 불러오기 이후 열려 있던 보관함 팝업 자동 종료 처리

---

## 드래그 문제 수정

보관함 슬롯의 일부 영역에서만 아이템 드롭이 인식되던 문제를 수정했다.

`StorageSlotTemplate`의 루트 `Image`가 드롭 이벤트를 받도록 `Raycast Target`을 활성화하고, 자식 아이콘과 텍스트의 `Raycast Target`을 비활성화했다.

각 슬롯 템플릿이 다른 오브젝트의 드래그 처리기를 참조하지 않도록 독립적인 `ItemSlotDragHandler`를 연결했다.

보관함 팝업에서는 별도의 Alt 키 입력 없이 아이템을 드래그할 수 있도록 `InventorySlotsUI` 설정을 수정했다.

* 보관함에서 플레이어 인벤토리로 이동 정상
* 보관함 내부 슬롯 이동 정상

* 서로 다른 아이템 교환 정상
* 슬롯 전체 영역의 드롭 인식 정상
* 소형·대형 보관함 데이터 분리 정상
* 저장 후 보관함 슬롯과 수량 복원 정상

* 아이템 복제 및 소실 없음

## 개발 결과

플레이어 인벤토리와 보관함 사이에서 아이템을 안정적으로 이동할 수 있게 되었다. 보관함별 아이템 상태가 저장 데이터에 포함되면서 게임을 종료하거나 저장 파일을 불러온 이후에도 슬롯 위치와 수량이 유지된다.
