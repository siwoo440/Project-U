# 프로젝트 U 12일차 개발 일지

---

## 개발 목표

플레이어의 지면 판정을 보완하고, 경사면 이동과 낙하·착지 상태를 안정적으로 구분할 수 있는 이동 기반을 구현했다.

---

## 주요 개발 내용

### 1. 지면 판정 보완

- `SphereCast`를 이용한 플레이어 발밑 지면 검사
- 평지, 경사면, 지면 모서리에서 접지 상태 확인
- 플레이어 전용 레이어와 지면 검사 마스크 분리
- 지면에 있을 때 하강 속도를 적용해 지면 밀착 유지

### 2. 점프 판정 안정화

- 새 접지 결과를 기준으로 점프 가능 여부 판정
- 지면에서만 점프 허용
- 공중에서 추가 점프가 실행되지 않도록 제한
- 점프 상승과 중력 적용 구조 유지

### 3. 경사면 이동 보완

- 충돌한 지면의 법선 방향과 경사 각도 계산
- 이동 방향을 경사면 표면에 맞게 보정
- `CharacterController`의 `Slope Limit`을 기준으로 보행 가능 경사 구분
- 45도를 초과하는 급경사 등반 제한

### 4. 낙하와 착지 상태 구현

- 플레이어가 공중에서 하강을 시작한 높이 기록
- 착지 시 낙하 시작 높이와 현재 높이로 낙하 거리 계산
- 마지막 낙하 거리와 유효 낙하 여부 저장
- 1.5m 이상 낙하를 유효 낙하로 구분
- 이후 낙하 피해, 착지 연출, 효과음에 사용할 공개 값 제공

### 5. 기존 이동 기능 유지

- 카메라 기준 이동 방향 유지
- 걷기와 달리기 속도 전환 유지
- 달리기 스태미나 소비·회복·탈진 기능 유지
- 인벤토리, 핫바, 도구 장착과 채집 기능 유지

## 주요 설정값

| 항목 | 설정값 | 설명 |
|---|---:|---|
| Ground Check Distance | 0.15 | 발밑 지면 검사 거리 |
| Ground Probe Radius Offset | 0.05 | 검사 구체 반지름 감소값 |
| Grounded Vertical Velocity | -2 | 지면 밀착용 하강 속도 |
| Minimum Fall Distance | 1.5 | 유효 낙하 최소 거리 |
| Slope Limit | 45 | 이동 가능한 최대 경사 각도 |
| Step Offset | 0.3 | 오를 수 있는 단차 높이 |
| Skin Width | 0.08 | 충돌 여유 범위 |

## 테스트 결과

- 평지에서 정지하거나 이동할 때 접지 상태가 유지됨
- 점프 시 접지 상태가 해제되고 공중 추가 점프가 차단됨
- 점프 상승이 끝난 뒤 하강할 때 낙하 상태가 활성화됨
- 착지 시 마지막 낙하 거리가 정상적으로 기록됨
- 낮은 높이의 낙하는 유효 낙하로 판정되지 않음
- 1.5m 이상의 낙하는 유효 낙하로 판정됨
- 20도와 35도 경사면을 정상적으로 오르내릴 수 있음
- 50도 경사면은 경사 제한으로 등반이 차단됨
- 경사면 이동 중 접지 상태가 불필요하게 반복되지 않음
- 달리기와 스태미나 기능이 기존처럼 작동함
- 인벤토리, 핫바, 도구 장착과 채집 기능이 정상 작동함
- Console에서 빨간색 Error가 발생하지 않음

---

## 완료 결과

플레이어 이동이 평지뿐 아니라 경사면과 낙하 상황에서도 안정적으로 상태를 구분하도록 보완되었다. 낙하 거리와 유효 낙하 여부를 외부에서 확인할 수 있어 이후 낙하 피해, 착지 애니메이션, 효과음과 카메라 연출을 연결할 수 있는 기반을 마련했다.
