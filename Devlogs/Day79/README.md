# Project U 개발 일지

## 79일차 : 씨앗·작물 데이터와 밭 콘텐츠 준비

### 1. 개발 목표

79일차부터 기획서의 **농사 콘텐츠(79~81일차)** 를 시작하였다.

기획서 79일차 완료 기준:

```text
대표 씨앗과 작물의 성장 시간·계절·수확물 데이터를 작성하고
밭·씨앗·물주기 구현에 사용할 콘텐츠를 준비한다.
```

| 일차 | 내용 |
| --- | --- |
| 79일차 | 씨앗·작물 데이터, 밭·도구 콘텐츠 준비 (이번 일차) |
| 80일차 | 밭 설치·씨앗 심기·물주기 구현 |
| 81일차 | 작물 성장·계절·날씨·수확 구현 |

이번 일차의 핵심 목표는 다음과 같다.

- 씨앗 아이템 분류와 농사 도구 종류 추가
- 작물 데이터(`CropData`)와 농사 규칙 데이터(`FarmingRulesData`) 추가
- 대표 작물 5종과 씨앗·수확물 데이터 작성
- 괭이·물뿌리개 아이템과 작업대 제작법 추가
- 거점에 설치하는 밭 건축물 추가
- 작물 성장 단계·씨앗·수확물·도구 저폴리 모델 추가
- 모든 콘텐츠를 한 번에 만들고 연결하는 에디터 도구 추가
- 농사 콘텐츠 검증 도구 추가

---

## 2. 기획서 농사 규칙 정리

```text
밭 만들기 → 씨앗 심기 → 물 주기 → 성장 대기 → 수확 → 요리 / 선물 / 판매 / 의뢰
```

| 항목 | 규칙 |
| --- | --- |
| 농사 위치 | 플레이어 거점(하우징 구역) 안 |
| 밭 생성 | 괭이 또는 건축 모드로 밭 배치 |
| 물 주기 | 매일 필요, 비·폭풍인 날은 생략 |
| 물을 주지 않은 날 | 성장 정지 |
| 수확량 | 작물별 최소~최대 사이에서 랜덤 |
| 계절 | 일부 작물은 특정 계절에만 성장 |
| 폭풍 | 낮은 확률로 작물 피해 |

## 4. 작물 데이터 `CropData`

작물 하나의 성장·계절·수확 정보를 담는 ScriptableObject를 추가하였다.

| 필드 | 설명 |
| --- | --- |
| `cropId` | `crop_` 접두사 고유 ID |
| `cropCategory` | 기본 / 계절 / 요리 / 선물 / 특수 작물 |
| `seedItem`, `harvestItem` | 씨앗과 수확 아이템 |
| `minimumHarvestAmount`, `maximumHarvestAmount` | 수확량 범위 |
| `seedReturnChance` | 수확 시 씨앗 반환 확률 |
| `growthDays` | 물을 받은 날 기준 전체 성장 일수 |
| `growthStages` | 단계 이름, 시작 일수, 단계 외형 Prefab |
| `requiresWater` | 물을 받은 날에만 성장 |
| `growingSeasons` | 성장 가능 계절 |
| `greenhouseAllowed` | 후반 온실 재배 허용 |
| `stormDamageChance` | 폭풍 피해 확률 |

주요 기능:

- `CanGrowInSeason()` : 계절 성장 가능 여부
- `GetStageIndex()` : 누적 성장 일수에 맞는 외형 단계
- `IsFullyGrown()` : 수확 가능 여부
- `RollHarvestAmount()` : 수확량 계산
- `TryValidate()` : 씨앗 분류, 수확량 범위, 계절, 단계 순서, 마지막 단계 일수 검사

## 6. 대표 작물 5종

기획서 9.2의 작물 성장 예시를 기준으로 작성하였다.

| 작물 | 분류 | 계절 | 성장 | 수확량 | 온실 |
| --- | --- | --- | --- | --- | --- |
| 감자 | 기본 | 봄 | 3일 | 1~3 | 가능 |
| 딸기 | 계절 | 봄 | 5일 | 2~5 | 가능 |
| 토마토 | 요리 | 여름 | 6일 | 2~4 | 가능 |
| 호박 | 계절 | 가을 | 7일 | 1~2 | 불가 |
| 겨울무 | 계절 | 겨울 | 4일 | 1~3 | 불가 |

성장 단계는 모두 4단계로 구성하였다.

```text
SEEDED(심은 직후) → SPROUT(새싹) → GROWING(성장) → MATURE(수확 가능)
```

기획서 아이템 시트에는 `기본 작물 씨앗` 한 종류만 있지만,
작물마다 심을 대상을 구분하기 위해 작물별 씨앗을 따로 만들었다.

## 8. 밭 건축물

| 항목 | 값 |
| --- | --- |
| ID | `structure_farm_plot` |
| 구조 역할 | None (지지 구조 불필요) |
| 배치 | Floor (건축 그리드 1칸 중앙) |
| 재료 | 없음 (기획서: 제작이 아닌 지면 전환) |
| 철거 반환 | 0 |

```text
FarmPlotPlaced
├─ BoxCollider / WorldObjectIdentity / PlacedBuildObject
├─ Soil (기본 도형, 외형 크기 기준)
├─ CropAnchor (작물 외형 기준점)
└─ LP_Visual (밭 모델)
   └─ WetSoil (물 준 흙, 기본 꺼짐)
```

`PlacedStructureSaveBridge`에 등록되어 저장·불러오기 대상이 된다.
괭이를 들어야 설치되는 조건은 80일차에 추가한다.

## 9. 저폴리 모델

`StylizedModelLibrary.Farming`에 농사 모델 27종을 추가하였다.

| 분류 | 모델 |
| --- | --- |
| 밭 | 경작지(이랑 2줄 + 나무 테두리), 젖은 흙 |
| 공통 단계 | 심은 직후 흙더미, 새싹 |
| 작물별 단계 | 감자·딸기·토마토·호박·겨울무의 성장 / 완성 외형 |
| 수확물 | 감자, 딸기, 토마토, 호박, 겨울무 |
| 씨앗 | 작물별 색 띠와 그림이 있는 씨앗 봉투 5종 |
| 도구 | 괭이, 물뿌리개 |
| 소품 | 허수아비 |

한 칸(1m)에 네 포기를 심고, 호박은 한 칸에 한 포기를 크게 표시한다.
흙·젖은 흙·감자·호박·토마토·딸기·씨앗 종이·작물 줄기 색상을 공용 색상표에 추가하였다.

## 10. 농사 콘텐츠 생성 도구

```text
Tools > Project U > Farming
├─ 1. Build Farming Content (Data + Prefabs + Scene)
└─ 2. Validate Farming Content
```

생성 메뉴가 처리하는 내용:

1. 농사 모델 생성
2. 아이템·제작법·작물·규칙 데이터 생성 또는 갱신
3. 밭 설치·미리보기 Prefab과 건축 데이터 생성
4. 씨앗·수확물·도구 월드 아이템 Prefab 생성
5. `ItemDatabase`, 월드 아이템 Registry 등록
6. `GameDataRegistry` 자동 수집
7. 현재 게임 Scene 연결
   - 제작법 해금 목록, 건축 목록, 건축물 저장 목록 추가
   - 손에 든 괭이·물뿌리개 외형 생성
   - 거점 가장자리에 농사 시작 아이템(씨앗 5종 각 6개, 괭이, 물뿌리개)과 허수아비 배치
   - 월드 오브젝트 저장 ID 발급

여러 번 실행해도 기존 Asset을 갱신하며 중복으로 생성하지 않는다.

## 12. 발견한 기존 버그 수정

`ItemDatabase`에 **활(`weapon_bow`)과 화살(`item_arrow`)** 이 등록되어 있지 않았다.

```text
월드 또는 인벤토리에 활·화살이 있음
→ WorldSaveBridge / InventorySaveBridge에서 ID 조회 실패
→ 저장 실패
```

생성 도구가 프로젝트의 모든 `ItemData`를 `ItemDatabase`에 채우도록 하였고,
검증 도구에서 누락 아이템을 오류로 표시하도록 하였다.

## 14. 정리

79일차에는 농사 구현에 필요한 씨앗·작물·수확물·도구 데이터와
밭 건축물, 단계별 작물 외형을 준비하고 게임 데이터와 Scene에 연결하였다.

80일차에는 이 데이터를 이용해
괭이로 밭을 만들고, 씨앗을 심고, 물뿌리개로 물을 주는 기능을 구현한다.
