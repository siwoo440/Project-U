# Project U 개발 일지

## 87일차 : 판매 상자·코인·떠돌이 상인 상점 구현

### 1. 개발 목표

농사(79~81일차), 낚시(82~83일차), 요리(85일차), 가축(86일차)으로 얻은 물건을 코인으로 바꾸고, 그 코인으로 씨앗·사료를 사서 다시 생산을 늘리는 순환을 만들었다.

이번 일차의 핵심 목표는 다음과 같다.

- 판매 가격표 (제철 · 희귀도 · 요리 가산 · 대량 판매 규칙)
- 플레이어 코인 지갑과 코인 표시
- 판매 상자 : 넣어 둔 물건을 자정에 판매
- 상인 가판대와 상인 창 (오늘 재고 사기 · 판매 가격표)
- 코인 · 상인 재고 · 판매 기록 저장

---

## 2. 판매 가격표

판매 상자는 가격표(`MarketCatalogData`)에 있는 아이템만 사 준다. 도구·장비·무기는 팔 수 없다.

| 분류 | 가격 정하는 방법 | 예시 |
| --- | --- | --- |
| 작물 | 고정 가격, 재배 계절에는 제철 +25% | 감자 8 (봄 10), 호박 28 (가을 35) |
| 채집물 | 고정 가격 | 사과 4, 야생 버섯 6 |
| 가축 생산물 | 고정 가격 | 달걀 10, 우유 16 |
| 물고기 | 14 × 희귀도 배율 × (1 + 난이도 × 0.5) | 붕어 15, 송어 34, 황금 잉어 96 |
| 요리 | 재료 가격 합 × 1.5 + 4 | 달걀 프라이 34, 황금 잉어 만찬 180 |
| 씨앗 | 상인 가격의 절반 | 감자 씨앗 3 |
| 재료·소모품 | 고정 가격 | 나무 1, 철광석 7, 붕대 6 |

- 희귀도 배율 : 일반 1 / 드묾 2 / 희귀 5 / 전설 12
- 하룻밤에 같은 아이템을 20개보다 많이 팔면, 넘는 수량은 70% 가격
- 상인에게 사서 판매 상자에 팔면 손해가 되도록 검증 도구가 확인한다.

## 3. 코인

- `PlayerWallet` : 플레이어 코인 (최대 9,999,999), 변경 알림
- 생존 게이지 바로 아래에 코인 알약 표시
  - 코인이 늘거나 줄면 숫자가 올라가고, 알약이 커졌다 작아지며, 옆에 +/- 금액이 떠오른다.
- 음식 효과 알약은 코인 아래로 내렸다. (요리 생성 도구를 다시 실행해도 같은 위치)

## 4. 판매 상자 (SHIPPING BIN)

| 항목 | 내용 |
| --- | --- |
| 크기 · 재료 | 1.2 × 0.8m, 나무 8, 식물 섬유 4 |
| 보관 | 16칸 (기존 보관함 기능과 저장을 그대로 사용) |
| 판매 | 날짜가 바뀌면 (자정, 잠자기) 모든 판매 상자의 물건을 모아 판매 |
| 팔 수 없는 물건 | 상자에 그대로 남음 |
| 철거 | 비어 있을 때만 가능 |

- 보관함 창 제목 아래 안내 : `SELLS AT MIDNIGHT · 39 ITEMS · EST. +501 · 1 CAN'T SELL`
- 상호작용 안내 : `F - OPEN SHIPPING BIN | EST. +501 COINS`
- 물건이 들어 있으면 상자 옆 빨간 깃발이 선다 (우체통처럼).
- 판매하면 상자 위에 `SOLD 39` 글자, 화면 위 가운데에 판매 결과 알림을 6초 동안 표시한다.

```text
[코인]  SHIPPING BIN · SOLD OVERNIGHT · 1 NOT SOLD          +501
        39 ITEMS · BEST: 25 POTATO +235
```

- 잠자는 동안 판매되면 잠에서 깬 뒤에 알림을 보여준다.

## 5. 상인 가판대 (MARKET STALL)

| 항목 | 내용 |
| --- | --- |
| 크기 · 재료 | 2.6 × 1.8m, 나무 18, 식물 섬유 8, 돌 6 |
| 영업 시간 | 06:00 ~ 20:00 (그 외에는 상인이 사라지고 `OPENS AT 06:00`) |
| 상인 | 계산대 뒤에 서서 가까이 온 플레이어를 바라보고, 숨 쉬듯 움직인다. |

### 상인 재고

| 물건 | 가격 | 하루 재고 | 조건 |
| --- | --- | --- | --- |
| 계절 씨앗 | 6 ~ 14 | 12 | 봄 감자·딸기 / 여름 토마토 / 가을 호박 / 겨울 겨울무 |
| 사료 | 3 | 30 | 매일 |
| 미끼 | 2 | 20 | 매일 |
| 철광석 | 20 | 5 | 매일 |
| 붕대 | 18 | 3 | 매일 |
| 화살 | 2 | 20 | 50% 확률 |
| 낚싯대 | 60 | 1 | 25% 확률 |
| 작은 가방 | 450 | 1 | 15% 확률 |

- 재고는 날짜로 정해지므로 같은 날에는 항상 같고, 다음 날 새로 채워진다.

## 6. 상인 창

```text
[상인 얼굴] TRAVELING MERCHANT   [SPRING STOCK · 103 LEFT TODAY] [코인 501] [ESC]
[ BUY (8) ] [ SELL PRICES ]  TAB
[목록 : 아이콘 · 이름 · 남은 수 · 가격]   [상세 : 아이콘 · 설명 · 분류 · 재고]
                                        [ 6 COINS EACH / 가방 보유 수 ]
                                        [ - x1 + ]      [ BUY x1 · 6 ]
```

| 탭 | 내용 |
| --- | --- |
| BUY | 오늘 재고 사기, Shift + / - 로 10개씩, 품절·코인 부족·가방 가득 참이면 버튼에 이유 표시 |
| SELL PRICES | 판매 가격표 40종 (분류별 · 비싼 순), 제철 표시, 가방 보유 수와 예상 판매 금액 |

- Tab 키로 탭 전환, 목록은 마우스 휠로 넘긴다.
- `GameUIManager`에 상인 창 종류(`Shop`)를 추가하여 다른 창과 같은 입력 잠금 규칙을 쓴다.
- 영업 시간이 끝나면 상인 창이 자동으로 닫힌다.

## 7. 저장

```text
hasMarketData
market { coins, lastProcessedDay, stockDay,
         stock[] { itemId, remaining }, totalCoinsEarned, totalItemsSold }
```

- 판매 상자 안의 물건은 기존 보관함 저장을 그대로 사용한다.
- 같은 날 저장이면 남은 재고를 복원하고, 다른 날이면 새 재고를 만든다.
- 불러온 날짜를 처리한 날짜로 기록하여 불러오기만으로 판매가 일어나지 않게 했다.
- 87일차 이전 저장 파일은 코인 0으로 불러온다.
- 저장 검사 : 코인 범위, 음수 기록, 중복 재고 아이템, 음수 남은 수량

## 8. 모델과 아이콘

- 저폴리 모델 : 판매 상자 (뚜껑이 살짝 열린 나무 상자 + 코인 간판), 판매 상자 깃발, 상인 가판대 (줄무늬 차양 + 과일 상자), 떠돌이 상인 (챙 넓은 모자 · 흰 수염 · 큰 배낭)
- 가판대 과일은 늘어난 모델 안에서도 동그랗게 보이도록 실제 크기 기준으로 만들었다.
- UI 아이콘 : 코인, 가격표, 상자, 상인 얼굴 (모델을 찍어 만든 초상)

---

## 9. 기존 문제 수정

- 보관함 창을 처음 열면 왼쪽 가방 칸이 `New Text`와 흰 네모로 보이던 문제를 고쳤다.
  - 창이 켜질 때 가방 목록이 칸의 초기화(Awake)보다 먼저 그리기를 요청해서 생긴 문제로, 칸이 그릴 때 참조를 다시 확인하도록 했다.

## 10. 생성 도구와 테스트 메뉴

```text
Tools > Project U > Market > 1. Build Market Content (Prices + Shipping Bin + Stall + UI)
Tools > Project U > Market > 2. Validate Market Content
```

- 코인·가격표·상자 아이콘, 상점 모델, 판매 가격표와 상인 재고, 판매 상자 보관함 종류
- 판매 상자·가판대 Prefab과 건축 데이터, 건축 목록·건축물 저장 목록 연결
- 상점 관리자, 플레이어 지갑, 상인 창, 코인 표시, 판매 알림 생성
- 보관함 창 Prefab에 판매 상자 안내 문구 추가
- 코드로 상점 UI를 만드는 부분은 `MarketPopupUIBuilder`로 나누고 `UIBuildKit`을 함께 사용

```text
Tools > Project U > Market > Debug (Play Mode) >
  Give Market Kit / Give 500 Coins / Sell Shipping Bins Now / Refresh Merchant Stock / Advance One Day / Log Market
```

## 12. 남은 문제

- 판매 상자 뚜껑은 모델 크기 제한 때문에 조금만 열려 있다.
- 상인에게 직접 파는 기능은 없고, 판매는 판매 상자로만 한다.
- 가격은 고정 규칙이며, 수요에 따라 가격이 오르내리는 시장 변동은 없다.
