# Project U 개발 일지

## 82일차 : 낚시 도구·물고기 데이터와 낚시 시작 흐름 구현

### 1. 개발 목표

81일차로 농사 콘텐츠(79~81일차)를 마무리하고, 82일차부터 낚시 콘텐츠(82~83일차)를 시작하였다.
82일차에는 낚시에 필요한 데이터와 "던지기 → 입질 대기 → 입질 → 챔질"까지의 시작 흐름을 만들었다.
실제로 물고기를 끌어올리는 미니게임과 보상은 83일차에 연결한다.

이번 일차의 핵심 목표는 다음과 같다.

- 낚싯대·미끼·물고기 아이템과 물고기 출현 조건 데이터
- 거점 근처 연못(낚시터)과 낚시 시작 아이템 배치
- F키로 던지기, 입질 대기, 입질, 챔질, 찌 회수
- 이동·회피·전투 피격·건축 모드·낚싯대 해제 시 취소
- 낚시 중 공격·핫바 변경·아이템 사용·건축 진입 차단
- 괭이로 밭을 만들 때 지렁이 미끼 획득
- 83일차 미니게임 연결 지점(`BiteHooked`) 준비
- 추가 수정 : 근처 아이템 UI 재디자인

## 2. 데이터 구성

| 데이터 | 내용 |
| --- | --- |
| `FishData` | 물고기 ID, 등급, 결과 아이템, 물 종류, 시간대, 계절, 날씨, 필요 낚싯대 등급, 출현 가중치, 난이도 |
| `FishingRodData` | 낚싯대 아이템, 등급, 던지는 거리, 입질 시간 배율, 입력 시간 보너스 |
| `FishingRulesData` | 낚싯대 목록, 미끼, 미끼 입질 배율(0.6), 입질 대기 3~8초, 챔질 시간 1.5초, 던지기 스태미나 3 |
| `FishingSpot` | 낚시터 ID, 물 종류(강·호수·바다·동굴·얼음 구멍·숨은 장소), 반경, 수면 높이 |

## 3. 낚시 흐름

```text
낚싯대를 들고 물을 바라봄 → 던질 지점 고리 표시, "F - CAST LINE (BAIT 10)"
F → Casting   : 찌가 포물선으로 날아감 (스태미나 3 소비)
  → Waiting   : 3~8초 × 낚싯대 배율 × 미끼 배율 후 입질   | F = 찌 회수 (REELED IN)
  → Bite      : "!" 표시, 찌가 출렁임 (1.5초)              | F = 챔질 (미끼 1개 소비)
      시간 초과 → "IT GOT AWAY..." 후 다시 Waiting
  → Reeling   : BiteHooked 이벤트 (83일차 미니게임 시작점)
      연결된 미니게임이 없으면 "IT GOT AWAY..."로 종료
```

| 취소 조건 | 결과 |
| --- | --- |
| 이동 0.35m 초과, 회피 | LINE CUT |
| 전투 피격 | LINE CUT |
| 사망, 건축 모드, UI 열림, 낚싯대 해제 | 조용히 종료 |

- 굶주림·탈수·온도 피해로는 줄이 끊기지 않도록 `PlayerHealth`에 전투 피해 전용 `CombatDamaged` 이벤트를 추가하였다.
- 낚시 중에는 공격, 핫바 숫자키·휠, 아이템 사용, 건축 모드 진입을 막는다.
- 낚시 중에는 손에 든 낚싯대가 찌 방향으로 60° 기울고, 낚싯줄이 처지는 곡선으로 찌까지 이어진다.

## 4. 연못과 시작 아이템

| 항목 | 내용 |
| --- | --- |
| 위치 | 거점 동쪽 울타리 밖 (26, 0, 5) |
| 선정 조건 | 평평한 곳, 자원·아이템·거점 소품 회피, 몬스터 스폰 지점과 충분한 거리 |
| 스폰 거리 | 몬스터 최대 탐지 거리(14m) + 연못 테두리 + 여유 = 18.9m 이상 |
| 구성 | 연못 모델, 낚시터, 물 테두리 충돌체 16개, NavMesh 장애물 |
| 시작 아이템 | 기본 낚싯대 1개, 지렁이 미끼 10개 |

처음 테스트에서 연못이 몬스터 스폰 지점과 8.6m 거리에 만들어져 던지자마자 공격을 받았다.
스폰 지점은 별도 거리 조건으로 검사하도록 바꾸고, 가까운 기존 연못은 자동으로 다시 만들며, 검증 도구에서도 거리를 확인한다.

기타 획득 경로

- 작업대 제작 : 기본 낚싯대 (나무 2 + 식물 섬유 3)
- 괭이로 밭을 만들 때 30% 확률로 지렁이 미끼 획득

## 6. 추가 수정 : 근처 아이템 UI 재디자인

기존 패널은 스크롤 영역 크기가 0이고, 편집용 견본 줄(흰 사각형과 "ItemName")이 남아 있어 목록이 제대로 보이지 않았다.
또 게임 중에는 커서가 잠기고 휠이 핫바 전환이라 스크롤 목록을 사용할 수 없었다.

| 항목 | 변경 |
| --- | --- |
| 위치 | 오른쪽 열, 시간 패널 바로 아래 같은 너비(260) |
| 제목 | 줍기 아이콘 + NEARBY ITEMS + 종류 수 배지 |
| 한 줄 | 분류 색 아이콘(첫 글자) · 이름 / 분류 · 수량 / 거리 |
| 거리 | 2.2m 이내는 청록색으로 강조 |
| 목록 | 가까운 순 최대 6줄, 나머지는 "+N MORE" |
| 빈 목록 | 패널 숨김 |

```text
Tools > Project U > Art & UI > 6. Rebuild Nearby Items Panel
```

- UI 테마 도구를 다시 실행해도 같은 디자인으로 다시 만들어지도록 연결하였다.
- 무기 분류 대체 색상(적갈색)을 추가하였다.
