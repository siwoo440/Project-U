## 개발 목표

기존 원거리 무기와 탄약 시스템을 확장하여 활을 누르고 있는 시간에 따라 장력이 증가하도록 구현한다.

장전 중에는 예상 화살 궤적과 카메라 확대를 제공하고, 발사 시 현재 장력에 비례하여 화살의 피해량·속도·충격력이 달라지도록 구성한다.

---
## 주요 구현 내용

### 1. 활 장전 입력

- 마우스 왼쪽 버튼을 누르면 활 장전을 시작한다.
- 버튼을 유지하는 동안 장력이 최소에서 최대까지 증가한다.
- 버튼을 놓으면 현재 장력으로 화살을 발사한다.
- 근접 무기와 채집 도구는 기존 즉시 공격 방식을 유지한다.

### 2. 장력 기반 능력치 계산

- 장력 비율을 `0~1` 범위로 계산한다.
- 장력에 따라 최종 피해량을 계산한다.
- 장력에 따라 화살 발사 속도를 변경한다.
- 장력에 따라 충격력을 변경한다.
- 최대 장전 시간 이후에는 장력이 더 증가하지 않는다.

### 3. 화살 예상 궤적

- `LineRenderer`를 사용해 장전 중 예상 경로를 표시한다.
- 현재 장력과 화살 속도, 중력을 반영해 포물선을 계산한다.
- 지형이나 건축물과 충돌할 예상 위치에서 궤적 표시를 종료한다.
- 발사하거나 장전을 취소하면 궤적을 숨긴다.

### 4. 실제 화살 비행 연출

- 화살 Rigidbody에 중력을 적용했다.
- 화살이 현재 이동 방향을 바라보도록 회전을 갱신한다.
- `TrailRenderer`를 사용해 실제 화살 비행 흔적을 표시할 수 있도록 구성했다.
- 고속 화살이 Collider를 통과하지 않도록 연속 충돌 판정을 사용한다.

### 5. 활 조준 카메라

- 활 장전을 시작할 때 현재 Camera FOV를 저장한다.
- 장력이 증가할수록 FOV를 줄여 조준 화면을 확대한다.
- 발사 또는 취소 후 기존 FOV로 부드럽게 복구한다.
- 1인칭과 3인칭의 서로 다른 기본 FOV를 유지한다.

### 6. 활시위와 장전 화살 연출

- 장력 비율에 따라 활시위 중앙 Transform을 이동할 수 있도록 구성했다.
- 장전 중 손에 보이는 화살 오브젝트를 표시할 수 있도록 구성했다.
- 발사 또는 취소 시 활시위와 장전 화살을 초기 상태로 복구한다.

### 7. 탄약과 스태미나 처리

- 장전 시작 전에 탄약과 스태미나 보유 여부를 확인한다.
- 탄약과 스태미나는 실제 발사 순간에만 소비한다.
- 탄약 또는 스태미나가 부족하면 발사를 취소한다.
- 장전 취소 시 탄약과 스태미나를 소비하지 않는다.

### 8. 장전 취소 처리

다음 상황에서 진행 중인 활 장전을 안전하게 취소하도록 구성했다.

- Hotbar 선택 아이템 변경
- 인벤토리 또는 UI 진입
- 일시정지 메뉴 실행
- 건축 모드 진입
- 커서 잠금 해제
- 컴포넌트 비활성화
- Scene 전환

장전이 취소되면 다음 상태를 함께 복구한다.

- 예상 궤적
- 조준 카메라
- 활시위 위치
- 장전 화살 표시
- 현재 장력 상태

## 테스트 결과

- 짧게 당긴 화살이 낮은 피해량과 속도로 발사된다.
- 오래 당긴 화살이 높은 피해량과 속도로 발사된다.
- 최대 장력 이후 수치가 계속 증가하지 않는다.
- 장력에 따라 예상 포물선이 달라진다.
- 실제 화살이 중력의 영향을 받아 이동한다.
- 화살이 비행 방향에 맞춰 회전한다.
- 발사 후 Camera FOV가 기존 값으로 복구된다.
- 장전 취소 시 탄약과 스태미나가 소비되지 않는다.
- 탄약은 화살을 발사할 때 한 개만 소비된다.
- 기존 근접 3단 공격과 중복 피해 방지 기능이 유지된다.
- 도끼와 곡괭이를 사용한 기존 채집 기능이 유지된다.

## 완료 기준

활을 선택한 상태에서 공격 버튼을 누르면 장전이 시작되며, 유지 시간에 따라 장력이 증가한다.

장전 중에는 Camera가 확대되고 예상 화살 궤적이 표시된다. 공격 버튼을 놓으면 현재 장력에 비례한 피해량·속도·충격력을 가진 화살이 발사된다.

발사 또는 장전 취소 후에는 Camera, 궤적, 활시위와 장전 화살이 정상적으로 초기 상태로 복구된다.
