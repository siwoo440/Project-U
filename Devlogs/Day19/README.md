## 19일차: 낙하 피해 및 공통 피격 화면 효과 구현

### 개발 목표

플레이어의 낙하 거리에 따라 체력 피해가 발생하도록 기존 이동 시스템과 체력 시스템을 연결한다. 낙하·굶주림·탈수 피해가 발생할 때 공통으로 붉은 화면 효과를 표시하여 피해 상황을 명확하게 전달한다.

### 구현 내용

| 구분 | 구현 내용 |
|---|---|
| 착지 감지 | 플레이어 착지 시 실제 낙하 거리를 이벤트로 전달 |
| 안전 낙하 | 설정된 안전 거리 이하의 낙하 피해 제외 |
| 거리 비례 피해 | 안전 거리 초과분에 따라 낙하 피해 증가 |
| 최대 낙하 피해 | 치명적 낙하 거리 이상에서 최대 피해 적용 |
| 공통 피해 이벤트 | 실제로 감소한 체력 수치를 UI에 전달 |
| 피격 화면 효과 | 피해 발생 시 화면 전체에 붉은 효과 표시 |
| 효과 강도 | 최대 체력 대비 피해량에 따라 화면 효과 강도 조절 |
| 생존 피해 연동 | 굶주림과 탈수 피해에도 피격 효과 적용 |
| 사망 연동 | 치명적인 낙하 시 기존 사망 시스템 실행 |
| 재시작 연동 | Retry 후 체력과 생존 상태 정상 초기화 |
| HUD 위치 수정 | 허기와 갈증 HUD가 겹치지 않도록 위치 조정 |
| 드롭 재질 수정 | 공통 드롭 아이템에서 물병 전용 재질 제거 |

### 주요 변경 파일

| 파일 | 역할 |
|---|---|
| `PlayerMovement.cs` | 착지 시 낙하 거리를 전달하는 이벤트 추가 |
| `PlayerHealth.cs` | 실제 피해량을 전달하는 공통 피해 이벤트 추가 |
| `PlayerFallDamage.cs` | 낙하 거리 계산과 체력 피해 적용 |
| `DamageFlashUI.cs` | 피해량에 따른 붉은 화면 효과 처리 |
| `WorldItemDrop.prefab` | 공통 드롭 아이템의 전용 물병 재질 제거 |
| `20_Gameplay.unity` | 낙하 피해 컴포넌트와 피격 UI 구성 및 연결 |

### 개발 결과

- 짧은 낙하에서는 체력 피해가 발생하지 않는다.
- 안전 낙하 거리를 초과하면 체력 피해가 발생한다.
- 낙하 거리가 길어질수록 피해량이 증가한다.
- 치명적 낙하 거리 이상에서는 최대 피해가 적용된다.
- 착지 한 번마다 낙하 피해가 한 번만 적용된다.
- 낙하 피해가 체력 HUD에 정상적으로 반영된다.
- 피해 발생 시 화면에 붉은 피격 효과가 표시된다.
- 피해량이 클수록 피격 화면 효과가 강하게 표시된다.
- 굶주림과 탈수 피해에도 동일한 화면 효과가 적용된다.
- 치명적인 낙하로 체력이 0이 되면 사망 화면이 표시된다.
- 사망 후 플레이어 조작이 차단된다.
- Retry 후 체력과 생존 수치가 정상적으로 초기화된다.
- 허기와 갈증 HUD가 서로 겹치지 않는다.
- 일반 드롭 아이템에 물병 전용 재질이 표시되지 않는다.
