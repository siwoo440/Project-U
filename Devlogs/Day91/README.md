# Project U 개발 일지

## 91일차 : NPC 대화 창과 호감도 · 선물 · 관계 저장 구현

### 1. 개발 목표

90일차에는 NPC에게 말을 걸면 말풍선 한 줄만 나왔다. 이번에는 제대로 된 대화 창을 열고, 대화와 선물로 호감도를 쌓아 저장까지 되게 만든다.

- 초상 · 이름 · 호감도 막대 · 한 글자씩 나오는 대사가 있는 대화 창
- 대화하기 · 선물하기 · 거래 · 닫기 버튼
- 하루 첫 대화와 선물로 호감도 변화, 생일 선물 보너스
- 호감도 단계에 맞는 인사 · 대사
- 관계 기록 저장 · 불러오기 · 검사

---

## 2. 관계 기록 (`NpcRelationshipManager`)

NPC마다 아래 값을 기록한다.

| 값 | 내용 |
| --- | --- |
| `met` | 만난 적 있는지 (첫 만남 대사용) |
| `affinity` | 호감도 (0 ~ 최대값) |
| `lastTalkDay` | 마지막으로 대화한 날 (하루 첫 대화 점수용) |
| `lastGiftDay` · `giftsOnLastGiftDay` | 오늘 선물 횟수 (하루 1개 제한) |
| `receivedGiftCount` · `talkDays` | 받은 선물 수 · 대화한 날 수 |

| 행동 | 호감도 |
| --- | --- |
| 하루 첫 대화 | +1 |
| 매우 좋아하는 선물 | +8 |
| 좋아하는 선물 | +4 |
| 보통 선물 | +1 |
| 싫어하는 선물 | -5 |
| 매우 싫어하는 선물 | -10 |
| 생일에 좋은 선물 | 점수 3배 + 생일 대사 |

- 선물 점수는 89일차 선물 데이터(`NpcGiftProfile` · 선물 태그)를 그대로 쓴다.
- 호감도가 바뀌면 `AffinityChanged` 이벤트를 보낸다 (93일차 퀘스트 · 이벤트용).

---

## 3. 대사 고르기 (`NpcDialogueSelector`)

- 창을 열 때
  - 처음 만나면 자기소개 대사
  - 그 뒤로는 현재 관계 단계의 인사를 날짜마다 바꿔 가며 표시
- 대화하기
  - 나쁜 날씨 대사 → 계절 대사 → 관계 단계 대사 → 지금 단계까지의 잡담 → (신뢰 이상) 이벤트 대사 순서
  - 같은 날 다시 말을 걸면 이어지는 대사가 나온다.
- 선물 반응 : 선호도별 반응 대사, 생일에는 생일 전용 대사

---

## 4. 대화 창 (`NpcDialoguePopup`)

| 부분 | 내용 |
| --- | --- |
| 초상 | NPC 모델의 가슴 위를 찍은 128px 그림, 대표 색 테두리 |
| 머리글 | 이름 · 종족 · 직업, "호기심 · 호감도 25/100", 5칸 막대 |
| 대사 | 초당 42글자로 한 글자씩 표시, 클릭 · 스페이스 · 엔터로 전체 표시 |
| 버튼 | 대화하기 · 선물하기 · 거래 (거래 역할 NPC만) · 닫기 (ESC) |
| 선물 칸 | 가방 아이템 목록, 누르면 1개 선물 |

- 창은 핫바 위(아래에서 122px)에 놓는다. 처음엔 핫바를 가려서 위치를 올렸다.
- 창이 열려 있는 동안 NPC는 그 자리에 멈춰 플레이어를 바라본다 (`NpcAgent.SetTalking`).
  - 걷던 중이었으면 창을 닫은 뒤 다시 목적지로 걸어간다.
  - 멈출 때 미끄러지지 않도록 속도를 0으로 만든다.
- 플레이어가 4.5m 넘게 멀어지거나 NPC가 집에 들어가면 자동으로 닫힌다.
- 호감도가 바뀌면 머리 위에 "호감도 +8" 숫자를 띄운다.
- 관계 단계가 오르면 "미오와의 관계가 '호기심'(으)로 가까워졌어요!" 알림을 보여 준다. 이름 받침에 따라 '와/과'를 고른다.
- `GameUIManager`에 대화 창 종류(`Dialogue`)를 추가했다. ESC · 다른 창 열기로 닫힌다.
- 리첼이 가판대에 서 있으면 거래 버튼이 기존 상점 창을 연다. 안내 문구는 `F - 리첼 | 대화 · 거래`다.

## 5. 초상 만들기

- 아이콘 촬영 도구(`ItemIconRenderer`)에 선택 옵션 두 개를 추가했다. 기존 아이템 아이콘 결과는 그대로다.
  - 촬영 전 준비 : NPC 색 입히기
  - 보일 정점 고르기 : 키의 60% 위만 찍기
- NPC 7명의 초상을 `UI/Icons/Npc/PORTRAIT_이름.png`로 만들고 캐릭터 데이터의 초상 칸에 넣었다.

---

## 6. 저장 (`NpcSaveBridge`)

- `SaveGameData`에 `hasNpcData`와 `npc`(관계 목록)를 추가했다.
- 저장할 때 관계를 담고, 불러올 때 다른 상태보다 먼저 복원한다.
- 불러오기 전 검사
  - 호감도 범위 (0 ~ 100)
  - ID가 `char_`로 시작하는지
  - 같은 NPC 중복, 음수 값
- 91일차 이전 저장 파일은 관계가 없는 상태로 시작한다.

## 7. 생성 도구 · 테스트 메뉴

- `Tools > Project U > Build Content > 9. NPC Dialogue (Portraits + Popup + Relationships)`
  - 초상 7개 촬영 → 관계 관리자 추가 → 대화 창 생성 · `GameUIManager` 연결 → 검사
  - 여러 번 실행해도 결과가 같다.
- `Debug (Play Mode) > NPC`
  - Affinity +20 (Nearest NPC)
  - Give Loved Gift Item (Nearest NPC)
  - Reset All Relationships
- `Validate All Content`에 **NPC 대화** 검사를 추가했다 (초상 7개, 대화 창 연결 20곳, 관계 관리자).

## 9. 남은 문제

- 초상은 저폴리 모델을 찍은 그림이라 표정이 없다.
- 대화에 선택지는 아직 없다 (이벤트 · 퀘스트에서 붙일 예정).
- 거래 버튼은 가판대의 리첼만 된다. 밀키 · 드라비아 상점은 92일차에 연결한다.
