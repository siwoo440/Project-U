# Project U 개발 일지

## 100일차 : 확장 준비 - 특수 체형 NPC 모델과 새 구역 6곳

### 1. 개발 목표

지금 마을의 NPC 7명은 모두 사람 몸에 귀 · 꼬리 · 뿔만 다른 종족이었다. 캐릭터 시트의 나머지 28명에는 라미아 · 아라크네 · 켄타우로스 · 인어 · 크라켄처럼 **몸 모양 자체가 다른 종족**이 많고, 출신지도 해안 · 폐허 · 설산 · 사막 · 습지 · 숲처럼 섬에 없는 곳이다. 101일차부터 NPC를 7명씩 넣을 수 있도록 **몸 모양을 만드는 틀**과 **새 구역**을 먼저 준비했다. 오늘은 NPC를 마을에 배치하지 않는다.

- NPC 모델 틀 확장 : 하반신 9종 · 날개 5종 · 종족 부속 · 새 옷 5종 · 새 머리 2종
- 28명 전원의 모양 값 (캐릭터 시트의 종족 · 키 · 외형 설명 기준)
- 하반신 모양별 충돌체 · 길찾기 크기 · 걷기 속도 · 움직임 방식 · 물가 규칙
- 새 구역 6곳과 흙길 · NPC 일정 위치 15곳 · 섬 경계 벽 · 바다 · 지도 구역 이름 · 적 생성 지점 2곳
- 생성 메뉴(18번) · 검사

## 2. NPC 모델 틀 (`StylizedModelLibrary.NpcBodies.cs`)

모양 값 `NpcLook`에 **하반신(NpcBody)** 과 **날개(NpcWings)** 를 더했다. 하반신이 사람 다리가 아니면 치마 · 바지를 빼고 상반신만 입히고, 상반신을 올리거나(Lift) 몸 전체를 앞으로 옮겨(Shift) 몸 가운데가 NPC 기준점 근처에 오게 했다.

| 하반신 | NPC | 모양 |
| --- | --- | --- |
| 뱀 꼬리 | 세이라 (라미아) | 허리에서 내려와 뒤로 S자로 감기는 꼬리, 앞쪽 크림색 배 비늘 · 등 무늬 |
| 거미 다리 | 아라크네 | 머리가슴 · 큰 배 · 무늬 · 다리 8개 |
| 말 몸 | 켄시아 (켄타우로스) | 몸통 · 발굽 달린 다리 4개 · 꼬리 · 안장 담요 · 짐 가방 |
| 물고기 꼬리 | 마리엘 (인어) | 비늘 꼬리 · 꼬리지느러미 · 옆 지느러미 |
| 촉수 | 옥타비아 (크라켄) | 치마 모양 몸통 · 끝이 말린 촉수 8개 · 빨판 |
| 전갈 몸 | 사피라 | 마디진 몸 · 등 위로 휘는 독침 꼬리 · 다리 6개 · 집게 |
| 떠 있는 옷자락 | 세레나 (유령) | 반투명 안개로 흐려지는 치맛자락, 바닥에서 떠 있음 |
| 슬라임 | 미루 | 바닥에 퍼진 젤리 웅덩이 · 핵 결정, 몸 · 머리까지 반투명 |
| 보물상자 | 체스카 (미믹) | 뒤로 열린 상자 · 테두리 이빨 · 자물쇠 보석 · 혀 |

- **날개** : 새(에이리) · 박쥐(벨라모르타) · 요정(리리엘, 반투명) · 나비(루미나) · 벌(베아트리체, 2쌍)
- **종족 부속** : 늑대 · 여우 · 개 · 호랑이 귀와 꼬리, 엘프 · 요정 · 고블린 귀, 오니 · 서큐버스 뿔, 벌 · 나비 더듬이, 상어 지느러미 · 꼬리, 꽃 여인의 꽃과 덩굴, 개구리 연잎 모자, 안드로이드 관절 · 통신기, 마녀 모자 · 까마귀 깃털 망토, 뱀파이어 망토 · 송곳니
- **듀라한(레이븐나)** 은 머리를 왼손에 들고, 목 위에 푸른 영혼 불꽃이 있다.
- **피부 색** : 유령 · 뱀파이어는 창백한 색, 안드로이드는 도자기 색, 고블린은 녹색, 슬라임은 반투명
- **새 옷** : 갑옷 · 기모노 · 보디슈트 · 가슴 감싼 상의 · 고딕 드레스. **새 머리** : 양 갈래 · 포니테일
- 색 22개를 추가했다 (비늘 · 껍질 · 반투명 안개 · 젤리 · 날개 · 사암 · 폐허 돌 · 얼음 · 진흙 · 습지 물 · 산호 · 빛나는 버섯 · 룬 빛 등).
- 기존 7명 모델은 정점까지 전과 같다.

## 3. 하반신별 움직임 규칙 (`NpcBodyRules` · `NpcAgent`)

| 하반신 | 움직임 | 속도 배율 | 뒤쪽 몸 충돌체 |
| --- | --- | --- | --- |
| 사람 다리 | 걷기 (90일차와 같음) | 1.0 | - |
| 뱀 꼬리 · 물고기 꼬리 | 미끄러지기 (좌우 흔들림) | 0.9 | 뱀 꼬리 있음 |
| 말 몸 | 말 걸음 (크게 오르내림 · 앞뒤 기울기) | 1.3 | 있음 |
| 거미 · 전갈 · 촉수 | 여러 다리 (빠르고 작은 떨림) | 1.05 (촉수 0.75) | 있음 |
| 떠 있음 | 떠다니기 (멈춰 있어도 둥실) | 0.85 | - |
| 슬라임 | 젤리 (눌렸다 늘어남) | 0.75 | - |
| 보물상자 | 깡충 | 0.8 | - |

- 길찾기 반지름 · 몸 충돌체도 하반신 넓이에 맞춘다. 뒤로 긴 몸통은 모델 아래에 상자 충돌체를 더해 집 안에 들어가 모델이 숨으면 같이 꺼진다.
- **물가 NPC** : 인어 · 크라켄 · 상어족은 집 · 일터 · 일정 위치가 모두 물가여야 한다 (검사에서 확인, 오늘은 일정이 없어 대상 0개).
- 사람형 7명의 NPC Prefab 값(반지름 0.3 · 높이 1.7 · 속도 2.2)은 그대로다.

## 4. 새 구역 6곳 (`StylizedModelLibrary.Zones.cs` · `WorldZoneBuilder`)

섬(250 × 250m) 가운데 마을에서 흙길 6개로 바깥쪽 구역과 이었다. 길 시작에는 구역 이름 표지판이 있다.

| 구역 | 자리 | 내용 | NPC 위치 |
| --- | --- | --- | --- |
| 해안 · 부두 | 동쪽 끝 | 모래 해변 · 바다 · 물가 거품 · 나무 부두 · 나룻배 2척 · 어부 오두막 · 그물 건조대 · 등대 · 갯바위 | 해안 부두(물가) · 모래 해변 · 갯바위(물가) |
| 고대 폐허 | 북서쪽 | 돌바닥 · 기둥 고리 · 입구 아치 · 석상 · 무너진 도서관(책장 3개) · 지하 유적 문 · 검은 오벨리스크 · 보물 · 룬 결정 | 유적 입구 · 무너진 도서관 · 유적 광장 |
| 깊은 숲 | 서쪽 | 큰 나무숲 · 거대 버섯 · 요정 버섯 고리 · 빛나는 꽃밭 · 마녀 오두막 · 세계수 그루터기 | 요정의 버섯 고리 · 빛나는 꽃밭 · 마녀의 오두막 |
| 설산 기슭 · 사당 | 북쪽 | 눈밭 · 눈 덮인 전나무 · 얼음 바위 · 털가죽 천막 · 모닥불 · 가죽 건조대 · 붉은 문 · 석등 · 작은 사당 | 설원 야영지 · 산기슭 사당 |
| 붉은 사막 | 남동쪽 | 모래 · 사암 바위 · 모래 언덕 · 선인장 · 오아시스와 야자수 · 상인 천막 · 짐승 뼈 | 사막 오아시스(물가) · 사막 천막 |
| 안개 습지 | 남서쪽 | 진흙 · 습지 웅덩이 3개와 연잎 · 나무길 · 죽은 나무 · 갈대 · 기둥 위 관측 오두막 | 습지 나무길(물가) · 습지 오두막 |

- **바닥** : Terrain에 모래 · 눈 · 진흙 · 돌바닥 층 4개를 더해 8층으로 칠하고, 흙길 · 깊은 숲 바닥은 흙을 섞었다. 구역 · 흙길의 풀과 기존 나무 · 바위 · 풀 246개를 정리했다. 여러 번 칠해도 같은 결과가 되도록 기존 바닥 비율을 되살려 칠한다.
- **바다** : 섬 동쪽(x 100 이상)부터 섬 밖까지 바다와 바다 밑을 깔았다. 물가 벽으로 들어갈 수 없고, 부두 자리만 비워 부두 위를 걸을 수 있다. 바다는 NavMesh에서 뺐다.
- **섬 경계 벽** : 섬 네 끝에 보이지 않는 벽을 세워 섬 밖으로 떨어지지 않는다 (이전에는 막혀 있지 않았다).
- **지도 구역 이름** : 새 레이어 `MapLabel`에 구역 이름 6개와 "마을"을 두고, 지도 카메라에만 보이게 했다.
- **적 생성 지점** : 고대 폐허(근접형) · 안개 습지(원거리형) 2곳을 기존 지점 설정 그대로 복사했다.
- **NavMesh** : 구역 충돌체를 넣은 뒤 바로 다시 굽고 기존 NavMesh Asset에 덮어쓴다 (GUID 유지).
- 구역 건물 · 큰 소품은 `Building` 레이어라 NPC 위치가 건물 안에 들어가지 않았는지 검사된다.

## 5. NPC 위치 데이터

- `NpcLocations.csv`에 **Zone**(구역) · **Waterside**(물가) 칸을 더했다. 마을 위치 17곳은 `village`이고, 연못 선착장만 물가다.
- 새 구역 위치 15곳을 추가해 모두 32곳이 되었다.
- 8번 메뉴(NPC 마을 배치)는 마을 위치만 배치하고, 새 구역 위치는 18번 메뉴가 만든 지점을 NPC 관리자에 그대로 연결한다. 8번 메뉴를 다시 실행해도 새 구역 위치가 빠지지 않는다.

## 6. 생성 도구 · 검사

- `Tools > Project U > Build Content > 18. World Zones (Special NPC Bodies + Coast/Ruins/Forest/Snow/Desert/Swamp)`
  - NPC 데이터 갱신 → NPC 35명 모델 · 구역 소품 45종 생성 → 바닥 칠하기 · 풀과 기존 나무 정리 → 구역 소품 · 충돌체 → 경계 벽 · 바다 → 지도 이름 → NPC 위치 등록 → 적 생성 지점 → NavMesh 굽기 → Scene 저장 → 검사
  - 게임 Scene이 아니면 저장 여부를 묻고 게임 Scene을 연다. 여러 번 실행해도 같은 구성이 된다.
- `Validate All Content`에 **새 구역 · 특수 체형** 검사를 추가했다.
  - NPC 35명 모양 값 · 모델 Prefab · 머리 색, 모델 크기(높이 · 폭 · 길이 · 땅 아래로 들어가지 않는지), 길찾기 크기
  - 물가 NPC의 일정 위치가 물가인지
  - 구역마다 NPC 위치가 있는지, 위치가 NavMesh 위 · 건물 밖인지, 물가 위치가 물에서 3.5m 안인지, NPC 관리자에 연결됐는지
  - 마을 → 6개 구역 입구까지 길이 이어지는지, 바다가 걸을 수 없는지, 경계 벽 · 바닥 층 · 지도 이름 레이어 · 적 생성 지점 ID

## 8. 남은 문제

- 28명의 NPC Prefab · 마을 배치 · 일정은 아직 없다 (101일차부터 7명씩).
- 예전 "맵 꾸미기" 도구를 다시 실행하면 새 구역 바닥 칠하기와 나무 정리가 사라진다. 그때는 18번 메뉴를 다시 실행해야 한다.
- 새 구역에는 채집 자원 · 낚시터 · 구역 전용 아이템이 없다.
- 모래 언덕이 주변 모래보다 밝게 보인다.
- 섬 밖(바다 쪽 제외)은 여전히 빈 공간이며 원경 산으로 가린다.
- 빌드 보고서 경로(`Docs/Build`, git 제외)를 `Docs/Release`로 옮기는 일과 회사 이름 정하기가 남아 있다.
