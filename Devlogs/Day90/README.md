# Project U 개발 일지

## 90일차 : NPC 마을 배치와 시간·요일·날씨별 일정 이동 구현

### 1. 개발 목표

89일차에 만든 NPC 설정 카드(데이터)를 실제 게임에 올렸다. 알파 NPC 7명이 캠프 북쪽 마을에 나타나 일정표대로 걸어 다니게 하는 것이 목표다.

- NPC 7명의 저폴리 모델 (종족 특징 · 캐릭터 시트 색)
- 마을 건물과 NPC 집, 일정 위치 17곳 배치
- 시간 · 요일 · 계절 · 날씨에 맞는 계획을 골라 NavMesh로 걸어서 이동
- 밤에는 집 안으로 들어가고, 잠·불러오기 뒤에는 바로 제자리로
- 다가가면 이름표 · 안내 문구, 말을 걸면 짧은 말풍선 (대화 창은 91일차)
- 리첼이 87일차 떠돌이 상인 자리를 대신

## 3. 마을 배치 (캠프 북쪽)

| 건물 | 위치 | 비고 |
| --- | --- | --- |
| 선셋 카페 | 광장 서쪽 | 줄무늬 차양 · 바깥 카운터 · 간판 |
| 대장간 | 광장 동쪽 | 화로 · 모루 · 물통 · 무기 거치대 |
| 게시판 | 광장 북쪽 | 93일차 퀘스트용 |
| 리첼의 짐마차 | 광장 동쪽 끝 | 리첼의 잠자리 |
| NPC 집 4채 | 캠프 서쪽 · 동쪽 · 연못 옆 | 루네트 · 베로나 · 미오 · 미레유 |

- 건물마다 충돌체와 NavMesh 길막음(carving)을 넣어 NPC·적이 건물을 뚫고 가지 않는다.
- 건물 앞에 한글 이름판을 달았다.
- 건물 자리에 있던 나무·풀 2개를 숨겼다.
- 일정 위치 17곳 : 광장 · 밭 · 연못 선착장 · 가축 우리 · 상인 가판대 · 숲 가장자리 · 카페(손님) · 카페 카운터(밀키) · 대장간(손님) · 대장간 모루(드라비아) · 집 7곳
- 카운터 안쪽과 손님 자리를 나누기 위해 `loc_cafe_counter`, `loc_smithy_anvil` 위치를 추가하고 밀키·드라비아 일정을 바꿨다.

## 4. 일정 실행

| 구성 | 내용 |
| --- | --- |
| `NpcManager` | 0.25초마다 NPC별 오늘 계획(`SelectPlan`)과 현재 칸(`GetStop`)을 확인 |
| `NpcAgent` | 목적지로 NavMesh 이동, 도착 후 방향 · 플레이어 바라보기, 걷기 흔들림 · 숨쉬기 |
| `NpcLocationPoint` | 위치 ID · 집 여부 · 따라갈 건축물 · 자리 간격 |

- 같은 곳에 여러 NPC가 있으면 옆으로 1.2m씩 자리를 벌린다.
- 21시~6시에 집 일정이면 집 안으로 들어가 모델·충돌체를 숨긴다.
- 15분(게임 시간)보다 크게 시간이 건너뛰면(잠 · 불러오기 · 날짜 이동) 걷지 않고 바로 옮긴다.
- 길이 막혀 4초 동안 움직이지 못하면 목적지로 옮긴다.
- 위치가 플레이어 건축물을 따라가는 경우
  - 상인 가판대 : 가판대의 상인 자리 (없으면 광장 옆 기본 자리)
  - 가축 우리 : 가장 가까운 우리 앞 (없으면 미레유 집 옆 기본 자리)
- NPC 위치는 시간으로 정해지므로 따로 저장하지 않는다.

## 5. 다가가기 · 말 걸기

- 머리 위 이름표 : 이름 + 직업, 14m 안에서 보이고 카메라를 향한다.
- 안내 문구 : `F - 미오 | 낚시`, 걷는 중에는 `이동 중`
- F : 오늘 말 건 횟수에 따라 인사 → 날씨(나쁜 날)·계절 → 잡담 대사를 말풍선으로 표시
- 리첼이 가판대에 서 있으면 `F - 리첼 | 거래`로 기존 상점 창을 연다.
- 가판대에 리첼이 있으면 87일차 기본 상인 모델은 숨긴다 (`MarketStall`).

## 6. 생성 도구 · 테스트 메뉴

- `Tools > Project U > Build Content > 8. NPC Placement (Village + Models + Manager)`
  - 7번 NPC 데이터 갱신 → 모델 12종 → NPC Prefab 7개 → 마을 건물 · 위치 · NPC · 관리자 배치
  - 여러 번 실행해도 결과가 같다.
- `Debug (Play Mode) > NPC` : Log NPC Status · Snap All To Schedule · Skip 1 Hour (NPCs Walk) · Teleport Player To Village
- `Validate All Content`에 **NPC 마을 배치** 검사를 추가했다.
  - NPC 모델 · Prefab
  - 관리자 연결
  - 위치 17곳이 NavMesh 위에 있고 건물 안이 아닌지
  - NPC 7명 배치 · 상호작용 레이어

## 8. 남은 문제

- 밤에는 마을이 어둡다 (창문 불빛 · 가로등 없음).
- NPC는 플레이어가 지은 벽은 피하지 않는다 (마을 건물 · 연못은 피함).
- 말풍선은 대사 한 줄만 보여 준다. 선택지·호감도는 91일차에 붙인다.
- 나머지 28명은 데이터만 있고 배치되지 않았다 (101일차 이후).
