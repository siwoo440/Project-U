## 16일차: 허기 시스템 및 음식 섭취 기능 구현

### 개발 목표

플레이어의 생존 상태를 나타내는 허기 시스템을 추가하고, 핫바에 등록된 음식 아이템을 사용하여 허기를 회복할 수 있도록 구현한다.

### 구현 내용

| 구분 | 구현 내용 |
|---|---|
| 허기 수치 | 최대 허기와 현재 허기 수치 관리 |
| 허기 감소 | 플레이 중 시간에 따라 허기 자동 감소 |
| 허기 HUD | 현재 허기와 최대 허기를 게이지와 숫자로 표시 |
| 음식 데이터 | 음식 아이템별 허기 회복량 설정 |
| 음식 섭취 | 선택한 핫바의 음식을 마우스 오른쪽 버튼으로 사용 |
| 수량 감소 | 음식 섭취 성공 시 해당 아이템 수량 1개 감소 |
| 사용 제한 | 허기가 최대일 때 음식 소비 차단 |
| 입력 제한 | 인벤토리 팝업이 열린 동안 음식 사용 차단 |
| 아이템 구분 | 음식 이외의 도구와 재료 사용 차단 |
| 테스트 아이템 | 허기 회복 기능을 확인하기 위한 사과 아이템 추가 |

### 주요 변경 파일

| 파일 | 역할 |
|---|---|
| `PlayerHunger.cs` | 현재 허기 관리와 시간에 따른 허기 감소 |
| `HungerBarUI.cs` | 허기 게이지와 수치 표시 |
| `HotbarItemUse.cs` | 선택한 핫바 음식의 사용 처리 |
| `ItemData.cs` | 음식별 허기 회복량 데이터 추가 |
| `ItemData_Apple.asset` | 테스트용 사과 아이템 데이터 |
| `ApplePickup.prefab` | 월드에 배치되는 사과 획득 오브젝트 |
| `20_Gameplay.unity` | 허기 HUD와 테스트 아이템 배치 |

### 개발 결과

- 플레이 시간이 흐르면 허기가 자동으로 감소한다.
- HUD에서 현재 허기 상태를 확인할 수 있다.
- 음식마다 서로 다른 허기 회복량을 설정할 수 있다.
- 핫바에서 음식을 선택하고 마우스 오른쪽 버튼으로 섭취할 수 있다.
- 음식 섭취에 성공하면 허기가 회복되고 수량이 1개 감소한다.
- 허기가 가득 찬 상태에서는 음식이 소비되지 않는다.
- 인벤토리가 열려 있거나 음식이 아닌 아이템을 선택한 상태에서는 사용되지 않는다.
