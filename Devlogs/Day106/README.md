# Project U 개발 일지

## 106일차 : 수영 · 잠수 · 먼 바다 파도 · 바닷속 보물

### 1. 개발 목표

105일차에 만든 무인도 바다에 들어갈 수 있게 했다. 지금까지는 허리 깊이만 넘어도 해변으로 순간이동했다.

- 깊은 물에서는 **헤엄**치고, **C로 잠수**, **Space로 떠오른다**.
- 잠수하면 **숨**이 줄고, 다 떨어지면 체력이 깎인다.
- 섬에서 너무 멀어지면 **파도**가 섬 쪽으로 밀어낸다.
- 난파선 앞바다에 해초 · 산호와 **잠수해서 주울 물건**을 놓았다.

새 메뉴 : `Tools > Project U > Build Content > 23. Swimming & Diving (Player + HUD + Underwater)`

---

## 2. 수영 (`PlayerSwimming`)

| 상황 | 동작 |
| --- | --- |
| 얕은 물 (발 깊이 0.35m ~) | 걷기, 깊을수록 최대 62% 속도까지 느려짐 |
| 깊은 물 (발 깊이 1.25m ~) | 헤엄 시작, 머리와 어깨가 물 위 (발 깊이 1.15m에 뜸) |
| 발이 0.9m보다 얕아짐 | 다시 걷기 |
| 높은 곳에서 뛰어듦 | 헤엄으로 바뀌고 낙하 피해 없음 |

| 조작 | 속도 | 스태미나 (초당) |
| --- | --- | --- |
| 헤엄 | 2.6 | 1.5 |
| Shift 빠른 헤엄 | 4.2 | 12 |
| 물속 헤엄 | 2.3 | 2.5 |
| C 잠수 · Space 떠오르기 | 2.4 · 2.8 | - |
| 가만히 떠 있기 | - | 땅 위의 40%로 회복 |

- 수면에서 Space : 물 밖으로 살짝 뛰어올랐다 다시 들어감
- 지치면(스태미나 0) 60% 속도, 잠수 · 빠른 헤엄 불가, 수면으로 떠오름
- 물에 들어가면 젖음이 빠르게 100까지 오른다 (추운 날 수영하면 체온이 떨어짐)
- 헤엄 자세 : 몸을 앞으로 눕히고 좌우로 흔들며, 잠수 방향에 따라 머리를 숙인다. 손 도구는 숨긴다.
- 물보라 · 물결 · 물방울 효과, 첨벙 소리 (오디오 파일 없이 코드로 만든 소리)
- 헤엄치는 동안에는 공격 · 건축 · 낚시 · 밭일이 막히고, 줍기(F)와 대화는 된다. 잠수 중에는 먹기 · 마시기가 막힌다.

### 숨

- 100 → 물속에서 약 25초, 물 위에서 약 2.5초 만에 다시 가득 참
- 25% 아래 : "숨이 얼마 남지 않았어요!"
- 0 : 1.2초마다 체력 8 피해, "숨이 막혀요! 물 위로 올라가세요."

## 3. 파도 경계 (`IslandShoreGuard`)

- 105일차의 "깊으면 되돌림"을 없애고, 먼 바다 파도로 바꿨다.
- 섬 방향별 해안선 72개(5°마다)를 넣고, 해안선 밖 **70m부터** 섬 쪽으로 밀기 시작해 **110m**에서 가장 세다 (초당 5.5m, 가장 빠른 헤엄보다 빠름).
- 해안선 밖 145m를 넘거나 땅 밑으로 빠지면 안전한 곳으로 되돌린다 (안전장치).
- 석호는 섬 안쪽이라 파도 없이 헤엄칠 수 있다.

---

## 4. 물속 화면 (`UnderwaterCameraEffect`)

- 카메라가 물속이면 푸른 안개(약 20m) · 푸른 배경 · 화면 물빛 · 먹먹한 소리
- 물속에서는 비 · 눈 줄기를 숨긴다.
- 물 밖으로 나오면 날씨 안개를 그대로 되돌린다 (물속에 있는 동안 날씨가 바뀌어도 새 날씨로).
- 3인칭 카메라 : 잠수하면 플레이어 쪽으로 당겨 물속에 두고, 떠 있으면 수면 위에 둔다.
- 물속에서 올려다보는 수면 (뒤집은 바다 판) 추가

---

## 5. 화면 막대

- 핫바 왼쪽 **스태미나**(번개), 오른쪽 **숨**(물방울, 새 아이콘)
- 줄었을 때 · 헤엄칠 때만 보이고 가득 차면 사라진다. 숨이 25%보다 적으면 깜빡인다.
- 왼쪽 위 생존 막대 아래는 코인 · 음식 효과 · 의뢰 표시가 있어서 핫바 옆에 두었다.

---

## 6. 바닷속

- 새 모델 : 해초(물결치는 줄기 5개), 산호 무더기(가지 · 뇌 · 부채 산호 · 불가사리)
- 난파선 앞바다 : 해초 23 · 산호 12 (물 밖으로 나오지 않게 깊이에 맞춰 크기 조절), 바위 · 가라앉은 상자 · 나무통 7
- 잠수해서 주울 물건 9개 (저장 ID `island_dive_..`, 모두 파도 시작보다 안쪽)

| 물건 | 깊이 |
| --- | --- |
| 폐품 2 · 철광석 2 · 낚싯대 · 폐품 3 | 약 1.7 ~ 2.9m |
| 진주 · 화살 6 · 진주 | 약 4.7 ~ 9.1m |
| **작은 가방** | 약 9.2m (가장 깊은 곳) |
| 진주 (석호) | 약 2.3m |

- 22번 메뉴를 다시 실행해도 파도 · 물속 수면 · 바닷속이 같은 코드로 함께 만들어진다.

- 스태미나 · 숨 막대 연결 · 자리 · 아이콘, 물속 화면 효과

106일차 Play 점검 내용

- W로 바다에 걸어 들어가면 느려지다가 헤엄, 도구 숨김, 젖음 증가, 카메라는 물 위
- C 잠수 : 숨 감소 · 숨 막대 · 물속 화면 · 물방울 · 비 숨김 · 몸 기울기, Space로 떠오르면 안개 원래대로
- 숨 0 → 체력 피해, 물속 9m에서 작은 가방 줍기
- 먼 바다에서 Shift로 헤엄쳐도 파도에 밀림, 너무 멀면 되돌림
- 헤엄쳐서 뭍으로 나오면 걷기 · 도구 다시 보임 · 자세 원래대로
- 석호로 뛰어들어도 낙하 피해 없음, Space로 뛰어올랐다 다시 헤엄
- 헤엄 중 쓰러지면 해변에서 걷는 상태 · 숨 가득으로 부활, 저장 정상

- 105일차 "깊은 바다는 되돌림"을 "깊은 바다는 헤엄"으로, 새 구역 점검의 "석호에서 되돌림"을 "석호에서 헤엄"으로 바꿨다 (의도한 변경).
- 배치 모드 테스트는 커서가 잠기지 않아 F · 클릭 입력이 처리되지 않는다. 물속 줍기는 시선 대상이 맞는지 확인한 뒤 F 처리를 직접 불러 확인했고, 공격 · 건축 막힘은 헤엄 차단 조건만 확인했다.

## 9. 남은 문제

- 물속 줍기 · 헤엄 중 공격 막힘은 실제 화면에서 마우스 · F 키로 한 번 더 확인해야 한다.
- 잠수 물건은 한 번 주우면 끝이다 (매일 다시 생기는 조개 · 진주 자리는 나중에).
- 부두 위로 헤엄쳐 올라가는 사다리가 없다 (해변으로 나와야 함).
- `New Terrain.asset`이 약 73MB로 GitHub 권장 크기(50MB)를 넘는다.
