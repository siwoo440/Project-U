## 20일차: 붕대 회복 아이템 및 체력 회복 화면 효과 구현

---

### 개발 목표

붕대 아이템을 획득하고 핫바에서 사용하여 체력을 회복할 수 있도록 구현한다. 회복 성공 시 초록색 화면 효과를 표시하고, 최대 체력이나 사망 상태에서는 아이템이 소비되지 않도록 처리한다.

---

### 구현 내용

| 구분       | 구현 내용                            |
| -------- | -------------------------------- |
| 의약품 분류   | 기존 아이템 분류에 `Medicine` 추가         |
| 회복 데이터   | 아이템별 체력 회복량 설정 기능 추가             |
| 붕대 아이템   | 체력을 30 회복하는 붕대 데이터 생성            |
| 붕대 획득물   | 필드에서 획득할 수 있는 붕대 프리팹 생성          |
| 핫바 사용    | 선택한 붕대를 오른쪽 클릭으로 사용              |
| 체력 회복    | 붕대 사용 시 `PlayerHealth`를 통해 체력 회복 |
| 최대 체력 제한 | 체력이 최대치일 때 붕대 사용 및 소비 차단         |
| 사망 상태 제한 | 사망한 상태에서 붕대 사용 차단                |
| 아이템 소비   | 체력 회복에 성공한 경우에만 붕대 1개 소비         |
| 회복 이벤트   | 실제로 적용된 체력 회복량을 UI에 전달           |
| 회복 화면 효과 | 회복 시 화면 전체에 초록색 효과 표시            |
| 효과 강도    | 실제 회복량에 따라 화면 효과 강도 조절           |
| 인벤토리 표시  | 붕대 아이템의 분류를 `MEDICINE`으로 표시      |
| 기본 아이콘   | 아이콘이 없는 의약품을 초록색으로 표시            |

### 개발 결과

* 붕대를 필드에서 획득할 수 있다.
* 붕대가 인벤토리에 `MEDICINE` 분류로 표시된다.
* 붕대를 핫바에 배치할 수 있다.
* 선택한 붕대를 오른쪽 클릭으로 사용할 수 있다.
* 붕대 사용 시 체력이 30 회복된다.
* 체력이 최대 체력을 초과하지 않는다.
* 실제 회복에 성공한 경우에만 붕대가 1개 소비된다.
* 최대 체력에서는 붕대가 소비되지 않는다.
* 사망한 상태에서는 붕대를 사용할 수 없다.
* 회복된 체력이 Health HUD에 즉시 반영된다.
* 회복 시 초록색 화면 효과가 표시된다.
* 실제 회복량에 따라 화면 효과 강도가 달라진다.
* Retry 후 체력 회복과 아이템 사용 기능이 정상적으로 초기화된다.
* 음식은 허기만 회복한다.
* 음료는 갈증만 회복한다.
* 의약품은 체력만 회복한다.
