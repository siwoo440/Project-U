# Project U 개발 일지

## 94일차 : NPC 하트 이벤트(이야기 장면·선택지·특별 의뢰 연결) 구현

### 1. 개발 목표

93일차까지 NPC와 대화하고, 선물하고, 사고팔고, 의뢰를 주고받을 수 있게 됐다. 이번에는 관계가 깊어질 때마다 그 NPC의 **짧은 이야기 장면(하트 이벤트)** 이 열리게 만들었다. 대사 여러 줄 뒤에 선택지가 나오고, 고른 답에 따라 호감도가 달라진다.

- NPC 7명 × 관계 단계 3개(호기심 · 신뢰 · 애정) = 이벤트 21개
- 장소 · 시간 · 날씨 조건과 NPC 머리 위 이벤트 표시
- 대화 창 이벤트 모드 (대사 넘기기 · 선택지 버튼 · 결과 알림)
- 특별 의뢰는 그 NPC의 '신뢰' 이벤트를 본 뒤에 열림
- 저장 · 생성 메뉴(12번) · 검사

---

## 2. 이벤트 데이터

원본 `Data/Npc/Source/NpcEvents.csv` 한 개로 만든다. 생성 도구가 NPC마다 `Data/Npc/Events/NpcEvents_이름.asset`(`NpcEventBook`)을 만든다.

| 줄 종류 | 내용 |
| --- | --- |
| Event | 이벤트 ID · 관계 단계 · 장소 · 시간대 · 날씨 · 제목 · 보상 아이템 |
| Line | 이야기 대사 (NPC 또는 플레이어) |
| Choice | 선택지 문구 · NPC 대답 · 호감도 변화 (-10 ~ +15) |
| After | 선택 뒤 마무리 대사 |

| NPC | 호기심 | 신뢰 | 애정 |
| --- | --- | --- | --- |

## 3. 이벤트 관리자 (`NpcEventManager`)

| 규칙 | 내용 |
| --- | --- |
| 기다리는 이벤트 | 지금 관계 단계 이하의 아직 안 본 이벤트 중 가장 낮은 단계 1개 |
| 열리는 조건 | NPC가 그 장소에 도착해 있고, 시간대 · 날씨가 맞을 것 |
| 하루 제한 | NPC 한 명당 하루에 이벤트 1개 |
| 한 번만 | 본 이벤트는 다시 나오지 않음 |
| 완료 | 선택한 호감도 적용 · 만난 날 기록 · 보상 아이템 지급 · 본 이벤트 기록 |

- 조건이 맞으면 NPC 이름표 위에 분홍 `…` 표시를 띄운다. 의뢰 `?` · `!` 표시보다 먼저 보인다.
- 관계 단계는 91일차 관계 관리자에서 부작용 없이 읽는다 (`PeekStage`).
- 완료를 이벤트(`EventCompleted`)로 알린다.

## 4. 대화 창 이벤트 모드

```text
[초상] 미오 · 낚시꾼
"쉿! 지금 찌가 움직였다냥…!"
이야기 · 찌가 흔들린다냥                         [ 다음 ]  [ 닫기 ]

(마지막 대사 뒤)
[ 미안, 다음엔 조용히 할게. ]
[ 원래 못 잡은 거 아냐? ]
```

- 이벤트가 기다리는 NPC에게 말을 걸면 인사 대신 이야기가 시작된다.
- `다음` 버튼(스페이스)으로 대사를 넘기고, 마지막 대사에서 분홍 선택지 버튼이 나온다.
- 선택 뒤 NPC 대답과 마무리 대사가 나오고, 끝나면 `찌가 흔들린다냥 · 호감도 +5`처럼 결과와 관계 단계 알림을 보여 준다.
- 이벤트 중에는 선물 · 의뢰 · 거래 버튼을 숨긴다.
- 이벤트 도중 창을 닫으면 기록하지 않아서 다음에 다시 볼 수 있다.
- 대화 창에 선택지 버튼 3개(`LP_Choice0~2`)를 추가했다. 긴 문구는 글자 크기를 줄이고 줄을 바꾼다.

## 5. 특별 의뢰 연결 (93일차)

- 의뢰 CSV에 `RequiredEvent` 칸을 추가했다.
- 특별 의뢰 7개는 그 NPC의 '신뢰' 이벤트(`event_이름_trust`)를 본 뒤에만 게시판에 붙는다.
- 검사 : 필요한 이벤트가 같은 NPC의 이벤트인지, 이벤트 단계가 의뢰 단계보다 높지 않은지

## 6. 저장 (`NpcEventSaveBridge`)

```text
hasNpcEventData
npcEvents { seen[] { eventId, choiceIndex, day } }
```

- 관계 복원 뒤, 의뢰 복원 앞에 복원한다 (특별 의뢰 조건이 본 이벤트를 보기 때문).
- 데이터에서 사라진 이벤트 ID는 버린다.
- 94일차 이전 저장 파일은 본 이벤트 없이 시작한다.
- 검사 : 이벤트 ID(`event_`), 중복, 선택 번호, 날짜, 개수 상한(200)

## 7. 생성 도구 · 테스트 메뉴

- `Tools > Project U > Build Content > 12. NPC Events (Heart Scenes + Choices)`
  - 원본 CSV → 이벤트 묶음 7개 → 의뢰 데이터 갱신 → 한글 글꼴 확인 → 이벤트 관리자 → 대화 창 다시 생성(선택지 버튼) → 검사
  - 여러 번 실행해도 결과가 같다.
- `Debug (Play Mode) > NPC` : Log NPC Events · Reset Seen Events
- `Validate All Content`에 **NPC 이벤트** 검사를 추가했다.
  - NPC마다 호기심 · 신뢰 · 애정 이벤트가 1개씩 있는지
  - 이벤트 ID 규칙 · 중복, 대사 · 선택지(2~3개, 좋은 답 1개 이상), 호감도 범위
  - 장소가 있는지, 시간대가 올바른지
  - 일정상 그 시간에 그 장소에 실제로 있는 날이 있는지
  - 한글 글꼴, Scene 연결 (관리자 · 이벤트 묶음 · 대화 창 선택지 버튼)
- NPC 글꼴 글자 모음에 이벤트 대사를 포함했다.

## 9. 남은 문제

- 이벤트는 대화 창 안에서만 진행된다 (카메라 연출 · 캐릭터 움직임 · 효과음 없음).
- 선택지 결과는 호감도만 바뀌고 이후 이야기가 갈라지지 않는다.
- 이벤트 기록을 다시 볼 수 있는 앨범 · 도감이 없다.
- 결혼 · 동료 영입 같은 애정 단계 이후 내용은 아직 없다.
