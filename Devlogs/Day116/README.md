# Project U 개발 일지

## 116일차 : 동굴 (섬 밖 고정 동굴 맵 · 절벽 입구 12곳 · 횃불 · 광맥)

### 1. 개발 목표

섬에 **들어갈 수 있는 곳**이 없었다. 섬 곳곳 **12곳에서 들어가는 하나의 큰 동굴**을 만들었다.

- 동굴은 **따로 지은 고정 맵**이다. 어느 입구로 들어가도 같은 동굴이고, 동굴 안에서 걸어가 다른 입구로 나올 수 있다.
- 입구는 **절벽 아래에 박혀 있다** (땅을 올려 언덕 · 절벽을 만들었다).
- 동굴 안은 **깜깜하다.** 횃불을 만들어 손에 들어야 앞이 보인다.

이번에도 메뉴 없이 자동 적용으로 넣었다.

## 4. 절벽 (땅 고치기)

- 입구 뒤 땅을 **최대 13m 올려** 언덕 · 절벽을 만든다 (9m 안에서 솟아 올라갈 수 없다).
- 입구 앞 5m × 5.5m는 평평하게 남겨 걸어 들어갈 수 있다.
- **흙길 · 마을 · 구역 터는 덮지 않는다** (길이 묻히지 않도록 가까울수록 언덕을 낮춘다).
- 바뀐 땅에 맞춰 : 섬 바닥을 다시 칠하고(가파른 곳은 바위 무늬), 절벽 자리의 나무 209그루를 정리하고, 채집 나무 · 돌 32개를 새 땅 높이에 맞췄다.
- 입구 앞에는 바위 얼굴(굴 입구 모양)을 세워 굴처럼 보이게 했다.
- 다시 만들어도 같은 자리 · 같은 모양이 되도록, 자리 · 방향 · 높이는 모두 **원래 섬 높이 계산식**으로만 정한다.

## 5. 드나들기 · 저장 (`CaveManager` · `CavePortal`)

- 입구에서 `F` → "설산 광굴 들어가기" → 동굴 안 같은 입구방으로 옮겨진다. 동굴 안 사다리에서 `F` → 들어온 입구 옆으로 나온다.
- 들어간 입구는 **찾아낸 입구**로 기록된다 (저장됨).
- 동굴 안에서 저장하고 불러오면 **동굴 안 그 자리에서 시작**한다.
- 동굴 안에서는 섬 바다 경계(파도 되돌리기)를 잠시 쉰다.

## 6. 어둠과 횃불

- 동굴 안에서는 햇빛을 끄고, 환경광을 아주 어둡게, 검은 안개를 켠다 (밖으로 나오면 원래 낮 · 밤 · 날씨로 돌아온다).
- **횃불** 아이템 추가 : 맨손 제작 (나무 1 + 식물 섬유 2 → 2개). 손에 들면 따라다니는 불빛이 켜지고 불꽃처럼 밝기가 흔들린다.
- 화면 밝기 : 횃불 없이 0.034 → 횃불을 들면 0.075 (밖은 0.36 ~ 0.49).

## 7. 지도

- 동굴 안에서는 미니맵 · 전체 지도가 **동굴 바닥만** 그린다 (천장은 그리지 않아 방과 굴이 보인다).
- 섬 지도에는 동굴 입구 12곳의 이름이 표시된다.

116일차 Play 점검 내용

- 입구에서 F → 동굴 안(섬에서 2,600m 떨어진 동굴 맵)으로 이동 · 바닥에 제대로 섬
- 횃불 없이 깜깜함(0.034) → 횃불을 들면 밝아짐 · 동굴 안 지도에 방과 굴이 보임
- 비 오는 날 동굴 안은 젖지 않음 · 바다 경계가 끌어내지 않음
- 가까운 광맥 8.6m · 동굴 광맥 52개 (철 포함)
- 동굴 출구에서 F → 들어온 입구 옆(3.2m)으로 나옴 · 바깥 햇빛 복구
- 다른 입구(사막)로 들어가도 같은 동굴 · 가운데 큰 방까지 길이 이어짐
- 동굴 안에서 저장 → 불러오기 → 동굴 안에서 시작 · 찾아낸 입구 기억

점검 중 고친 것

- 굴 바닥 면이 아래를 보고 있어 길(NavMesh)이 생기지 않았다 → 면 방향을 안쪽으로 뒤집었다.
- 방 벽 구멍이 굴보다 넓어 하늘이 보였다 → 구멍 양옆 · 위를 굴 입구까지 메웠다.
- 절벽을 만들자 흙길이 묻히고 나무가 떴다 → 언덕이 길 · 마을 · 구역을 피하게 하고, 나무 · 채집물을 새 땅 높이에 맞췄다.
- 다시 만들 때마다 입구 자리가 조금씩 달라졌다 → 자리 · 방향을 원래 섬 높이 계산식으로만 정해 고정했다.
- 섬 NavMesh 검사가 동굴 NavMesh를 보고 오류를 냈다 → 섬 · 동굴 NavMesh를 이름으로 구분했다.

## 9. 남은 문제

- 동굴 안에는 아직 적이 없다 (120일차 예정).
- 광물이 돌 · 철뿐이다 (117일차에 구리 · 은 · 수정과 제련 · 도구 등급).
- 동굴 안 소리(물방울 · 울림)가 없다.
- 입구 바위가 조금 각져 보인다.
- 섬 Terrain 파일(73MB)이 이번 절벽 작업으로 한 번 다시 저장된다.
