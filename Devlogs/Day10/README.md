# 프로젝트 U 개발 일지

---

## 10일차 : 도구 타격 연출과 물리 아이템 구현

### 개발 목표

채집 행동의 시각적 반응을 추가하고, 자원 채집과 일반 상호작용의 입력을 분리했다. 도끼·곡괭이·목재·돌 획득 오브젝트에는 물리 효과를 적용해 월드에 자연스럽게 떨어지고 충돌하도록 구성했다.

---

### 주요 구현 내용

| 구분 | 구현 내용 |
|---|---|
| 도구 연출 | 도끼와 곡괭이 사용 시 휘두르기 애니메이션 실행 |
| 자세 복구 | 휘두르기 종료 후 도구가 기본 위치와 회전으로 복귀 |
| 자원 반응 | 나무와 바위의 외형이 타격 순간 축소됐다가 원래 크기로 복구 |
| 반응 범위 | Collider가 아닌 `VisualRoot`에만 크기 반응 적용 |
| 채집 입력 | 나무와 바위는 가까운 거리에서 마우스 좌클릭으로 채집 |
| 일반 상호작용 | 도끼·곡괭이 등 아이템 획득은 기존 F키 유지 |
| 입력 차단 | 인벤토리 등 UI 조작 중 좌클릭 공격 방지 |
| 연속 입력 제한 | 빠른 반복 입력으로 자원이 중복 획득되는 현상 방지 |
| 물리 효과 | 획득 오브젝트에 중력·충돌·회전 효과 적용 |
| 기존 기능 유지 | 도구 판정, 인벤토리, 핫바, 자원 소진 및 재생성 유지 |

---

### 입력 체계

| 대상 | 입력 | 안내 문구 |
|---|---|---|
| 나무 | 마우스 좌클릭 | `LMB - CHOP TREE` |
| 바위 | 마우스 좌클릭 | `LMB - MINE STONE` |
| 도끼 획득 | F | `F - PICK UP AXE` |
| 곡괭이 획득 | F | `F - PICK UP PICKAXE` |
| 목재 획득 | F | 기존 획득 문구 유지 |
| 돌 획득 | F | 기존 획득 문구 유지 |

`PlayerInteractor`에서 `Attack`과 `Interact` 입력을 각각 처리하도록 수정했다. `GatherableResource`는 좌클릭으로만 실행되며, `WorldItemPickup`과 그 밖의 일반 상호작용 대상은 F키로 실행된다.

---

### 추가 및 수정한 구성

| 대상 | 작업 내용 |
|---|---|
| `PlayerInteractor.cs` | 좌클릭 공격과 F키 상호작용 분리 |
| `GatherableResource.cs` | 중복 도구 휘두르기 제거 및 자원 반응 유지 |
| `ToolSwingAnimation.cs` | 도구 휘두르기와 기본 자세 복구 |
| `ResourceHitFeedback.cs` | 자원 외형의 타격 크기 반응 |
| Input Actions | `Attack` 좌클릭 입력 추가, `Interact` F키 유지 |
| 자원 프리팹 | 안내 문구와 타격 반응 참조 설정 |
| 획득 프리팹 | Rigidbody와 Box Collider 추가 |

---

### 물리 아이템 설정

다음 획득 오브젝트에 `Rigidbody`와 `Box Collider`를 적용했다.

- `AxePickup`
- `PickaxePickup`
- `WoodPickup`
- `StonePickup`

공통 설정은 중력 사용, Kinematic 해제, 보간 적용, 연속 충돌 감지 사용으로 구성했다. `Box Collider`의 `Is Trigger`는 해제해 바닥 및 다른 오브젝트와 충돌하면서도 기존 전방 탐지에 포함되도록 설정했다.

각 오브젝트의 루트는 `Interactable` 레이어를 유지하고, 외형 자식에 중복 Collider가 남지 않도록 정리했다. 아이템별 질량과 감쇠값은 외형과 움직임에 맞춰 조절했다.

---

### 동작 흐름

1. 플레이어가 좌클릭하면 장착 도구의 휘두르기 연출이 실행된다.
2. 전방 가까운 대상이 `GatherableResource`이면 도구 종류와 획득 가능 여부를 검사한다.
3. 조건을 만족하면 자원 타격 반응과 아이템 획득이 실행된다.
4. F키를 누르면 자원이 아닌 아이템 획득 및 일반 상호작용만 실행된다.
5. 월드의 획득 아이템은 중력에 따라 낙하하고 바닥과 충돌한다.

### 완료 결과

10일차 작업으로 채집 행동에 도구와 자원의 시각적 피드백을 추가했다. 자원 채집은 좌클릭, 아이템 획득과 일반 상호작용은 F키로 구분해 조작 목적을 명확하게 분리했다. 획득 오브젝트에는 물리 효과를 적용해 월드 배치와 생성 시 자연스럽게 낙하하고 충돌하도록 개선했다.
