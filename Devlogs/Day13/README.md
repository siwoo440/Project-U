# 프로젝트 U 13일차 개발 일지

---

## 개발 목표

3인칭 카메라의 거리를 플레이 중 조절할 수 있도록 줌 기능을 추가하고, 플레이어와 카메라 사이의 벽을 감지해 카메라가 지형을 관통하지 않도록 보완한다.

---

## 구현 내용

### 1. 카메라 줌 기능

- 마우스 휠 입력을 이용한 카메라 거리 조절
- 최소 거리 `3m`, 최대 거리 `10m` 제한
- `SmoothDamp`를 이용한 부드러운 거리 변화
- 커서 잠금이 해제된 상태에서 줌 입력 차단

### 2. 카메라 벽 충돌 보정

- 플레이어와 카메라 사이를 `SphereCast`로 검사
- 벽이 감지되면 카메라를 벽 앞 안전 거리로 즉시 이동
- 벽에서 벗어나면 기존 목표 거리까지 부드럽게 복귀
- 카메라의 부피를 고려한 충돌 반지름과 여유 거리 적용
- Trigger Collider 충돌 검사 제외

### 3. 충돌 레이어 분리

- 카메라 차단 구조물용 `CameraCollision` 레이어 추가
- `Default`, `CameraCollision` 레이어만 카메라 충돌 대상으로 설정
- `Player`, `Interactable`, `Water`, `UI` 레이어 제외
- 자원, 아이템 등으로 인한 불필요한 카메라 거리 변경 방지

### 4. 실행 상태 확인

- 현재 적용 중인 카메라 거리 표시
- 카메라 차단 여부 표시
- Inspector 설정값의 최소·최대 범위 자동 검증

---

## 주요 설정값

| 항목 | 설정값 |
|---|---:|
| 기본 카메라 거리 | `10m` |
| 최소 카메라 거리 | `3m` |
| 최대 카메라 거리 | `10m` |
| 휠 거리 변화량 | `1.5m` |
| 줌 보간 시간 | `0.08초` |
| 충돌 검사 반지름 | `0.3m` |
| 벽 여유 거리 | `0.15m` |

## 테스트 내용

- 마우스 휠로 카메라 거리가 `3~10m` 범위에서 변경되는지 확인
- 줌 동작과 벽 이탈 후 거리 복귀가 부드러운지 확인
- 커서 잠금 해제 상태에서 줌이 작동하지 않는지 확인
- 벽과 모서리에서 카메라가 지형을 관통하지 않는지 확인
- 벽이 감지되면 카메라가 플레이어 쪽으로 즉시 이동하는지 확인
- 자원과 아이템이 카메라 충돌 보정에 영향을 주지 않는지 확인
- 기존 이동, 점프, 경사면, 낙하, 스태미나 기능이 유지되는지 확인
- 인벤토리, 핫바, 장착, 채집 기능이 정상 작동하는지 확인
- Console의 빨간색 Error가 없는지 확인

---

## 완료 결과

카메라 거리를 플레이 상황에 맞게 조절할 수 있게 되었으며, 플레이어와 카메라 사이에 벽이나 지형이 있을 때 카메라 위치가 자동으로 보정되도록 구현했다. 카메라 충돌 대상을 레이어로 분리해 월드 아이템으로 인한 불필요한 거리 변경을 방지했고, 기존 플레이어 이동 및 상호작용 기능도 유지했다.
