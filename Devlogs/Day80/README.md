# Project U 개발 일지

## 80일차 : 밭 경작·씨앗 심기·물주기 구현

### 1. 개발 목표

79일차에 준비한 씨앗·작물·밭·농사 도구 데이터를 실제 플레이에서 사용할 수 있도록 구현하였다.

기획서 80일차 완료 기준:

```text
거점 구역에 밭을 설치하고 준비한 씨앗을 심으며
물 공급 상태를 칸별 데이터와 화면에서 확인할 수 있다.
```

이번 일차의 핵심 목표는 다음과 같다.

- 밭 한 칸의 작물·물 상태 데이터 추가
- 날짜·계절·날씨·물뿌리개를 관리하는 밭 관리자 추가
- 괭이로 거점 땅을 밭으로 만드는 경작 기능 추가
- 씨앗 심기와 계절 제한 추가
- 물뿌리개 물주기, 우물에서 물 채우기 추가
- 비·폭풍인 날 자동 물주기 추가
- 밭 상태 안내 문구, 대상 칸 표시, 물뿌리개 게이지 추가
- 칸별 상태 저장·불러오기 추가
- 마우스 휠 핫바 칸 이동 추가

---

## 2. 전체 구조

```text
PlayerInteractor (F키)
├─ 시선 앞 상호작용 대상 (우물, 아이템 등)
└─ 없으면 FarmingToolController에 앞 칸 대상 요청
   ├─ 밭이 있으면 → FarmPlot
   └─ 괭이를 들었고 경작 가능한 칸 → FarmTillTarget

FarmManager (Scene)
├─ 날짜 / 계절 / 날씨 조회
├─ 물뿌리개 남은 물
├─ 비·폭풍 자동 물주기
└─ 활성 밭 목록

FarmPlot (밭 Prefab)
├─ 상태 / 작물 / 심은 날 / 성장 일수 / 물 받은 날
├─ 단계별 작물 외형, 젖은 흙 외형
└─ 저장 데이터 생성·적용
```

## 3. 밭 한 칸 `FarmPlot`

| 필드 | 설명 |
| --- | --- |
| `state` | Empty / Growing / Ready / Withered |
| `currentCrop` | 심은 작물 데이터 |
| `plantedDay` | 심은 날짜 |
| `grownDays` | 물을 받아 성장한 일수 (81일차에서 증가) |
| `lastWateredDay` | 마지막으로 물 받은 날짜 (-1은 없음) |
| `lastGrowthDay` | 성장 계산을 마지막으로 처리한 날짜 |

- `InteractableBase`를 상속하여 기존 F키 상호작용과 안내 UI를 그대로 사용한다.
- 오늘 물을 받은 칸은 `WetSoil` 외형을 켜고, 작물 단계에 맞는 외형을 `CropAnchor` 아래에 표시한다.
- 안내 문구는 상태가 바뀔 때만 다시 만든다.
- 작물이 있는 밭은 건축 모드에서 철거되지 않는다 (`IBuildRemovalGuard`).

## 4. 손에 든 아이템별 동작

| 손에 든 것 | 대상 | 동작 |
| --- | --- | --- |
| 괭이 | 거점 안 빈 땅 | 밭 만들기 (스태미나 4) |
| 괭이 | 빈 밭 | 밭 제거 |
| 괭이 | 시든 작물 | 작물 정리 |
| 괭이 | 자라는 작물 | 상태만 표시 (실수 방지) |
| 씨앗 | 빈 밭 | 심기 (씨앗 1개 소비) |
| 씨앗 | 계절이 맞지 않는 작물 | `PUMPKIN GROWS IN AUTUMN` 안내 |
| 물뿌리개 | 밭 | 물주기 (하루 1회, 물 1 소비, 스태미나 2) |
| 물뿌리개 | 우물 | 물뿌리개 가득 채우기 |

안내 문구 예시:

```text
F - TILL SOIL
CAN'T TILL | SPACE BLOCKED
F - PLANT POTATO
POTATO | DAY 0/3 | NEEDS WATER
F - WATER (9/10)
F - REFILL WATERING CAN (9/10)
```

## 5. 괭이 경작

`FarmingToolController`가 플레이어 앞 1.3m 지점을 대상 칸으로 계산한다.

```text
Camera 수평 방향 → 앞 지점 → 건축 그리드 칸 중앙
→ 지형·경사·장애물 검사 → 초록/빨강 칸 표시 → F키로 밭 설치
```

`BuildPlacementController`에 건축 모드 밖에서 쓰는 공개 기능을 추가하여
건축 모드와 같은 그리드·지형·충돌 검사를 재사용하였다.

| 추가 기능 | 설명 |
| --- | --- |
| `TryResolveGroundStructure` | 타일 중앙 지면 설치 가능 여부 계산 |
| `TryPlaceGroundStructure` | 재료 소비 후 설치 |
| `HasBlockingOverlap(recipe, …)` | 건축 데이터를 매개변수로 받도록 정리 |
| `TryRemoveIngredients` | 기존 설치와 공용 재료 소비 |

`BuildRecipeData`에 필요 도구(`requiredTool`)를 추가하고,
밭은 괭이가 있어야 건축 모드에서도 설치되도록 하였다 (`NEED HOE`).
`PlayerInventory.HasTool`로 도구 보유 여부를 확인한다.

## 6. 물주기와 날씨

| 상황 | 처리 |
| --- | --- |
| 맑음·흐림 | 물뿌리개로 직접 물주기 |
| 비·폭풍 | 모든 밭 자동 물주기 |
| 비·폭풍 중 새로 만든 밭·심은 작물 | 바로 물 받은 상태 |
| 날짜 변경 | 젖은 흙 표시 갱신 |
| 물뿌리개 물 없음 | `WATERING CAN EMPTY | REFILL AT THE WELL` |

검증 중 수면처럼 시간을 건너뛸 때 지나간 중간 날씨(잠깐 온 비)까지
그날 물을 준 것으로 처리되는 문제를 발견하였다.
날씨 변경 이벤트는 표시만 해 두고, `LateUpdate`에서 **최종 날씨**로만 판단하도록 수정하였다.

## 8. 저장·불러오기

`SaveDataSchema`에 밭 데이터를 추가하였다.

```text
hasFarmData
farm
├─ wateringCanWater
└─ plots[]
   ├─ structureId
   ├─ state
   ├─ cropId
   ├─ plantedDay / grownDays
   └─ lastWateredDay / lastGrowthDay
```

- `FarmSaveBridge`가 건축물 복원 뒤 건축물 ID로 칸 상태를 적용한다.
- 저장 이후 새로 만든 밭은 빈 밭으로 초기화한다.
- 80일차 이전 저장 파일은 `hasFarmData = false`로 현재 상태를 유지한다.
- `SaveDataValidator`에 ID 중복, 상태 값, 상태·작물 ID 일치, 날짜 값 검사를 추가하였다.
- `SaveSchemaValidator` 예제에 밭 데이터를 추가하였다.

## 9. 마우스 휠 핫바 이동

휠 핫바 이동은 기존에 구현되어 있지 않았고, 휠은 3인칭 Camera 줌에만 사용되고 있었다.

| 입력 | 동작 |
| --- | --- |
| 휠 위 | 1번 방향으로 한 칸 (1번 → 8번 순환) |
| 휠 아래 | 8번 방향으로 한 칸 (8번 → 1번 순환) |
| Shift + 휠 | 3인칭 Camera 줌 |

- UI가 열려 커서가 풀린 상태, 건축 모드에서는 휠 이동을 막는다.
- Ctrl은 회피, Alt는 커서 모드에 사용 중이어서 줌 보조키는 Shift로 정하였다.
- 터치패드 연속 입력을 막기 위해 한 칸 이동 후 짧은 간격을 둔다.

## 10. 생성 도구 확장

`Tools > Project U > Farming > 1. Build Farming Content`가 80일차 설정도 함께 처리한다
(`FarmingGameplaySetup`).

- 밭 Prefab에 `FarmPlot` 연결
- 밭 건축 데이터 필요 도구 = 괭이
- `FarmManager` 생성과 시간·날씨·Registry·규칙 연결
- 플레이어에 `FarmingToolController` 추가, `PlayerInteractor` 연결
- 대상 칸 표시 오브젝트와 반투명 재질 생성
- 우물에 `WaterSource` 추가, 상호작용 레이어 적용
- 물뿌리개 게이지 UI 생성, 핫바 이름 칸 정리
- 검증 메뉴에 위 항목 검사 추가

## 12. 정리

80일차에는 괭이로 밭을 만들고, 씨앗을 심고, 물뿌리개로 물을 주는 농사 기본 흐름과
칸별 상태 저장을 구현하였다.

81일차에는 날짜가 지날 때 물·계절·날씨 조건에 따라 작물이 자라고,
다 자란 작물을 수확해 아이템을 얻는 기능을 구현한다.
