# Project U 개발 일지

---

## 40일차 : 날씨 시각·음향 효과 구현

### 개발 목표

39일차에 구현한 기본 날씨 순환 시스템과 연동하여 날씨별 시각 효과와 환경음을 적용한다. 날씨가 변경될 때 파티클, 안개, 태양광 밝기, 반복 음향이 자연스럽게 전환되도록 구성한다.

### 구현 내용

#### 1. 날씨 효과 관리 시스템

- `WeatherEffectsController` 추가
- `WeatherCycle.WeatherChanged` 이벤트와 날씨 효과 연동
- 날씨별 안개 색상과 밀도 적용
- 날씨별 태양광 밝기 배율 적용
- 날씨 변경 시 환경 효과의 부드러운 전환 구현
- 기존 낮·밤 조명 계산 이후 날씨 밝기 배율 적용

#### 2. 비·눈 파티클

- 플레이어를 따라다니는 날씨 효과 루트 구성
- 비 전용 파티클 시스템 추가
- 눈 전용 파티클 시스템 추가
- 비와 폭풍의 빗방울 발생량 분리
- 눈송이의 느린 낙하와 좌우 흔들림 구현
- 날씨 종료 시 기존 파티클이 자연스럽게 사라지도록 처리

#### 3. 날씨 환경음

- 날씨 전용 `AudioSource` 추가
- 비, 바람, 폭풍 반복 음향 연결
- 흐림과 눈에 바람 환경음 적용
- 비와 폭풍에 각각 다른 환경음 적용
- 날씨 전환 시 기존 음향 감소 후 새 음향 증가
- 맑은 날씨에서 날씨 환경음 정지

#### 4. 날씨별 효과

| 날씨 | 적용 효과 |
|---|---|
| 맑음 | 파티클·안개·환경음 제거, 기본 밝기 적용 |
| 흐림 | 옅은 회색 안개, 태양광 감소, 약한 바람 적용 |
| 비 | 빗방울, 회색 안개, 태양광 감소, 빗소리 적용 |
| 눈 | 눈송이, 밝은 안개, 태양광 감소, 바람 적용 |
| 폭풍 | 강한 빗방울, 짙은 안개, 큰 태양광 감소, 폭풍음 적용 |

#### 5. 날씨 테스트 기능

- 특정 날씨를 즉시 적용하는 `ForceWeather` 기능 추가
- 컴포넌트 메뉴에서 맑음·흐림·비·눈·폭풍 강제 적용 가능
- 강제 변경 직후 날씨 HUD 갱신
- 자동 날씨 변경과 동일한 이벤트 처리 구조 사용

### 테스트 결과

- 맑음에서 비·눈 파티클과 날씨 환경음이 제거됨
- 흐림에서 옅은 안개와 바람 소리가 적용됨
- 비에서 빗방울, 안개, 빗소리가 적용됨
- 눈에서 눈송이, 밝은 안개, 바람 소리가 적용됨
- 폭풍에서 강한 비, 짙은 안개, 폭풍 소리가 적용됨
- 날씨 변경 시 안개, 밝기, 환경음이 부드럽게 전환됨
- 파티클 발생 영역이 플레이어 이동을 따라감
- 낮·밤 변화 중에도 날씨 밝기 배율이 정상 적용됨
- 자동 날씨 변경 시 시각·음향 효과가 함께 변경됨
- 강제 날씨 테스트 기능이 정상 작동함
- Unity Console 컴파일 오류 없음

### 개발 결과

기존 날씨 데이터가 실제 게임 화면과 환경음에 반영되도록 확장했다. 각 날씨는 서로 다른 파티클, 안개, 밝기, 음향을 사용하며 날씨가 바뀔 때 효과가 갑자기 끊기지 않고 자연스럽게 전환된다.

현재 날씨 효과는 실내 여부와 관계없이 플레이어 주변에 발생한다. 실내·지붕 판정과 캐릭터 젖음 처리는 다음 개발 단계에서 구현한다.

### 다음 개발 방향

41일차에는 실내·지붕·야외 판정 시스템을 구현한다. 플레이어가 지붕 아래나 실내에 들어가면 비와 눈 파티클 및 날씨 환경음을 조절하고, 야외에서 비나 폭풍에 노출되면 젖음 수치가 증가하도록 확장한다.
