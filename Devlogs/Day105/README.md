# Project U 개발 일지

## 105일차 : 2km 무인도 지형 · 사방 바다 · 난파선 해변 시작

### 1. 개발 목표

지금까지의 맵(약 250m 땅 + 가장자리 벽)을 **하나의 큰 무인도**로 바꾸는 첫날이다.

- Terrain을 **2048m × 2048m**로 키우고, 사방을 바다로 둘러쌌다.
- 마을은 섬 한가운데에 그대로 두고, 해안까지 넓은 땅이 생겼다.
- 플레이어는 이제 **남쪽 해변의 난파선 옆**에서 게임을 시작한다.
- 너무 깊은 바다로 걸어 들어가면 해변 쪽으로 되돌려 보낸다 (수영은 106일차).

새 메뉴 : `Tools > Project U > Build Content > 22. Island Terrain (Sea + Beaches + Shipwreck Start)`

---

## 2. 섬 지형 (`IslandTerrainBuilder`)

| 항목 | 값 |
| --- | --- |
| Terrain 크기 | 2048m × 2048m (높이 해상도 2049, 색칠 해상도 2048) |
| 해안선 | 반지름 약 800m (756 ~ 844m, 방향마다 조금씩 다름) |
| 마을 평지 | 가운데 ±130m, 높이 0 (예전 마을 · 구역 그대로) |
| 북쪽 산 | 가장 높은 곳 184m, 능선 무늬 |
| 수면 | -0.5m |
| 석호 | 동쪽 부두 옆 물웅덩이 (걸을 수 없음) |

- 높이는 "마을 평지 → 들판 → 해변(45m 폭) → 얕은 물 → 깊은 바다" 순서로 부드럽게 이어진다.
- 섬 바닥 색 : 해변 모래 · 바다 밑 · 산 위 눈 층을 새로 만들고, 바위 · 오솔길을 칠했다. 해변과 물속 풀은 지웠다.
- 예전 원경 산 16개는 지웠다 (이제 섬의 진짜 산이 그 역할을 한다).
- 바다 : 6km 넓이의 수면 판 + 먼 바다 밑 판
- 카메라가 먼 곳까지 보이도록 거리 2600m, 안개 350 ~ 2400m

## 3. 난파선 해변 시작

| 항목 | 위치 |
| --- | --- |
| 난파선 | (-9, -794) 물가, 비스듬히 기운 배 |
| 시작 위치 | (0, -762) 해변 |
| 부활 위치 | 시작 위치 조금 안쪽 |
| 마을까지 | 오솔길 약 760m, 가장 가파른 곳 12° |

- 새 모델 2개 : 부서진 난파선(13m 배 · 부러진 돛대 · 찢어진 돛 · 밧줄 · 등불 · 상자), 떠밀려 온 널빤지
- 해변 소품 25개 : 야자수 · 바위 · 통나무 · 상자 · 통 · 널빤지
- 떠밀려 온 물건 9개 : 저장해도 다시 생기지 않도록 고정 ID(`island_wreck_00_...`)를 붙였다.
- 플레이어 · 기본 부활 위치 · 카메라를 해변으로 옮겼다. 예전 저장은 저장된 위치(마을)에서 이어진다.

## 4. 바다 경계 (`IslandShoreGuard`)

- 발이 물에 1.1m보다 깊이 잠기면 마지막으로 안전했던 곳으로 되돌린다.
- 안내 문구 : "물이 너무 깊어요. 더 나갈 수 없어요."
- 섬 가장자리 벽 · 바다 벽은 더 이상 만들지 않는다. 석호만 NavMesh에서 뺐다.

## 5. 예전 메뉴 정리

- 18번 구역 메뉴 : 섬 지형이면 해안 구역의 옛 바다 판 · 가장자리 벽을 만들지 않고 부두 · 배만 만든다.
- 해안 모래 칠하기를 석호 주변으로만 줄였다 (동쪽 절반이 모래가 되던 문제).
- 장식 메뉴 : 섬 지형에서는 칠하는 범위를 가운데 250m로 제한하고 원경 산을 만들지 않는다.
- NavMesh는 가운데 280m 범위만 굽는다 (섬 전체는 107일차).
- 전체 콘텐츠 검사에 "무인도" 항목 추가

## 8. 남은 문제

- `New Terrain.asset`이 약 76MB가 되었다 (GitHub 50MB 경고). 필요하면 색칠 해상도 1024 또는 Git LFS로 줄인다.
- 섬 안쪽 넓은 땅이 아직 비어 있다 (나무 · 바위는 108일차).
- NavMesh가 가운데만 있어서 NPC · 적은 아직 바깥으로 나가지 않는다.
- 해안 구역(부두)은 아직 석호 옆에 있다. 진짜 동쪽 해변으로 옮기는 건 107일차.
