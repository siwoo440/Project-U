## 112일차 : 5차 NPC 7명 등장 (마지막 이웃 · 새 집 4채 · 동료 후보 · 길찾기 수정)

### 1. 개발 목표

아직 섬에 나오지 않은 마지막 NPC 7명을 **5차**로 등장시켰다. 이제 캐릭터 시트의 **35명이 모두 섬에 산다**. 방식은 110일차(4차)와 같고, 이번부터는 메뉴 대신 **자동 적용**으로 넣었다.

## 5. 길찾기 수정 (`WorldZoneBuilder.RebakeNavMesh`)

- 문제 : NavMesh를 다시 구울 때 집에 서 있는 NPC 몸이 길에 구멍을 냈다. 물가에 선 옥타비아 자리는 1.5m 안에 걸을 수 있는 곳이 없어 검사에서 걸렸다.
- 해결 : 굽는 동안 NPC를 잠시 숨긴다 (굽기가 끝나면 다시 보임). 앞으로 모든 NavMesh 굽기에 적용된다.

## 6. 자동 적용

- `ProjectUAutoContent`에 `112-wave5-cast`(구역 · 배치 · 초상 · 대화 창 · 동료)를 추가했다.
- 모든 데이터 · 코드 · 점검을 끝낸 뒤 **마지막에** 항목을 넣었다 (먼저 넣으면 열려 있는 Unity가 덜 된 상태로 한 번 실행하고 '적용함'으로 기록해 버린다).

## 8. 남은 문제

- 5차 7명은 아직 의뢰 · 하트 이벤트가 없고, 동료 후보 3명은 잠겨 있다.
- 한낮 광장에 NPC가 많이 모인다 (자리는 넓게 퍼짐).
- 35명이 된 뒤 실제 화면 프레임은 창 있는 실행에서 확인이 필요하다.
