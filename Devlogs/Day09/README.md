# 프로젝트 U 9일차 개발 일지

---
## 개발 목표

기존 인벤토리·핫바·반복 채집 시스템에 도구 아이템과 장착 기능을 연결했다.

플레이어가 핫바에서 도끼와 곡괭이를 선택하고, 자원에 맞는 도구를 장착했을 때만 나무와 바위를 채집할 수 있도록 구성했다.

---
## 구현 내용

- 아이템 분류용 `ItemCategory` 열거형 추가
- 도구 종류 구분용 `ToolType` 열거형 추가
- `ItemData`에 아이템 분류와 도구 종류 설정 추가
- 도구 아이템의 최대 중첩 수량을 1개로 제한
- 도끼와 곡괭이 아이템 데이터 생성
- `PlayerInventory`에 현재 선택된 핫바 슬롯과 아이템 조회 기능 추가
- 숫자키로 선택한 핫바 아이템을 장착 도구로 사용
- `GatherableResource`에 자원별 필요 도구 설정 추가
- 나무는 도끼, 바위는 곡괭이로만 채집하도록 판정
- 맨손 및 잘못된 도구 사용 시 채집 차단
- 잘못된 도구로 채집할 때 자원 수량이 감소하지 않도록 처리
- `EquippedToolView`를 이용한 장착 도구 외형 갱신
- 핫바 선택 변경과 슬롯 이동 시 도구 외형 즉시 반영
- 도끼와 곡괭이 테스트용 획득 오브젝트 구성
- 기존 자원 소진·재생성 기능과 인벤토리 드래그 기능 유지

---
## 주요 게임 진행 흐름

```text
도구 획득
→ 인벤토리에서 핫바로 이동
→ 숫자키로 도구 선택
→ 플레이어의 장착 외형 변경
→ 자원과 필요 도구 비교
→ 조건 일치 시 자원 획득
```

---
## 채집 규칙

| 채집 대상 | 필요 도구 | 채집 결과 |
|---|---|---|
| 나무 | 도끼 | 목재 획득 |
| 바위 | 곡괭이 | 돌 획득 |
| 나무 | 곡괭이 | 채집 차단 |
| 바위 | 도끼 | 채집 차단 |
| 나무·바위 | 도구 미장착 | 채집 차단 |

---
## 테스트 내용

- 도끼와 곡괭이 획득 후 인벤토리 등록 확인
- 도구 아이템이 한 슬롯에 중첩되지 않는지 확인
- 인벤토리에서 도구를 핫바로 이동할 수 있는지 확인
- 숫자키 입력에 따라 선택 핫바 슬롯이 변경되는지 확인
- 도끼 선택 시 도끼 외형만 표시되는지 확인
- 곡괭이 선택 시 곡괭이 외형만 표시되는지 확인
- 일반 아이템 또는 빈 슬롯 선택 시 도구 외형이 사라지는지 확인
- 도끼로 나무를 채집하여 목재를 획득하는지 확인
- 곡괭이로 바위를 채집하여 돌을 획득하는지 확인
- 맨손과 잘못된 도구로 채집할 수 없는지 확인
- 채집 실패 시 자원 수량이 유지되는지 확인
- 자원 소진 및 일정 시간 후 재생성 기능 유지 확인
- 인벤토리 슬롯 이동·교환·중첩 기능 유지 확인
- 인벤토리와 핫바 UI의 실시간 동기화 확인
- Unity Console Error 미발생 확인

---
## 완료 결과

9일차 작업을 통해 핫바 선택 상태가 실제 장착 도구와 채집 가능 여부에 영향을 주도록 연결했다.

자원별 필요 도구 판정이 추가되어 나무와 바위의 채집 방식이 구분되었으며, 이후 도구 내구도·채집 애니메이션·타격 효과를 확장할 수 있는 기반을 마련했다.
