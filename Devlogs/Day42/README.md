# Project U 개발 일지

---

## 42일차 : 체온 및 저체온 시스템 구현

### 개발 목표

계절, 시간, 날씨, 젖음, 실내 판정이 플레이어의 체온에 영향을 주도록 생존 시스템을 확장한다. 낮아진 체온은 추위와 저체온 상태로 구분하고, 저체온이 지속되면 플레이어가 주기적으로 피해를 받도록 구현한다.

### 구현 내용

- 플레이어 체온을 `0~100` 범위로 관리하는 `PlayerTemperature` 구현
- 계절별 체온 감소량 적용
- 비, 눈, 폭풍 등 날씨별 체온 감소량 적용
- 야간 체온 감소 적용
- 젖음 수치에 비례한 추가 체온 감소 적용
- 지붕 아래에서 추위 영향을 줄이는 실내 보정 적용
- 체온에 따른 정상, 추위, 저체온 상태 구분
- 저체온 상태에서 일정 주기마다 체력 피해 적용
- 현재 체온과 상태를 표시하는 체온 HUD 구현
- 체온 상태에 따른 HUD 색상 변경
- 체온 데이터 저장 및 불러오기 지원
- 기존 저장 데이터 불러오기 시 체온을 최대값으로 초기화하는 호환 처리
- 부활 시 젖음과 체온 초기화
- 저장 구조 검사에 체온 데이터 검증 항목 추가

### 체온 상태 기준

| 상태 | 체온 범위 | 적용 효과 |
| --- | ---: | --- |
| 정상 | `51~100` | 별도 피해 없음 |
| 추위 | `21~50` | 체온 HUD에 추위 상태 표시 |
| 저체온 | `0~20` | 체온 HUD 경고 및 주기적 체력 피해 |

### 환경 영향

| 환경 요소 | 체온 영향 |
| --- | --- |
| 봄·가을·겨울 | 계절에 따라 체온 감소 |
| 밤 | 추가 체온 감소 |
| 비·눈·폭풍 | 날씨 강도에 따라 체온 감소 |
| 젖음 | 젖음 수치가 높을수록 체온 감소량 증가 |
| 지붕 아래 | 외부 추위 영향 감소 |
| 맑은 낮 | 체온 회복 가능 |

### 테스트 결과

- 맑은 낮에 체온이 정상 범위로 유지되는지 확인
- 비, 눈, 폭풍에서 체온이 감소하는지 확인
- 젖음 수치가 높을수록 체온이 더 빠르게 감소하는지 확인
- 지붕 아래에서 젖음이 감소하고 체온 감소량이 완화되는지 확인
- 체온이 `50` 이하일 때 추위 상태가 표시되는지 확인
- 체온이 `20` 이하일 때 저체온 상태와 주기적 체력 피해가 적용되는지 확인
- 저장 후 불러오기 시 저장 당시 체온이 복원되는지 확인
- 기존 저장 데이터에서 체온이 `100`으로 안전하게 초기화되는지 확인
- 사망 후 부활 시 젖음 `0`, 체온 `100`으로 복구되는지 확인
- 저장 구조 검사 완료 및 Console 오류가 없는지 확인

### 완료 결과

41일차에 구현한 날씨 노출과 젖음 시스템을 체온 시스템에 연결했다. 플레이어는 계절과 날씨뿐 아니라 젖은 상태와 실내 여부에 따라 서로 다른 속도로 체온이 변하며, 낮은 체온이 실제 생존 위험과 체력 피해로 이어지도록 구현했다.
