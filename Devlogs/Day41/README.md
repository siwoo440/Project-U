# Project U 개발 일지

---

## 41일차 : 실내 판정 및 젖음 시스템 구현

### 개발 목표

기존 날씨 시스템과 연동하여 플레이어의 야외·실내 상태를 판정하고, 강수 노출 상태에 따라 젖음 수치와 날씨 효과를 조절한다.

### 구현 내용

- 플레이어 위쪽 Raycast를 이용한 지붕 판정
- `WeatherShelter` 및 `Structure` Layer 기반 실내 판정
- 야외 `OUTDOOR` 및 실내 `SHELTERED` 상태 표시
- 비와 폭풍에 노출될 때 젖음 수치 증가
- 실내 또는 강수 종료 상태에서 젖음 수치 감소
- 젖음 수치를 표시하는 HUD Bar 추가
- 젖음 수치 저장 및 불러오기 기능 추가
- 기존 저장 파일과의 호환 유지
- 매개변수가 있는 날씨 강제 변경 `ContextMenu` 정리
- 실내에서도 문과 창문을 통해 외부 강수 파티클 표시
- 비와 눈 파티클의 천장 Collider 충돌 처리
- 천장에 닿은 강수 파티클 제거
- 실내 날씨 환경음 감소 처리 유지

### 개발 결과

플레이어가 야외에서 비나 폭풍에 노출되면 젖음 수치가 증가하고, 지붕이나 설치 건축물 아래로 이동하면 젖음 수치가 감소한다.

강수 파티클은 플레이어가 실내에 들어가도 전체적으로 비활성화되지 않으므로 문과 창문을 통해 바깥의 비를 계속 확인할 수 있다. 지붕 아래로 떨어지는 비와 눈은 `WeatherShelter` 또는 `Structure` Layer의 Collider와 충돌하면 제거되어 천장을 통과하지 않는다.

### 테스트 결과

- 야외 비 상태에서 젖음 수치 증가 확인
- 야외 폭풍 상태에서 비보다 빠른 젖음 증가 확인
- 지붕 아래에서 젖음 수치 감소 확인
- 실내 진입 시 날씨 환경음 감소 확인
- 실내에서 외부 강수 파티클 표시 확인
- 천장 아래 강수 파티클 차단 확인
- 젖음 수치 저장 및 복원 확인
- 기존 체력·허기·갈증·스태미나 저장 기능 유지 확인
- Console 오류 없음 확인
