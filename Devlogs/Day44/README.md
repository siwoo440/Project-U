# Project U 개발 일지

---

## 44일차 : 추위와 더위 상태 효과 구현

### 개발 목표

기존 체온 시스템을 추위뿐 아니라 더위까지 표현할 수 있도록 확장하고, 체감 온도 구간에 따라 이동 속도, 스태미나, 갈증, 체력에 상태 효과가 적용되도록 구현했다.

### 주요 구현 내용

- 체감 온도 범위를 `0~100`에서 `0~200`으로 확장
- 정상 체감 온도를 `100`으로 설정
- 체감 온도 상태를 저체온, 추위, 쾌적, 더위, 열사병의 다섯 단계로 구분
- 계절, 날씨, 시간대, 젖음, 실내 여부에 따른 체감 온도 변화 처리
- 여름과 맑은 낮 환경에서 체감 온도가 상승하는 더위 계산 추가
- 방한 장비 수치가 환경의 추위 감소량에 반영되도록 연결
- 모닥불 열기를 받는 동안 체온 회복 및 저체온 피해 중단 처리 유지
- 추위와 더위 상태에 따른 이동 속도 감소 적용
- 온도 상태에 따른 스태미나 소비 증가 및 회복 감소 적용
- 더위와 열사병 상태에서 갈증 감소 속도 증가 적용
- 저체온과 열사병 상태에서 일정 주기로 체력 피해 적용
- 체온 HUD에 `COLD`, `HYPOTHERMIA`, `COMFORTABLE`, `HOT`, `HEATSTROKE`, `WARMING` 상태 표시 추가
- 체온 상태별 HUD 색상 구분
- 이전 저장 데이터에 체온 정보가 없을 경우 정상 체온 `100`을 적용하도록 호환 처리
- 저장 및 불러오기 후 현재 체온과 상태 효과가 다시 적용되도록 연결

### 체감 온도 상태 기준

| 상태 | 체감 온도 | 주요 효과 |
|---|---:|---|
| 저체온 | `0~20` | 이동 속도 감소, 스태미나 불이익, 주기적 체력 피해 |
| 추위 | `21~50` | 이동 속도 감소, 스태미나 소비 증가 및 회복 감소 |
| 쾌적 | `51~129` | 상태 불이익 없음 |
| 더위 | `130~169` | 이동 속도 감소, 스태미나 불이익, 갈증 감소 가속 |
| 열사병 | `170~200` | 강한 이동·스태미나·갈증 불이익, 주기적 체력 피해 |

### 테스트 내용

- 정상 체온에서 `COMFORTABLE` 표시 및 기본 이동·스태미나·갈증 속도 확인
- 추위와 저체온 상태에서 이동 및 스태미나 불이익 확인
- 저체온 상태에서 일정 주기의 체력 피해 확인
- 모닥불 열기 수신 중 `WARMING` 표시와 저체온 피해 중단 확인
- 더위와 열사병 상태에서 이동, 스태미나, 갈증 불이익 확인
- 열사병 상태에서 일정 주기의 체력 피해 확인
- 여름의 맑은 낮에 체감 온도 상승 확인
- 실내에서 추위와 더위 변화량 감소 확인
- 저장 후 체온 수치와 상태 효과 복원 확인
- 이전 저장 데이터 불러오기 시 정상 체온 `100` 적용 확인
- 사망 후 부활 시 체온이 정상값으로 복구되는지 확인
- Unity Console 컴파일 오류 여부 확인

### 완료 결과

환경 조건에 따라 체감 온도가 정상 범위보다 낮아지거나 높아지며, 현재 온도 구간에 맞는 생존 불이익이 플레이어의 이동, 스태미나, 갈증, 체력과 HUD에 함께 반영된다. 기존 모닥불과 방한 장비 기능을 유지하면서 더위와 열사병까지 포함하는 양방향 체온 시스템을 완성했다.
