# Project U 개발 일지

---

## 39일차 : 기본 날씨 순환 시스템

### 개발 목표

기존 시간 및 계절 시스템을 기반으로 게임 시간에 따라 자동으로 변화하는 기본 날씨 순환 시스템을 구현했다.

### 구현 내용

- 계절당 날짜 수를 기존 임시값 7일에서 28일로 변경
- 맑음, 흐림, 비, 눈, 폭풍의 다섯 가지 날씨 정의
- 현재 계절에 따른 날씨별 발생 확률 적용
- 봄, 여름, 가을에는 눈이 발생하지 않도록 설정
- 겨울에는 눈이 주요 날씨로 등장하도록 설정
- 날씨별 최소·최대 지속 시간 설정
- 게임 시간 경과에 따른 날씨 남은 시간 감소
- 침낭 수면으로 이동한 게임 시간 반영
- 날씨 지속 시간 종료 시 새로운 날씨 자동 선택
- HUD에 현재 날씨와 남은 지속 시간 표시
- Inspector에서 다음 날씨를 강제로 선택하는 테스트 기능 추가

### 날씨별 지속 시간

| 날씨 | 최소 지속 시간 | 최대 지속 시간 |
|---|---:|---:|
| 맑음 | 6시간 | 10시간 |
| 흐림 | 4시간 | 8시간 |
| 비 | 3시간 | 6시간 |
| 눈 | 4시간 | 8시간 |
| 폭풍 | 2시간 | 4시간 |

### 테스트 결과

- 현재 계절에 맞는 날씨가 무작위로 선택되는지 확인
- 날씨 HUD에 현재 날씨와 남은 시간이 표시되는지 확인
- 일반적인 시간 진행 중 남은 날씨 시간이 감소하는지 확인
- 수면으로 시간이 이동할 때 날씨 시간도 함께 처리되는지 확인
- 날씨 종료 후 새로운 날씨가 자동으로 선택되는지 확인
- 봄, 여름, 가을에 눈이 선택되지 않는지 확인
- 겨울에 눈이 정상적으로 선택되는지 확인
- 기존 시간, 계절 및 저장 시스템이 정상 작동하는지 확인
- Console에 오류가 발생하지 않는지 확인

### 개발 결과

39일차에는 기존 계절 시스템과 게임 시간 시스템을 기반으로 기본 날씨 순환 시스템을 구현했다.

계절당 날짜 수를 확정값인 28일로 변경하고, 맑음·흐림·비·눈·폭풍의 다섯 가지 날씨를 정의했다. 현재 계절에 따라 서로 다른 확률로 날씨가 선택되며, 겨울을 제외한 계절에는 눈이 발생하지 않도록 구성했다.

각 날씨에는 최소 및 최대 지속 시간을 적용했다. 게임 시간이 흐르거나 침낭 수면으로 시간이 이동하면 지난 시간만큼 날씨의 남은 시간이 감소하고, 지속 시간이 끝나면 다음 날씨가 자동으로 선택된다.

HUD에는 현재 날씨와 남은 지속 시간을 표시했으며, Inspector 메뉴에서 다음 날씨를 강제로 선택할 수 있는 테스트 기능을 추가했다.

이번 일차에는 기본 날씨 상태와 시간 순환만 구현했다. 날씨 파티클, 안개, 음향, 젖음, 체감 온도 및 날씨 저장·복원은 이후 개발 범위로 남겨두었다.
