## 47일차 : 제작·보관·건축 규칙 문서 확정

### 개발 목표

제작, 보관함, 건축 시스템을 본격적으로 확장하기 전에 공통 데이터 구조와 처리 규칙을 문서로 확정한다.

### 개발 내용

* `CraftingStorageBuildingRules.md` 작성
* 제작법 고유 ID와 해금 방식 정의
* 맨손 제작, 작업대, 모닥불의 시설별 제작 규칙 정의
* 제작 성공·실패 및 재료 복구 처리 순서 정의
* 소형·대형 보관함의 슬롯 용량과 아이템 이동 규칙 정의
* 보관함과 설치 건축물의 `StructureId` 연동 규칙 정의
* 기초, 바닥, 벽, 가구, 지붕의 연결·지지 관계 정의
* 기능성 가구의 상호작용 및 저장 규칙 정의
* 건축물 철거 차단 조건과 재료 50% 반환 규칙 정의
* 기존 제작법과 건축물의 저장 ID 유지 목록 정리
* 48~54일차 후속 구현 범위 분리

### 주요 확정 사항

* 제작법 해금과 제작 시설 요구 조건을 별도로 판정
* 제작 실패 시 재료를 소비하지 않도록 처리
* 건축물은 설치 확정 시점에만 재료 소비
* 소형 보관함 12칸, 대형 보관함 24칸 사용
* 보관함 슬롯 순서와 아이템 위치 유지
* 건축물 연결과 기능 상태를 `StructureId` 기준으로 저장
* 상위 건축물을 지지하는 구조물은 철거 제한
* 철거 시 설치 재료의 50%를 소수점 이하 내림으로 반환
* 기존 저장 ID와 `BuildPlacementType` 숫자 값 유지

### 작업 결과

제작, 보관함, 건축 시스템의 공통 규칙을 문서로 확정했다. 이번 일차에는 Unity 실행 코드와 기존 C# 스크립트를 변경하지 않았으며, 다음 일차부터 확정된 규칙을 기준으로 실제 기능을 구현한다.

### 다음 개발 방향

48일차에는 제작 시설 구분과 제작법 해금 데이터를 확장하고, 저장 가능한 제작법 해금 목록을 구현한다.
