# 프로젝트 U 28일차 개발 일지

## 개발 주제

낮·밤 시간 순환 시스템 구현

## 개발 목표

게임 내 날짜와 시간이 지속해서 흐르고, 현재 시간에 따라 태양과 환경광이 변화하도록 구현했다. 화면 우측 상단에는 날짜와 시간을 표시하여 플레이어가 현재 시간대를 바로 확인할 수 있도록 구성했다.

## 구현 내용

### 1. 게임 시간 진행

- 게임 시작 시간을 `DAY 1 08:00`으로 설정
- 현실 시간 10분마다 게임 내 하루가 지나도록 구성
- 프레임 속도와 관계없이 일정하게 시간이 흐르도록 `Time.deltaTime` 사용
- 자정을 통과하면 현재 날짜가 자동으로 증가하도록 처리
- 빠른 테스트를 위한 시간 진행 배율 제공

### 2. 태양 이동과 조명 변화

- 기존 `Directional Light`를 태양광으로 연결
- 현재 시간에 따라 태양의 회전값 변경
- 낮에는 밝고 따뜻한 태양광 적용
- 일출과 일몰에는 주황색 계열의 태양광 적용
- 밤에는 태양광 밝기와 환경광을 낮춰 어두운 분위기 표현

### 3. 날짜·시간 HUD

- `GameplayCanvas` 우측 상단에 `DayTimeHUD` 생성
- `DayTimeText`를 통해 현재 날짜와 시간을 분 단위로 표시
- `DAY 1  08:00` 형식으로 시간 정보 통일
- UI 요소의 Raycast Target을 해제하여 기존 조작을 방해하지 않도록 설정

### 4. 기존 모닥불 시스템 연동 확인

- 야간 환경에서 모닥불 조리 시작 시 불꽃과 Point Light 활성화 확인
- 모닥불 조명이 어두운 주변 환경을 밝히는지 확인
- 조리 완료 후 불꽃과 조명이 정상적으로 비활성화되는지 확인

### 5. 예외 처리

- 태양광 또는 시간 표시 텍스트 참조 누락 시 오류 출력 후 기능 비활성화
- Directional Light가 아닌 조명이 연결되면 오류 출력
- 하루 길이, 시작 날짜, 시간 배율과 조명 밝기의 잘못된 값 보정
- 음수 시간 배율과 음수 조명 밝기 방지

## 테스트 결과

- `DAY 1 08:00`에서 시간 시작 확인
- 날짜와 시간이 분 단위로 계속 갱신되는지 확인
- 시간에 따라 Directional Light가 회전하는지 확인
- 일출·낮·일몰·밤의 색상과 밝기 변화 확인
- 자정 통과 시 날짜 증가 확인
- 시간 배율 `60`에서 약 10초마다 하루가 순환하는지 확인
- 야간에 모닥불 조명이 주변을 밝히는지 확인
- 여러 날이 지나도 시간과 날짜가 정상적으로 순환하는지 확인
- 테스트 후 시작 시간 `8`, 시간 배율 `1`로 복구
- Console 오류 없음 확인

## 완료 결과

28일차 작업으로 게임 내 날짜와 시간의 흐름이 추가되었다. 시간대에 따라 태양과 환경광이 변하며, 플레이어는 HUD를 통해 현재 날짜와 시간을 확인할 수 있다. 27일차에 구현한 모닥불 조명도 야간 환경에서 정상적으로 작동하여 낮·밤 변화와 기존 생존 시스템이 연결되었다.
