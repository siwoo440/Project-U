# Project U 개발 일지

---

## 38일차 : 메인 메뉴 이어하기·저장 복원 및 계절 시스템

---

### 개발 목표

기존 저장 시스템을 메인 메뉴와 연결하여 새 게임과 이어하기를 구분하고, 저장된 게임을 선택하면 Gameplay Scene 진입 후 플레이 상태가 자동으로 복원되도록 구현했다.

게임의 전체 날짜를 기준으로 봄, 여름, 가을, 겨울이 순환하는 계절 시스템을 추가하고, 현재 계절을 HUD와 환경 조명에 반영했다.

---

### 구현 내용

#### 1. 메인 메뉴 새 게임과 이어하기 분리

- 메인 메뉴에 `NEW GAME` 버튼과 `CONTINUE` 버튼을 분리했다.
- 유효한 저장 데이터가 있을 때만 `CONTINUE` 버튼이 활성화되도록 구현했다.
- 저장 데이터가 없거나 손상된 경우 `NO SAVE DATA` 문구가 표시되도록 구성했다.
- 저장된 날짜와 시간을 메인 메뉴에서 확인할 수 있도록 저장 정보 문구를 추가했다.
- 기본 저장 파일이 손상된 경우 백업 파일을 검사하여 이어하기에 사용할 수 있도록 연결했다.
- 기본 저장 슬롯 ID를 공통 상수로 관리하도록 정리했다.
- `NEW GAME` 선택 시 기존 저장 데이터를 적용하지 않고 Gameplay Scene의 초기 상태로 시작하도록 구현했다.
- `CONTINUE` 선택 시 저장 데이터의 유효성을 검사한 후 Gameplay Scene으로 이동하도록 구현했다.
- 메인 메뉴로 돌아갈 때 남아 있는 이어하기 요청 상태가 초기화되도록 처리했다.

#### 2. 저장 데이터 자동 복원

- Scene 전환 완료 후 `GameplaySaveController`를 찾아 저장 데이터를 자동 복원하도록 구현했다.
- 동일한 저장 데이터가 Scene 전환 후 중복으로 불러와지지 않도록 처리했다.
- 37일차에 구현한 침낭 수면 완료 후 오전 8시 자동 저장 기능을 유지했다.
- 저장된 전체 날짜와 시간을 정상적으로 복원하도록 연결했다.

#### 3. 계절 종류 정의

- `SeasonType` 열거형을 추가했다.
- 봄, 여름, 가을, 겨울의 네 계절을 정의했다.
- 문자열 대신 고정된 계절 값으로 현재 상태를 관리하도록 구성했다.

#### 4. 계절 순환 시스템 구현

- `SeasonCycle` 컴포넌트를 추가했다.
- 전체 날짜를 기준으로 현재 계절과 계절 내부 날짜를 계산하도록 구현했다.
- 봄 → 여름 → 가을 → 겨울 순서로 계절이 순환하도록 구성했다.
- 겨울 종료 후 다시 봄으로 돌아오도록 구현했다.
- 계절당 날짜 수를 Inspector에서 변경할 수 있도록 구성했다.
- 현재 임시 기준값을 계절당 7일로 설정했다.

#### 5. 날짜 및 저장 시스템 연동

- `DayNightCycle`과 `SeasonCycle`을 연결했다.
- 자정 통과와 수면으로 날짜가 변경되면 현재 계절이 자동으로 갱신되도록 구현했다.
- 저장 데이터를 불러오면 복원된 날짜를 기준으로 현재 계절을 다시 계산하도록 연결했다.
- 별도의 계절 저장 항목을 추가하지 않고 기존 날짜 데이터를 활용했다.
- 기존 저장 파일 구조와의 호환을 유지했다.

#### 6. 계절 HUD 구현

- Gameplay HUD에 `SeasonText`를 추가했다.
- 현재 계절의 영문 이름을 표시하도록 구현했다.
- 현재 계절 내부 날짜와 계절당 날짜 수를 표시하도록 구성했다.
- 표시 형식을 `SPRING DAY 1/7`로 통일했다.

#### 7. 계절별 환경 변화 구현

- 계절별 태양광 색상 설정을 추가했다.
- 계절별 환경광 색상 설정을 추가했다.
- 기존 낮·밤과 일출·일몰 조명 계산을 유지했다.
- 시간대별 조명 결과에 현재 계절 색상을 추가로 적용했다.
- 계절이 변경되면 HUD와 환경 조명이 즉시 갱신되도록 구현했다.

### 메인 메뉴 동작

| 선택 항목 | 동작 |
| --- | --- |
| `NEW GAME` | 저장 데이터를 불러오지 않고 초기 상태로 시작 |
| `CONTINUE` | 유효한 기본 저장 또는 백업 저장을 불러와 이어서 시작 |
| 저장 데이터 없음 | `CONTINUE` 비활성화 및 `NO SAVE DATA` 표시 |
| 백업 데이터 사용 | 저장 정보에 `BACKUP` 표시 |

### 테스트 결과

- 저장 데이터가 없을 때 `CONTINUE` 버튼이 비활성화되는 것을 확인했다.
- 저장 데이터가 있는 경우 저장 날짜와 시간이 정상적으로 표시되는 것을 확인했다.
- `NEW GAME` 선택 시 기존 저장 상태가 적용되지 않는 것을 확인했다.
- `CONTINUE` 선택 시 Gameplay Scene 이동 후 저장 상태가 자동 복원되는 것을 확인했다.
- 기본 저장 파일이 손상된 경우 백업 저장 데이터를 사용할 수 있는 것을 확인했다.
- Scene 전환 후 저장 데이터가 중복으로 불러와지지 않는 것을 확인했다.
- 시작 날짜를 변경하여 네 계절의 계산 결과를 확인했다.
- 계절 마지막 날에서 수면한 후 다음 계절로 전환되는 것을 확인했다.
- 겨울 마지막 날 이후 다시 봄으로 돌아오는 것을 확인했다.
- 계절 변경 시 HUD 문구와 환경 조명이 갱신되는 것을 확인했다.
- 침낭 수면 후 저장된 오전 8시 상태가 정상적으로 복원되는 것을 확인했다.
- 이어하기 후 저장 날짜에 맞는 계절이 자동으로 복원되는 것을 확인했다.
- 기존 플레이어, 인벤토리, 월드 및 건축물 저장 데이터가 정상적으로 복원되는 것을 확인했다.
- Console에 컴파일 오류와 참조 누락 오류가 발생하지 않는 것을 확인했다.

---

### 완료 결과

메인 메뉴에서 새 게임과 이어하기를 명확하게 선택할 수 있으며, 유효한 저장 파일이 존재할 경우 저장된 플레이 상태를 Gameplay Scene에서 자동으로 복원할 수 있게 되었다.

전체 날짜를 기반으로 사계절이 순환하며, 현재 계절과 계절 내부 날짜가 HUD에 표시된다. 계절별 태양광과 환경광 변화가 적용되고, 수면 및 저장 데이터 불러오기 이후에도 날짜에 맞는 계절이 유지된다.
