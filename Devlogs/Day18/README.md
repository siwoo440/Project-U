## 18일차: 갈증·탈수 피해 및 음료 시스템 구현

### 개발 목표

플레이어의 갈증 생존 수치를 추가하고, 갈증이 모두 소진되면 탈수 피해를 받도록 구현한다. 음료 아이템을 획득하고 사용하여 갈증을 회복할 수 있도록 기존 인벤토리와 핫바 시스템을 확장한다.

### 구현 내용

| 구분 | 구현 내용 |
|---|---|
| 갈증 관리 | 최대 갈증과 현재 갈증 및 시간에 따른 자동 감소 처리 |
| 탈수 상태 | 현재 갈증이 0에 도달하면 탈수 상태 적용 |
| 탈수 피해 | 탈수 상태에서 일정한 간격으로 체력 감소 |
| 피해 중단 | 음료로 갈증을 회복하면 탈수 피해 시간 초기화 |
| 갈증 HUD | 현재 갈증을 게이지와 숫자로 표시 |
| 음료 분류 | 기존 아이템 분류에 `Drink` 항목 추가 |
| 음료 데이터 | 아이템별 갈증 회복량 설정 기능 추가 |
| 물병 아이템 | 갈증을 회복하는 물병 데이터와 획득 프리팹 구성 |
| 핫바 사용 | 선택한 물병을 오른쪽 클릭하여 사용 |
| 수량 처리 | 갈증 회복에 성공한 경우에만 음료 수량 감소 |
| 음식 분리 | 음식은 허기, 음료는 갈증만 회복하도록 구분 |
| 사망 연동 | 사망 후 음식과 음료 사용 차단 |
| 재시작 연동 | Scene 재시작 후 갈증을 최대 수치로 초기화 |

### 주요 변경 파일

| 파일 | 역할 |
|---|---|
| `ItemCategory.cs` | 음료 아이템 분류 추가 |
| `ItemData.cs` | 음료 여부와 갈증 회복량 데이터 관리 |
| `ItemIconUtility.cs` | 음료 기본 아이콘 색상 처리 |
| `InventoryDetailUI.cs` | 인벤토리 상세 화면의 음료 분류 표시 |
| `HotbarItemUse.cs` | 음식과 음료의 핫바 사용 처리 |
| `PlayerThirst.cs` | 플레이어 갈증 수치와 회복 상태 관리 |
| `DehydrationDamage.cs` | 갈증 0 상태의 주기적인 체력 피해 처리 |
| `ThirstBarUI.cs` | 갈증 게이지와 현재 갈증 수치 표시 |
| `ItemData_WaterBottle.asset` | 물병 아이템 정보와 갈증 회복량 설정 |
| `WaterBottlePickup.prefab` | 필드에서 획득할 수 있는 물병 구성 |
| `20_Gameplay.unity` | 갈증 HUD, 생존 컴포넌트와 참조 연결 |

### 개발 결과

- 플레이어가 갈증 100으로 시작한다.
- 갈증이 시간에 따라 자동으로 감소한다.
- 갈증 HUD에서 현재 갈증 상태를 확인할 수 있다.
- 갈증이 0에 도달하면 일정한 간격으로 탈수 피해를 받는다.
- 물병을 획득하여 인벤토리와 핫바에 보관할 수 있다.
- 핫바에서 물병을 선택하고 오른쪽 클릭하여 사용할 수 있다.
- 물병을 사용하면 설정된 수치만큼 갈증이 회복된다.
- 갈증 회복에 성공한 경우에만 물병 수량이 감소한다.
- 갈증이 최대일 때는 물병이 소비되지 않는다.
- 음식은 허기만 회복하고 음료는 갈증만 회복한다.
- 갈증이 회복되면 탈수 피해가 즉시 중단된다.
- 허기와 갈증이 모두 0이면 굶주림과 탈수 피해가 각각 적용된다.
- 사망 후 음식과 음료를 사용할 수 없다.
- Retry 버튼으로 재시작하면 갈증이 초기 상태로 복구된다.
