# Project U 25일차 개발 일지

---

## 개발 목표

25일차에는 최신 제작 시스템과 연동되는 건축 시스템을 구현했다. 플레이어가 Terrain 위의 지정 구역에서 나무 바닥, 나무 벽, 모닥불을 선택하고 회전하여 설치할 수 있도록 구성했다.

---

## 주요 구현 내용

### 1. 건축 데이터 구조

- `BuildPlacementType`으로 바닥, 벽, 자유 배치 유형 구분
- `BuildRecipeData`를 이용한 건축물별 데이터 관리
- 설치 프리팹과 미리보기 프리팹 분리
- 필요 재료, 회전 단위, 경사 제한, 높이 차이 제한 설정
- 배치 충돌 검사 범위를 건축 데이터별로 지정

### 2. Terrain 기반 건축 구역

- `BuildGridArea`를 이용한 가상 건축 구역 생성
- Terrain 높이를 따라 표시되는 1×1 그리드 구현
- 건축 가능 구역 내부 여부 검사
- 바닥을 타일 중앙에 자동 정렬
- 벽을 가장 가까운 타일 경계에 자동 정렬
- 모닥불을 건축 구역 내부에서 자유롭게 배치

### 3. 건축물 미리보기

- 선택한 건축물의 미리보기 프리팹 생성
- 설치 가능 시 초록색 재질 표시
- 설치 불가능 시 빨간색 재질 표시
- `Q`, `E` 입력으로 미리보기 회전
- `Z`, `X` 입력으로 건축물 종류 변경
- `B`, 우클릭, `ESC` 입력으로 건축 모드 종료

### 4. 설치 가능 조건 검사

- 플레이어와 설치 지점 사이의 최대 거리 검사
- 중앙과 네 모서리를 이용한 Terrain 높이 검사
- 최대 경사와 지형 높이 차이 검사
- Terrain 일부가 없는 위치의 설치 차단
- 플레이어, 자원, 구조물, 환경 장애물과의 충돌 검사
- 동일 바닥과 동일 벽의 중복 설치 차단
- 바닥과 벽의 같은 타일 공존 허용
- 설치된 바닥 위 모닥불 배치 허용

### 5. 재료 소비 연동

- 건축 데이터에 설정된 필요 재료와 보유량 비교
- 재료 부족 시 설치 차단 및 상태 문구 표시
- 설치 직전에 재료 보유량 재검사
- 설치 성공 시 인벤토리에서 재료 차감
- 재료 제거 도중 오류 발생 시 이미 제거된 재료 복구

### 6. 건축 HUD

- 현재 설치 가능 상태 표시
- 선택한 건축물 이름과 배치 유형 표시
- 재료별 현재 보유량과 필요량 표시
- 건축 모드 진입 시 HUD 활성화
- 건축 모드 종료 시 HUD와 그리드 비활성화

### 7. 기존 입력 시스템 연동

- 건축 중 도끼와 곡괭이 공격 차단
- 건축 중 `F` 상호작용과 안내 UI 차단
- 건축 중 음식, 음료, 붕대 사용 차단
- 우클릭 취소 프레임의 아이템 오사용 방지
- 인벤토리 진입 시 건축 모드 자동 종료
- 건축 종료 후 기존 입력 기능 정상 복구

## 입력 방식

| 입력 | 기능 |
|---|---|
| `B` | 건축 모드 시작·종료 |
| 좌클릭 | 건축물 설치 |
| 우클릭 | 건축 모드 종료 |
| `ESC` | 건축 모드 종료 |
| `Q` / `E` | 건축물 회전 |
| `Z` / `X` | 건축물 선택 |
| `I` | 인벤토리 열기 및 건축 모드 종료 |
