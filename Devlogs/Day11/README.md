# 프로젝트 U 11일차 개발 일지

## 개발 목표

기존 플레이어 달리기에 스태미나 소비와 회복을 연결하고, 스태미나가 부족할 때 달리기를 제한하는 기능을 구현했다.

## 주요 개발 내용

### 1. 플레이어 스태미나 시스템 구현

- 최대 스태미나와 현재 스태미나 관리
- 실제 이동하며 달릴 때만 스태미나 소비
- 제자리에서 달리기 키만 누를 경우 소비 방지
- 스태미나 수치를 최소 0, 최대치 이하로 제한

### 2. 스태미나 회복 구현

- 달리기를 멈춘 뒤 일정 시간이 지나면 자동 회복
- 회복 지연 시간과 초당 회복량을 Inspector에서 조절 가능
- 최대 스태미나 도달 시 추가 회복 방지

### 3. 탈진과 재달리기 제한 구현

- 스태미나가 0이 되면 탈진 상태 적용
- 탈진 중에는 달리기 입력을 눌러도 걷기 속도로 이동
- 지정된 스태미나 수치까지 회복한 뒤 달리기 재허용
- 낮은 스태미나에서 달리기와 걷기가 빠르게 반복되는 현상 방지

### 4. 기존 이동 시스템 연결

- 기존 `Sprint` Input Action 유지
- `PlayerMovement`와 `PlayerStamina` 역할 분리
- 이동 입력과 달리기 입력이 모두 있을 때만 달리기 판정
- 걷기, 점프, 중력 등 기존 이동 기능 유지

## 주요 설정값

| 항목 | 설정값 | 설명 |
|---|---:|---|
| 최대 스태미나 | 100 | 플레이어의 최대 스태미나 |
| 초당 달리기 소비량 | 20 | 약 5초간 연속 달리기 가능 |
| 초당 회복량 | 15 | 회복 시작 후 초당 회복 수치 |
| 회복 지연 | 1.5초 | 마지막 소비 후 회복 대기 시간 |
| 탈진 해제 수치 | 20 | 다시 달릴 수 있는 최소 수치 |

## 테스트 결과

- 걷는 동안 스태미나가 감소하지 않음
- 제자리에서 달리기 키를 눌러도 스태미나가 감소하지 않음
- 이동 중 달리기 키를 누르면 스태미나가 정상적으로 감소함
- 스태미나가 0이 되면 달리기가 차단되고 걷기로 전환됨
- 달리기 종료 후 1.5초가 지나면 스태미나가 회복됨
- 탈진 상태에서 스태미나가 20 이상 회복되면 달리기가 다시 허용됨
- 기존 이동, 점프, 인벤토리, 핫바, 도구 장착 및 채집 기능이 정상 작동함
- Console에서 빨간색 Error가 발생하지 않음

## 완료 결과

플레이어의 달리기에 자원 제한이 생겨 이동 시스템의 기본 구조가 보완되었다. 스태미나 로직을 별도 컴포넌트로 분리해 이후 HUD, 음식 효과, 장비 보너스와 생존 시스템에서 현재 수치와 최대 수치를 사용할 수 있는 기반을 마련했다.
