# Project U 개발 일지

## 109일차 : NPC 동료 (따라다니기 · 전투 · 채집 · 치유 · 대화 창 버튼)

### 1. 개발 목표

108일차에 섬이 넓어지고 들판에 적이 생겼지만, 플레이어는 늘 혼자 다녔다.

- 친해진 NPC(**신뢰** 단계 이상)를 대화 창에서 **"함께 가자"** 로 데려갈 수 있게 했다.
- 동료는 플레이어를 **따라다니며** 역할에 맞게 돕는다 : **전투 · 채집 · 치유**
- 동료는 한 번에 한 명, 밤에는 집으로 돌아간다.
- 동료 상태를 **저장 · 불러오기** 한다.

실행 메뉴 : 새 메뉴 `25. NPC Companions (Follow + Fight/Gather/Heal + Dialogue Button)` (19번 · 22번 메뉴 안에서도 함께 실행)

---

## 2. 동료 정보 (`NpcCompanions.csv` → `NpcCompanionBook`)

| 역할 | NPC | 하는 일 |
| --- | --- | --- |
| 전투 | 베로나 · 체스카 · 리리엘 | 플레이어 둘레 14m 안의 가장 가까운 적에게 다가가 때림 (힘 · 간격이 NPC마다 다름) |
| 채집 | 미오 · 네리 · 루미나 | 마을 밖(가운데에서 140m ~)을 함께 다니면 가끔 물건을 찾아 줌 (미오 : 생선 · 미끼, 네리 : 버섯 · 열매 · 풀 섬유, 루미나 : 열매 · 딸기 · 사과) · 하루 8번까지 |
| 치유 | 루네트 · 알리우네 · 미레유 | 플레이어 체력이 절반 아래면 회복 (16 ~ 32, 40 ~ 60초마다) |

- NPC마다 대사를 따로 넣었다 : 합류 · 헤어짐 · 밤 인사 · 거절 · 역할 대사 · 혼잣말 3개
- 채집 대사는 `{item}` 자리에 찾은 물건 이름이 들어간다 (예 : "TROUT 찾았다냥! 너 줄게냥.").

---

## 3. 따라다니기 (`NpcAgent`)

- 플레이어 뒤 비스듬한 자리(뒤 2.4m · 옆 1.3m)로 걸어간다. 멀수록 빨리 걷는다 (5m ~ 1.6배, 10m ~ 2.8배).
- 45m보다 멀어지면 플레이어 뒤로 **순간이동**한다.
- 플레이어가 **헤엄치면** 플레이어와 가장 가까운 **물가**로 가서 기다린다 (물에는 들어가지 않음).
- 가까이 서 있을 때는 플레이어 쪽을 본다.
- 동료인 동안에는 NPC 일정(`NpcManager`)이 동료를 끌고 가지 않는다. 헤어지면 다음 일정 자리로 돌아간다.

---

## 4. 동료 규칙 (`NpcCompanionManager`)

| 규칙 | 내용 |
| --- | --- |
| 합류 조건 | 호감도 **신뢰(40)** 이상. 아니면 NPC가 거절 대사를 한다. |
| 한 명 제한 | 이미 동료가 있으면 "이미 다른 동료와 함께 다니고 있어요." |
| 밤 | 잠자는 시각(21시 ~ 6시)이 되면 밤 인사를 하고 집으로 돌아간다. 밤에는 합류하지 않는다. |
| 동행 호감도 | 게임 시간 2시간을 함께 다니면 호감도 +1 (하루 3까지) |
| 쓰러짐 | 플레이어가 쓰러지면 싸움을 멈춘다. |

## 5. 화면

- **대화 창** : 대사 칸 오른쪽 아래(닫기 버튼 옆)에 **"함께 가자 / 이제 돌아가"** 버튼
  - 동료가 될 수 있는 9명에게만 보이고, 하트 이벤트 중에는 숨는다.
  - 버튼 자리를 만들려고 대사 칸 높이를 110 → 102px로, 알림 글자 칸 너비를 버튼 왼쪽까지로 줄였다.
- **화면 왼쪽 아래 동료 표시** (`NpcCompanionHUD`) : 초상 · "동료 이름 · 역할", 동료가 있을 때만 보이고 글자 길이에 맞춰 폭이 바뀐다. 클릭을 막지 않는다.

---

## 6. 저장 (`NpcCompanionSaveBridge`)

- 저장 : 지금 동료 · 함께한 시간 · 그날 받은 동행 호감도 · 그날 채집 횟수
- 불러오면 동료가 다시 따라다닌다. 109일차 이전 저장 파일은 동료 없이 시작한다.
- 알 수 없는 NPC ID는 동료 없이 불러오고, 범위를 벗어난 값은 저장 검사에서 막는다.

- 전투형이 들판 적을 때림
- 밤이 되면 집으로 돌아가고 합류 안 됨 · 다음 일정 받음
- 한 명 제한 · 마을 안에서는 채집 안 함 · 마을 밖 채집 · 하루 한도
- 체력이 낮을 때만 치유 · 2시간 함께 → 호감도 +1 · 일정이 바뀌어도 계속 따라옴
- 저장 · 초기화 · 불러오기, 잘못된 값 막기
- 동료가 아닌 NPC는 버튼 없음 · 대화 창 "이제 돌아가"로 헤어짐

## 9. 남은 문제

- 아이템 이름이 영어라서 채집 대사에 "TROUT"처럼 영어 이름이 나온다 (의뢰 문구와 같음).
- 동료는 적에게 맞지 않는다 (적이 동료를 노리지 않음).
- 동료는 Terrain 나무를 피하지 않고 지나갈 수 있다 (NavMesh에 나무가 없음).
