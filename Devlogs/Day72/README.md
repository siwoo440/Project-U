# 프로젝트 U 개발 일지

## 72일차 : 아이템 데이터 시트 통합 및 데이터 구조 정리

### 1. 오늘의 개발 목표

72일차의 목표는 기존에 작성해 둔 `프로젝트 U - 아이템` 시트의 아이템 정보를 새로운 `프로젝트 U - 아이템 데이터` 시트 구조에 맞게 이전하고 정리하는 것이었다.

기존 시트에는 아이템의 이름, 분류, 설명, 획득 방법, 제작 조건 등의 기획 정보가 작성되어 있었지만, 실제 Unity 데이터 제작과 연결하기 위해 필요한 세부 수치와 Asset 관련 항목이 부족했다.

따라서 기존 데이터를 최대한 유지하면서 새로운 데이터 시트의 형식에 맞게 분류하고, 부족한 부분은 프로젝트 U의 현재 기획 방향에 맞는 임시 값으로 보완했다.

---

## 2. 주요 작업 내용

### 2.1 기존 아이템 데이터 분석

기존 `프로젝트 U - 아이템` 시트의 다음 항목을 기준으로 데이터를 확인했다.

- 도구 및 무기
- 의상 및 방어구
- 음식
- 채집 및 기타 아이템

기존에 작성되어 있던 다음 정보는 가능한 한 그대로 유지했다.

- 아이템 ID
- 아이템 한글 이름
- 아이템 설명
- 획득 방법
- 출현 및 해금 조건
- 제작 시설
- 제작 결과 수량
- 제작 조합법
- 판매 가능 여부
- 폐기 가능 여부
- 아이템별 기존 비고

### 2.2 새로운 아이템 데이터 구조에 맞게 재분류

기존 아이템들을 새로운 데이터 시트 구조에 맞춰 다음과 같이 분류했다.

| 분류 | 등록 수 |
| --- | ---: |
| 제작 재료 | 85개 |
| 도구 | 31개 |
| 무기 | 40개 |
| 음식 | 57개 |
| 음료 | 12개 |
| 의약품 | 0개 |
| 장비 | 108개 |
| 기타 퀘스트·이벤트 아이템 | 3개 |
| 전체 | 336개 |

기존 시트에 독립적인 의약품 데이터가 존재하지 않았기 때문에 `의약품` 시트는 데이터 구조만 유지하고 비워 두었다.

퀘스트 및 이벤트 전용 아이템은 삭제하지 않고 `전체 아이템` 시트에서 `기타` 분류로 관리하도록 정리했다.

## 11. 이번 작업의 결과

이번 72일차 작업을 통해 기존에 기획용으로 작성되어 있던 아이템 목록을 실제 게임 데이터 제작에 사용할 수 있는 형태로 정리했다.

특히 기존의 단순 아이템 목록에서 다음 단계로 확장되었다.

**기존**

`아이템 이름 → 분류 → 설명 → 획득/제작 정보`

**현재**

`아이템 ID → 공통 데이터 → 종류별 세부 데이터 → 밸런스 수치 → Unity Asset → Pickup Prefab`

이제 새로운 아이템 데이터 시트를 기준으로 Unity의 `ItemData`, 무기 데이터, 음식 데이터, 장비 데이터 등의 ScriptableObject를 순차적으로 제작할 수 있는 기반이 마련되었다.
