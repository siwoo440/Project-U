# Project U 개발 일지

## 98일차 : 건축물·채집 자원 외형 설정 카드 정리와 돌벽 미리보기 연결 수정

### 1. 개발 목표

96일차에 만든 외형 설정(Visual Profile)은 "이 물건은 이 모델로 보여 줘"라는 카드다. 97일차까지 이 카드를 쓰는 것은 나무 바닥 설치본 · 나무 아이템 · 적 3종 · 도끼 · 활뿐이었다. 나머지 건축물 20종과 나무 · 돌 자원은 78일차 방식(Prefab 안의 저폴리 모델을 직접 바꿔 끼움)이라, 모델을 바꾸려면 Prefab을 하나씩 고쳐야 했다. 이번에는 건축물과 채집 자원도 **카드 방식으로 정리**했다.

- 건축물 20종 · 나무 · 돌 자원 외형 설정 카드 22개
- 카드가 기준 : 카드를 고치고 메뉴를 다시 실행하면 설치본 · 미리보기가 함께 바뀜
- 콘텐츠 ID → 카드 연결
- 돌벽 설치 미리보기 연결 수정
- 생성 메뉴(16번) · 검사

---

## 2. 외형 설정 카드

| 종류 | 카드 | 콘텐츠 ID → 카드 |
| --- | --- | --- |
| 건축물 20종 | `Data/VisualProfiles/Buildables/VP_Buildable_이름` | `structure_workbench` → `visual_buildable_workbench` |
| 나무 | `Data/VisualProfiles/Resources/VP_Resource_Tree` | 채집 아이템(`item_wood`) + 카드 ID 직접 지정 `visual_resource_tree` |
| 돌 | `Data/VisualProfiles/Resources/VP_Resource_Stone` | `resource_stone` + `visual_resource_stone` |

- 건축물 : 모닥불 · 돌 모닥불 · 큰 상자 · 작은 상자 · 침낭 · 스탠드 조명 · 작업대 · 나무 바닥(기존 카드 사용) · 나무 기초 · 나무 벽 · 돌 바닥 · 돌 기초 · 돌벽 · 나무 의자 · 나무 탁자 · 밭 · 닭장 · 외양간 · 판매 상자 · 상인 가판대
- 처음 만들 때는 지금 Prefab에 붙은 저폴리 모델과 위치 · 회전 · 크기를 그대로 옮겨서 모양이 바뀌지 않는다 (42개 Prefab 차이 0).
- 그다음부터는 **카드가 기준**이다. 카드의 모델 · 위치 · 크기가 Prefab과 다르면 16번 메뉴가 카드대로 모델을 바꿔 끼운다 (설치본 · 미리보기 함께).
- 모델은 Prefab 안에 넣어 두는 방식이다. 게임 실행 중에 다시 만들지 않아서 미리보기 색 · 채집 후 숨기기 · 저장이 예전과 같다.
- Prefab마다 콘텐츠 ID(`ContentVisualIdentity`)를 붙였다. 데이터 점검(96일차)이 이 ID로 카드를 "쓰는 곳"으로 센다.

## 3. 돌벽 설치 미리보기 수정

- 돌벽 레시피(`structure_stone_wall`)의 설치 미리보기가 나무 벽 미리보기(`WoodWallPreview`)로 연결되어 있었다. 돌벽을 지으려 하면 나무 벽 모양이 보였다.
- `StoneWallPreview`로 고쳤고, 검사에 "설치본과 미리보기가 같은 건축물인지(이름 비교)"를 추가해 같은 실수를 잡는다.

---

## 4. 생성 도구 · 검사

- `Tools > Project U > Build Content > 16. Buildable + Resource Visual Profiles`
  - 돌벽 미리보기 수정 → 카드 만들기(없으면 지금 모양으로) → Prefab을 카드대로 맞추기 · 콘텐츠 ID 연결 → 등록 목록 다시 모으기 → 검사
  - 여러 번 실행해도 결과가 같다. Scene은 바꾸지 않는다 (Scene의 나무 · 돌은 Prefab을 따라감).
- `Validate All Content`에 **건축물·자원 외형** 검사를 추가했다.
  - 카드 22개가 등록 목록에 있는지, 분류 · 모델
  - 42개 Prefab의 콘텐츠 ID → 카드 연결, 모양이 카드와 같은지
  - 설치본과 미리보기가 같은 건축물인지

## 6. 남은 문제

- 카드를 고친 뒤에는 16번 메뉴를 다시 실행해야 Prefab 모양이 바뀐다 (실행 중 자동 반영 아님).
- 나무 · 돌 자원은 한 종류씩만 있다 (자원 모양 여러 개는 없음).
- 아이템 바닥 Prefab 대부분은 아직 카드 방식이 아니다 (나무 아이템만 카드).
