# Project U 개발 일지

## 86일차 : 닭장·외양간과 가축 먹이·생산 구현

### 1. 개발 목표

농사(79~81일차), 낚시(82~83일차), 요리(85일차)에 이어 가축 콘텐츠를 추가하였다.
닭과 소를 우리에서 기르고, 먹이를 주면 다음 날 달걀·우유를 얻으며, 이 재료를 요리에 쓰는 흐름을 만드는 것이 목표이다.

이번 일차의 핵심 목표는 다음과 같다.

- 달걀·우유·사료 아이템과 닭·소 데이터
- 닭장·외양간 건축물과 우리 안을 돌아다니는 동물
- 하루 단위 먹이·기분·생산 규칙
- 우리 창 (동물 카드 · 먹이 · 쓰다듬기 · 수거 · 내보내기)
- 동물 머리 위 상태 표시
- 달걀·우유 요리 3종과 요리 목록 스크롤
- 가축 상태 저장

---

## 2. 아이템과 동물

| 아이템 | 분류 | 내용 |
| --- | --- | --- |
| EGG | 음식 | 허기 +6, 요리 재료 |
| MILK | 음료 | 갈증 +25, 요리 재료 |
| ANIMAL FEED | 재료 | 맨손 제작 : 식물 섬유 2 → 사료 3 |

| 동물 | 하루 먹이 | 불러오기 비용 | 생산물 | 추가 생산 확률 |
| --- | --- | --- | --- | --- |
| 닭 (HEN) | 사료 1 | 사료 4 | 달걀 1 (매일) | 35% |
| 소 (COW) | 사료 2 | 사료 8 | 우유 1 (매일) | 25% |

- `AnimalData` : 먹이·생산 주기·최대 보관 수·기분 규칙·모델·아이콘
- 저폴리 모델 : 닭, 소, 달걀, 우유병, 사료 자루, 먹이통 사료, 둥지 달걀, 우유 통

## 3. 우리 건축물

| 건축물 | 크기 | 마리 수 | 재료 |
| --- | --- | --- | --- |
| CHICKEN COOP | 2.6 × 2.6m | 3 | 나무 12, 식물 섬유 4 |
| BARN | 3.6 × 3.6m | 2 | 나무 20, 돌 8 |

- 울타리·닭집(외양간) 충돌체가 있어 플레이어는 우리 안으로 들어갈 수 없다.
- 우리 안 동물은 정해진 영역 안을 천천히 걷고, 쉬는 동안 고개를 숙이며, 쓰다듬으면 폴짝 뛴다.
- 먹이를 준 동물이 있으면 먹이통에 사료가, 생산물이 있으면 둥지 달걀·우유 통이 보인다.
- 동물이 남아 있으면 "RELEASE THE ANIMALS FIRST"로 철거를 막는다.
- 박공(앞면 삼각형 벽)과 외양간 벽이 지붕 밖으로 튀어나오지 않게 모델을 다듬었다.

## 4. 하루 규칙

```text
하루가 지나감 (LivestockManager가 날짜 변경 확인)
→ 오늘 먹이를 먹은 동물 : 기분 +10, 생산 조건 확인
     기분 30 이상 → 생산물 +1 (기분 80 이상이면 확률로 +1 더)
→ 먹이를 못 먹은 동물 : 기분 -25, 생산 없음
→ 먹이·쓰다듬기 기록 초기화
```

| 항목 | 규칙 |
| --- | --- |
| 시작 기분 | 60 |
| 쓰다듬기 | 하루 한 번, 닭 +8 / 소 +10 |
| 기분 단계 | SAD (30 미만) / CONTENT / HAPPY (80 이상) |
| 보관 | 한 마리당 생산물 최대 3개 |
| 여러 날 건너뛰기 | 첫날만 먹은 날로 계산, 나머지는 굶은 날 (최대 30일) |

## 5. 우리 창

```text
[닭 아이콘 CHICKEN COOP      3 / 3 CHICKENS · 0 EGG READY    ESC]
[ HEN 1 카드      ] [ HEN 2 카드      ] [ EMPTY SPACE       ]
[  기분 막대       ] [                  ] [ ATTRACT CHICKEN   ]
[  FED TODAY       ] [                  ] [ 4 ANIMAL FEED     ]
[  EGG TOMORROW    ] [                  ] [                   ]
[ FEED | PET       ] [                  ] [                   ]
[ TAKE             ] [                  ] [                   ]
[ANIMAL FEED 15 IN BAG                 [FEED ALL] [TAKE ALL]]
```

| 영역 | 내용 |
| --- | --- |
| 동물 카드 | 아이콘, 이름, 기분 막대, 먹이 상태, 생산 상태 (준비 / 내일 / 우울해서 생산 안 함) |
| 버튼 | FEED x1 / PET / TAKE x2, 이미 한 일은 FED · PETTED로 잠김 |
| 내보내기 | RELEASE → SURE? 두 번 눌러야 실행 |
| 빈 자리 | 사료로 새 동물 불러오기, 사료가 부족하면 잠김 |
| 아래쪽 | 가방 사료 수, 모두 먹이기, 모두 꺼내기, 하루 규칙 안내, 결과 알림 |

- `GameUIManager`에 우리 창 종류를 추가하고, 요리 창과 우리 창이 같은 Scene 팝업 처리(`IGameScenePopup`)를 쓰도록 정리하였다.
- 우리 창이 없는 Scene에서는 F로 바로 수거하고 먹이를 준다.

## 6. 화면 표시

| 표시 | 내용 |
| --- | --- |
| 안내 문구 | `F - CHICKEN COOP (3/3) \| 3 EGG READY` / `F - BARN (1/2) \| 1 HUNGRY` |
| 머리 위 아이콘 | 12m 안의 동물 : 생산물이 있으면 주황 원 + 달걀·우유 아이콘, 굶었으면 빨간 허기 아이콘 |
| 월드 알림 | 동물 입주, 수거, 새 생산물 준비를 우리 위 글자로 표시 |

## 7. 요리 연결

| 요리 | 재료 (+ 나무 1) | 효과 |
| --- | --- | --- |
| FRIED EGGS | 달걀 2 | 허기 +25, 스태미나 회복 +20% (2분) |
| VEGGIE OMELETTE | 달걀 2, 토마토 1, 버섯 1 | 허기 +45, 체력 +10, 허기 감소 -30% (4분) |
| WARM MILK | 우유 1 | 허기 +10, 갈증 +30, 추위 -30% (3분) |

- 요리법이 11개로 늘어나 요리 창 목록을 마우스 휠로 넘길 수 있게 바꾸었다. (85일차 남은 문제)
- 달걀·우유가 아직 없으면 요리 생성 도구가 해당 요리법을 오류 없이 건너뛴다.

## 8. 저장

```text
hasLivestockData
livestock.pens[] { structureId, lastProcessedDay,
                   animals[] { animalId, nameNumber, mood, fedToday, pettedToday, daysSinceProduct, productReady } }
```

- 건축물 복원 뒤 우리 ID로 동물 상태를 적용한다.
- 86일차 이전 저장 파일은 빈 우리로 불러온다.
- 저장 검사 : 빈 ID, 중복 우리 ID, 6마리 초과, 기분 범위, 음수 값, 중복 개체 번호, 없는 동물 ID

## 9. 생성 도구와 테스트 메뉴

```text
Tools > Project U > Livestock > 1. Build Livestock Content (Data + Pens + UI + Recipes)
Tools > Project U > Livestock > 2. Validate Livestock Content
```

- 아이템·동물·사료 제작법, 닭장·외양간 Prefab과 건축 데이터
- 가축 관리자, 건축 목록·건축물 저장 목록·제작법 목록 연결
- 우리 창·머리 위 상태 표시 생성
- 이어서 요리 생성 도구 → 아이템 외형 생성 도구 실행 (동물 아이콘 포함)
- 코드로 UI를 만드는 부품을 `UIBuildKit`으로 분리하여 요리 창과 우리 창이 함께 사용

```text
Tools > Project U > Livestock > Debug (Play Mode) >
  Give Livestock Kit / Add Animal / Feed All (Free) / Set Mood 100 · 10 / Advance One Day / Log Nearest Pen
```

## 11. 남은 문제

- 한 우리에 한 종류만 기를 수 있다.
