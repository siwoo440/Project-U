# 프로젝트 U 개발 일지

---

## 49일차 : 보관함 데이터 구조 및 UI 구현

### 개발 목표

소형·대형 보관함의 종류와 슬롯 구성을 데이터로 관리하고, 플레이어 인벤토리와 보관함을 한 화면에서 확인할 수 있는 보관함 UI의 기반을 구현했다.

### 구현 내용

- `CraftingManager`의 기본 제작 시설을 `Hand`로 수정
- 제작·보관·건축 규칙 문서의 Markdown 구조 오류 수정
- 보관함 종류를 정의하는 `StorageTypeData` 구현
- 소형 보관함 데이터 생성
  - 표시 이름: `SMALL CHEST`
  - 슬롯 수: 12칸
  - 배치: 4열 × 3행
- 대형 보관함 데이터 생성
  - 표시 이름: `LARGE CHEST`
  - 슬롯 수: 24칸
  - 배치: 6열 × 4행
- 고정 슬롯 목록을 관리하는 `StorageContainer` 구현
- 슬롯 번호, 아이템 아이콘, 이름과 수량을 표시하는 `StorageSlotView` 구현
- 보관함별 슬롯 수와 열 개수를 자동 적용하는 `StorageContainerUI` 구현
- 플레이어 인벤토리와 보관함을 동시에 표시하는 `StoragePopup` 구성
- 보관함 열기 시 마우스 커서 활성화 처리
- Close 버튼과 ESC 입력을 통한 보관함 닫기 처리
- 보관함을 전환할 때 기존 슬롯 UI가 중복되지 않도록 재생성 처리
- 테스트용 소형·대형 보관함 오브젝트 구성

### 테스트 결과

- 소형 보관함이 12칸, 4열 × 3행으로 정상 표시됨
- 대형 보관함이 24칸, 6열 × 4행으로 정상 표시됨
- 보관함 전환 후 이전 슬롯이 중복되어 남지 않음
- 플레이어 인벤토리와 보관함이 함께 표시됨
- Close 버튼과 ESC 입력으로 팝업이 정상적으로 닫힘
- 보관함을 열고 닫을 때 마우스 잠금 상태가 정상적으로 변경됨
- 도끼와 곡괭이의 손 제작 시설 판정이 정상 작동함
- 기존 인벤토리, 핫바, 건축, 저장 및 불러오기 기능이 정상 작동함
- 저장 데이터 구조 검사 통과
- Unity Console 오류 없음

### 다음 개발 방향

50일차에는 플레이어 인벤토리와 보관함 사이의 아이템 이동 기능을 구현한다. 아이템 이동, 합치기, 교환과 수량 처리를 추가하고 두 슬롯 영역의 변경 내용을 즉시 갱신하도록 확장한다.
