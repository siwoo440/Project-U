# Project U 22일차 개발 일지

---

## 개발 목표

장비에 개별 능력치를 부여하고, 플레이어가 장비를 착용했을 때 방어력·최대 체력·이동 속도·허기·갈증 감소량에 실제로 반영되도록 구현했다.

가방 장비를 착용하면 인벤토리 슬롯이 증가하고, 장비 능력치 화면에서 현재 적용 중인 능력치를 확인할 수 있도록 구성했다.

---

## 구현 내용

### 1. 장비 능력치 데이터 추가

- 장비별 방어력 수치 추가
- 최대 체력 증가량 추가
- 이동 속도 증가율 추가
- 허기 감소 방지율 추가
- 갈증 감소 방지율 추가
- 가방 인벤토리 슬롯 증가량 추가

### 2. 장비 능력치 합산 시스템 구현

- 현재 착용 중인 모든 장비의 능력치 자동 합산
- 장비 장착·교체·해제 시 합산 결과 즉시 갱신
- 장비 변경 이벤트를 이용한 관련 시스템 갱신

### 3. 플레이어 능력치 적용

- 방어력에 따른 최종 피해량 감소
- 장비에 따른 최대 체력 증가 및 복구
- 걷기와 달리기 속도 증가
- 허기 감소 속도 완화
- 갈증 감소 속도 완화

### 4. 가방 용량 시스템 구현

- 기본 인벤토리 용량 32칸 설정
- `SMALL BACKPACK` 착용 시 슬롯 8칸 추가
- 가방 착용 시 전체 용량 40칸으로 증가
- 추가 슬롯에 아이템이 있을 때 가방 해제 차단
- 가방 교체·해제 실패 시 기존 장비와 용량 복구
- 슬롯 용량 변경 시 인벤토리 UI 재생성

### 5. 장비 능력치 UI 구현

- 현재 장비의 총 방어력 표시
- 최대 체력 증가량 표시
- 이동 속도 증가율 표시
- 허기·갈증 감소 방지율 표시
- 가방 추가 슬롯 수 표시
- 장비 변경 시 화면 즉시 갱신

### 6. 테스트용 장비 데이터 구성

| 장비 | 주요 효과 |
|---|---|
| `CLOTH CAP` | 방어력과 허기 감소 방지 |
| `WORK HAT` | 방어력과 이동 속도 증가 |
| `CLOTH SHIRT` | 방어력, 최대 체력, 허기·갈증 감소 방지 |
| `SMALL BACKPACK` | 인벤토리 슬롯 8칸 증가 |

## 현재 확인된 결과

- 가방 장착 후 추가 슬롯 8칸 생성 확인
- 전체 인벤토리 용량 32칸에서 40칸으로 증가 확인
- 장비 능력치 합산과 화면 표시 확인
- 추가 슬롯이 인벤토리 화면 아래에 생성되는 것 확인

---

## 남은 문제

- 인벤토리 보관함의 세로 스크롤이 작동하지 않음
- 실행 중 세로 스크롤바가 비활성화되는 현상 확인
- 인벤토리 영역 크기를 키워도 마우스 휠과 스크롤바 이동이 동작하지 않음
- `ScrollRect`, `Viewport`, `Content Size Fitter`, `Grid Layout Group`의 실행 중 레이아웃 계산 추가 점검 필요
- 가방 장착 후 `InventoryStorageContent` 높이가 실제 4줄 크기로 갱신되는지 확인 필요

---

## 22일차 상태

장비 능력치 시스템과 가방 용량 확장 기능은 구현되었다. 추가 슬롯도 정상 생성되지만, 인벤토리 세로 스크롤 문제는 해결되지 않아 UI 조정 작업이 남아 있다.
