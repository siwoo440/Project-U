# Project U 개발 일지

## 108일차 : 넓은 섬 다듬기 · 흙길망 · 섬 자연 · 들판 적 · 섬 전체 지도

### 1. 개발 목표

107일차에 구역을 섬 곳곳으로 옮겼지만, 그 사이는 풀밭뿐이었고 흙길도 마을에서 뻗은 곧은 길 6개뿐이었다.

- 흙길을 섬 전체를 잇는 **길망**으로 바꿨다 (구역끼리 둘레길 · 갈림길 · 구불구불한 길).
- 섬 곳곳에 **나무 · 바위 · 덤불**을 땅 모양에 맞춰 심었다.
- 흙길 옆에 **채집 나무 · 돌**, 구역 사이 들판에 **적 생성 지점**을 만들었다.
- 지도(M)에서 **섬 전체**를 볼 수 있게 했다.

실행 메뉴 : `22. Island Terrain` (모두 한 번에) · 새 메뉴 `24. Island Nature (Trees + Rocks + Field Enemies + Map)` (자연만 다시)

## 2. 흙길망 (`IslandZoneLayout`)

| 종류 | 길 | 설명 |
| --- | --- | --- |
| 큰길 6 | 마을 → 해안 · 폐허 · 숲 · 설산 · 사막 · 습지 | 마을 표지판에서 출발 |
| 둘레길 7 | 폐허 ↔ 설산 ↔ (동쪽 언덕) ↔ 해안 ↔ 사막 ↔ 남쪽 오솔길 ↔ 습지 ↔ 숲 ↔ 폐허 | 구역 터 가장자리끼리 이어 섬을 한 바퀴 |
| 갈림길 2 | 숲 큰길 → 서쪽 해변, 마을 → 석호 | |

- 모두 15개, 약 5.7km. 가장 가파른 곳 11°.
- 지나는 점 사이를 옆으로 부드럽게 흔들어 **구불구불하게** 만들었다. 마을 안은 곧게 두었다.
- 둘레길 · 갈림길 양 끝에 **표지판**을 세웠다 (예 : "설산 기슭 · 사당 → 280m").
- 길이 많아져도 지형 계산이 느려지지 않게, 길 조각을 40m 칸으로 나눠 가까운 조각만 찾는다.

## 3. 섬 자연 (`IslandNatureBuilder`)

나무를 Scene 오브젝트 수천 개 대신 **Terrain 나무**로 심었다.
- Terrain 파일에 저장되어 Scene이 커지지 않는다 (6.9 → 7.2MB).
- 800m보다 먼 나무는 자동으로 그리지 않는다.

| 땅 | 심는 것 |
| --- | --- |
| 들판 | 띄엄띄엄 나무 · 덤불 · 바위 |
| 숲 (넓은 숲 무늬) | 빽빽한 둥근 나무 · 소나무 · 단풍나무 · 덤불 · 그루터기 · 쓰러진 통나무 |
| 산비탈 (45m ~) | 소나무 · 눈 소나무 · 바위 |
| 눈 덮인 산 (120m ~) | 바위 · 얼음 바위 · 눈 소나무 |
| 해변 | 야자수 · 작은 바위 |
| 습지 둘레 | 마른 나무 |
| 가파른 곳 (36° ~) | 바위만 |

- 모두 6,877개 : 나무 4,294 · 바위 406 · 덤불 · 그루터기 2,177
- 칸(7m)마다 정해진 무작위 값을 써서, 여러 번 실행해도 같은 자리에 심는다.
- 비우는 곳 : 마을, 흙길 양옆 7m, 오솔길, 구역 터, 난파선 해변, 석호, 물
- 나무 줄기 · 바위 · 그루터기에는 부딪힌다 (Terrain 나무 충돌).
- 숲 아래에는 **숲 바닥**(짙은 풀 · 낙엽)을 칠했다. 마을 둘레는 둥글고 울퉁불퉁하게 사라진다.
- 여러 곳에서 화면에 들어오는 나무를 세어 보니 가장 많은 곳이 1,856그루였다 (기준 4,000 이하).

### 흙길 옆 채집 자원

- 흙길 옆 12 ~ 22m에 도끼로 캐는 나무 26개, 곡괭이로 캐는 돌 18개
- 저장 ID `island_res_(길)_(번호)_(tree · stone)`

### 들판의 적

- 흙길에서 50m 옆 들판 12곳 (근접형 · 원거리형 번갈아)
- 마을(220m) · 시작 해변(170m) · 구역 터 둘레 · 해안 구역에서는 멀리 둔다.

## 4. 섬 전체 지도 (`MinimapCameraController` · `WorldMapPanelView` · `MapLabelScaler`)

| 항목 | 107일차 | 108일차 |
| --- | --- | --- |
| 전체 지도 기본 범위 | 280m | 640m |
| 가장 넓게 | 440m | 2000m (섬 전체) |
| 휠 줌 | 한 칸 12m씩 | 한 칸 1.2배씩 |

- 멀리 볼수록 지도 가운데가 플레이어에서 **섬 가운데**로 부드럽게 옮겨 간다. 플레이어 화살표는 실제 자리에 표시한다.
- 지도 카메라를 북쪽 산보다 높게(260m 이상) 두어 산이 잘리지 않는다.
- 지도에서는 나무 · 풀과 날씨 · 물속 안개를 그리지 않는다 (숲 바닥 색으로 표시, 선명하게).
- 지도 이름이 지도 범위에 맞춰 커진다 (최대 6배). "난파선 해변" · "석호" 이름을 추가했다.

## 7. 남은 문제

- NPC 길(NavMesh)은 Terrain 나무를 피하지 않는다 (흙길 밖으로 갈 때 드물게 나무를 지나감).
- 전체 지도 밝기는 날씨 · 시간의 햇빛 영향을 받는다.
- 흙길 갈림목에는 표지판이 없다 (길 끝에만 있음).
- `New Terrain.asset`(약 73MB)이 GitHub 권장 크기(50MB)를 넘는다.
