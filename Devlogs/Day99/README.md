# Project U 개발 일지

## 99일차 : 메뉴 화면 디자인·설정 창·로딩 화면과 Windows 알파 빌드

### 1. 개발 목표

빌드 전에 게임의 첫 화면들을 점검했다. Scene 연결(Bootstrap → 메인 메뉴 → 게임 → 메인 메뉴 → 이어하기)은 정상이었다. 하지만 메인 메뉴는 개발 초기(7월 29일) 상태 그대로였다 (회색 배경 · Unity 기본 버튼 · 개발용 `STATE:` 글자). 설정 창은 일시정지 메뉴 안에만 있었고 항목도 3개뿐이었다. 이번에는 **메뉴 화면을 게임 UI 스타일로 새로 만들고, 공용 설정 창과 로딩 화면을 넣은 뒤 Windows 알파 빌드**를 만들었다.

- 공용 설정 창 (메인 메뉴 · 일시정지 메뉴) : 화면 모드 · 해상도 · 그래픽 품질 · 수직 동기화 · 프레임 제한 · 볼륨 · 마우스 감도
- 메인 메뉴 새 디자인 : 배경 마을 · 새 게임 · 이어하기 · 설정 · 게임 종료 · 새 게임 확인 창
- 로딩 화면 (시작 · Scene 전환)
- 생성 메뉴(17번) · 빌드 도구 · 검사

## 2. 점검에서 찾은 것

| 항목 | 내용 | 처리 |
| --- | --- | --- |
| 메인 메뉴 디자인 | 회색 배경, 기본 흰 버튼, 게임 UI와 다른 분위기 | 새로 만듦 |
| 개발용 글자 | 메인 메뉴 `STATE: MAIN MENU`, 게임 화면 `STATE: GAMEPLAY` | 기본 숨김 (`GameStateView.showStateText`) |

| 저장 정보 줄바꿈 | 칸이 좁아 `SAVE / DAY 1 /` · `08:04` 두 줄 | 새 디자인에서 한 줄 |

## 3. 설정 (`GameSettingsService` · `SettingsWindowUI`)

| 항목 | 고르는 값 | 기본값 |
| --- | --- | --- |
| 화면 모드 | FULLSCREEN (테두리 없는 전체 화면) · WINDOWED | 전체 화면 |
| 해상도 | 모니터가 지원하는 가로 1280 이상 해상도 | 모니터 해상도 |
| 그래픽 품질 | 품질 단계 (URP 품질 설정) | 가장 높은 단계 |
| 수직 동기화 | ON · OFF | ON |
| 프레임 제한 | 30 · 60 · 120 · 144 · 제한 없음 (수직 동기화가 켜져 있으면 모니터에 맞춤) | 60 |
| 마스터 볼륨 | 0 ~ 100% | 100% |
| 마우스 감도 | 0.02 ~ 0.5 | 0.10 |

- 설정은 `PlayerPrefs`에 저장하고, 게임을 켤 때(Bootstrap) 먼저 적용한다. 예전 3개 항목(볼륨 · 감도 · 전체 화면) 저장 키는 그대로다.
- 설정 창 : `<` `>` 버튼과 슬라이더로 바꾸고, **APPLY**로 저장 · 적용, **CLOSE**로 닫으면 바꾼 값을 버린다, **DEFAULTS**는 기본값을 불러온다(APPLY를 눌러야 저장).
- 메인 메뉴와 일시정지 메뉴가 **같은 설정 창 Prefab**(`PF_UI_SettingsWindow`)을 쓴다. 일시정지 메뉴의 SETTINGS 버튼이 이 창을 열고, 창을 닫거나 ESC를 누르면 일시정지 메인 화면으로 돌아간다.
- 에디터 Game 창에서는 해상도 · 화면 모드를 바꾸지 않는다 (실행 파일에서만 적용).

## 4. 메인 메뉴 (`MainMenuController` · `MenuBackdropCamera`)

```text
PROJECT U                       (배경 : 저폴리 마을, 카메라가 천천히 돈다)
SURVIVE · FARM · BEFRIEND
[ NEW GAME ]  ← 금색
[ CONTINUE ]  ← 저장이 없으면 꺼짐
[ SETTINGS ]
[ QUIT     ]
LAST SAVE · DAY 1 · 08:04
ALPHA 0.1.0                                   ESC  CLOSE WINDOW
```

- 배경 마을 : 집 · 카페 · 대장간 · 우물 · 모닥불(불꽃) · 플레이어 · 미오 · 밀키 · 베로나 · 밭과 작물 · 닭 · 소 · 울타리 · 나무 · 산 등 저폴리 모델 45개, 잔디 바닥과 흙 광장, 안개 · 따뜻한 햇빛
- 왼쪽 어두운 패널과 금색 테두리 선, 게임 UI 색 · 버튼 모양
- 저장이 있을 때 NEW GAME → 확인 창 "START A NEW GAME?" (START NEW · CANCEL)
- ESC : 설정 창 · 확인 창 닫기, 메뉴에서는 커서를 풀고 시간을 정상 속도로
- 버전은 Player Settings의 버전(`0.1.0`)을 보여 준다.

## 5. 로딩 화면 (`LoadingScreenUI` · `SceneFlowManager`)

- `00_Bootstrap`의 AppRoot 아래 로딩 Canvas를 두어 Scene이 바뀌어도 유지된다.
- 제목 · 진행 막대 · 상태 문구(`PREPARING NEW WORLD` · `LOADING SAVED GAME` · `RETURNING TO MENU`) · 도움말 6개 중 하나
- 최소 0.6초 보여 준 뒤 새 Scene 첫 화면을 그리고 서서히 사라진다.
- Bootstrap에 시작 카메라(어두운 배경)를 두어 첫 화면이 비지 않는다.
- `SceneFlowManager.IsLoading`으로 이동 중 메뉴 버튼 중복을 막는다. 일시정지 상태에서 넘어가도 시간 속도를 1로 되돌린다.

## 6. 생성 도구 · 빌드 도구

- `Tools > Project U > Build Content > 17. Menu Scenes (Boot + Main Menu + Settings + Loading)`
  - 설정 창 Prefab → 일시정지 메뉴 연결 → `00_Bootstrap`(시작 카메라 · 로딩 화면) → `10_MainMenu`(배경 마을 · 카메라 · 조명 · 메뉴 UI · 확인 창 · 설정 창) → 빌드 Scene 목록 → 검사
  - 두 Scene은 도구가 직접 저장한다. 여러 번 실행해도 같은 구성이 된다.
- `Tools > Project U > Build > Windows Alpha Build` (개발용 빌드 메뉴도 있음)
  - 빌드 전 검사 : 첫 Scene이 Bootstrap인지, 메뉴 화면 검사, 전체 콘텐츠 검사(오류가 있으면 빌드하지 않음), 회사 이름 안내
  - `Builds/Windows/Project U.exe` (Windows 64비트), 결과를 `Docs/Build/AlphaBuildReport.md`로 남긴다.
  - URP 패키지의 `.urtshader` 안내는 "알려진 Unity 메시지"로 따로 센다.
- `Validate All Content`에 **메뉴 화면** 검사를 추가했다 (설정 창 연결 · 일시정지 연결 · 빌드 Scene 순서 · Bootstrap 로딩 화면 · 메인 메뉴 구성 · 예전 메뉴가 남았는지).

## 8. 남은 문제

- 창 없는 자동 점검으로는 마우스 커서 잠금 · 실제 프레임 · 해상도 변경 화면을 확인할 수 없다. 실행 파일을 직접 켜서 확인해야 한다.
- 회사 이름이 `DefaultCompany`다. 저장 · 설정 폴더 경로(`AppData/LocalLow/DefaultCompany/Project U`)에 들어가므로 출시 전에 정해야 한다.
- 빌드 크기의 대부분은 외부 에셋(ThirdParty)이다. 쓰지 않는 에셋을 정리하면 줄일 수 있다.
- 메뉴 문구는 영어다 (한국어 · 언어 선택 없음).
- 예전 메뉴 스크립트(`SceneNavigationUI` · `MainMenuContinueUI`)와 일시정지 메뉴 안의 예전 설정 페이지는 쓰지 않지만 남아 있다.
