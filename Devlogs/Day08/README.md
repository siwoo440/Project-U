# 프로젝트 U 8일차 개발 일지

---
## 개발 목표

기존 상호작용 및 인벤토리 시스템과 연결되는 반복 채집 자원 시스템을 구현했다.

플레이어가 나무와 바위에 상호작용하여 목재와 돌을 획득하고, 소진된 자원이 일정 시간 후 다시 생성되도록 구성했다.

---
## 구현 내용

- 반복 채집 자원 관리용 `GatherableResource` 구현
- 기존 `InteractableBase`를 이용한 `F`키 채집 기능 연결
- 나무 채집 시 목재 획득 기능 구현
- 바위 채집 시 돌 획득 기능 구현
- 자원별 전체 보유 수량과 1회 획득 수량 설정
- 기존 `PlayerInventory.AddItem()`을 이용한 아이템 지급
- 인벤토리의 기존 아이템 중첩 규칙 적용
- 인벤토리가 가득 찬 경우 자원 수량이 감소하지 않도록 처리
- 자원 소진 시 외형과 Collider 비활성화
- 설정한 대기 시간 이후 자원 수량과 외형 복구
- 재생성 여부와 재생성 시간 Inspector 설정 지원
- 나무와 바위 테스트 오브젝트 및 채집 프리팹 구성
- 인벤토리와 핫바 UI에 채집 결과 즉시 반영

---
## 테스트 내용

- 나무와 바위 접근 시 상호작용 안내 문구 표시 확인
- `F` 입력마다 설정된 수량의 목재와 돌 획득 확인
- 동일 아이템의 기존 슬롯 중첩 확인
- 인벤토리와 핫바 UI의 실시간 갱신 확인
- 자원 수량 소진 시 외형과 Collider 비활성화 확인
- 설정한 시간이 지난 후 자원 재생성 확인
- 인벤토리가 가득 찬 상태에서 자원 손실 방지 확인
- 7일차 슬롯 선택·드래그·교환 기능 정상 유지 확인
- Unity Console Error 미발생 확인
