# Project U 개발 일지

## 117일차 : 광물과 제련 (광석 7종 · 보석 5종 · 도구 등급 · 용광로 · 동굴 2층 · 밤의 운석)

### 1. 개발 목표

동굴에 광물이 **돌 · 철뿐**이었다. 캘 것을 늘리고, 캔 것으로 만들 것을 만들었다.

- 광석 · 보석을 늘리고 **깊은 곳일수록 좋은 광물**이 나오게 한다 (동굴 2층).
- 좋은 광물은 **좋은 곡괭이**가 있어야 캔다 (돌 → 구리 → 철 → 강철).
- **용광로**를 지어 광석 + 석탄을 주괴로 녹이고, 주괴로 등급 도구를 만든다.
- 밤에 가끔 **운석**이 떨어져 구덩이가 생기고, 그 안에서 운석 조각을 캔다. 다 캐면 잠시 뒤 사라진다.

메뉴 없이 자동 적용(`117-mineral-items` · `117-minerals`)으로 넣었다.

## 3. 도구 등급 (`ItemData.toolTier` · `GatherableResource.requiredToolTier`)

| 등급 | 도구 | 캐는 속도 | 한 번에 더 얻는 수 |
| --- | --- | --- | --- |
| 0 | 돌 곡괭이 · 돌도끼 | 1배 | 0 |
| 1 | 구리 곡괭이 · 구리 도끼 | 1.3배 | 0 |
| 2 | 철 곡괭이 · 철 도끼 | 1.6배 | +1 |

- 은 · 수정 · 금 · 보석은 **철 곡괭이**부터, 다이아몬드는 **강철 곡괭이**부터 캘 수 있다.

## 6. 밤의 운석 (`MeteorEventManager`)

| 항목 | 내용 |
| --- | --- |
| 떨어지는 때 | 밤 22시 30분 · 확률 20% · 섬에 동시에 최대 2곳 |
| 떨어지는 곳 | 섬 가운데에서 180 ~ 640m · 바다 · 가파른 곳(22° 초과) 제외 · 플레이어에게서 120m 이상 |
| 알림 | "밤하늘에서 무언가 떨어졌어요!" · 전체 지도에 **운석** 표시 |
| 구덩이 | 그을린 자국(지름 9m)과 운석 덩어리 5개 (철 곡괭이 이상 · 하나당 운석 조각 3개) |
| 사라짐 | **다 캐면 게임 6시간 뒤 사라짐** · 캐지 않아도 3일 뒤 사라짐 |
| 저장 | 구덩이 자리 · 덩어리마다 남은 수량 · 사라지기까지 지난 시간을 저장한다 (`hasMeteorData`) |

운석 덩어리는 실행 중에 생기므로 월드 저장 목록(`WorldSaveBridge`)에서는 빼고, 운석 저장에만 담는다.

### 복사본 프로젝트 (batchmode)

117일차 Play 점검 내용

- 구리 곡괭이로는 은 광맥을 캘 수 없고, 철 곡괭이로 바꾸면 캔다 (한 번에 2개 — 등급 보너스)
- 돌 곡괭이로 석탄을 캔다
- 용광로에 구리 광석 2 + 석탄 1을 넣어 구리 주괴를 꺼낸다
- 밤에 운석이 떨어져 구덩이 · 덩어리 5개 · 지도 표시가 생긴다 (플레이어에게서 733m)
- 저장 · 불러오기 후에도 구덩이와 남은 덩어리가 그대로다
- 운석 덩어리를 다 캐서 운석 조각 15개를 얻고, 게임 7시간이 지나면 구덩이가 사라진다

점검 중 고친 것

- 보석 · 주괴 아이템 ID가 프로젝트 규칙에 어긋났다 → `resource_gem_*` · `resource_ingot_*`로 바꿨다.
- 새 광물에 판매 가격이 없어 주괴가 "팔 수 없는 요리"로 잡혔다 → 가격표에 17종을 넣었다.
- 보석 광맥 벌이가 낚시보다 높았다 → 자수정 · 에메랄드 · 다이아몬드가 다시 생기는 시간을 늘렸다.
- 운석 주괴 값이 재료 값보다 낮았다 → 170코인으로 올렸다.
- 용광로가 건축물 저장 목록에 없어 불러오면 사라졌다 → 저장 목록에도 등록했다.
- 새 아이템의 모델 · 아이콘 · 바닥 Prefab이 만들어지지 않았다 → 아이템 외형 표에 22개를 넣었다.
- 자동 적용을 처음부터 돌리면 111 · 113일차 의뢰가 없는 광물을 찾았다 → 아이템 만들기를 앞 단계로 나눴다.
- 운석 관리자가 매 프레임 일해 광장 CPU가 늘었다 → 0.5초마다 확인하게 바꿨다(멈춤 상태에서도 흐르는 실제 시간 사용).

## 9. 남은 문제

- 동굴에는 아직 적이 없다 (120일차 예정).
- 운석 구덩이에 떨어지는 연출(빛줄기 · 소리 · 흔들림)이 없다. 지금은 지도 표시와 글자 알림만 있다.
- 강철 도구 위(운석 주괴 도구)가 없다. 운석 주괴는 아직 팔거나 선물하는 용도다.
- 낚싯대 · 활은 아직 등급이 없다.
- 광석을 캐는 소리가 돌과 같다.
