# Project U 개발 일지

---

## 45일차 : 날씨·환경 상태 저장 및 복원

### 개발 목표

게임을 저장하고 불러왔을 때 현재 날씨와 남은 지속 시간까지 이어지도록 환경 저장 시스템을 확장한다. 기존에 저장되던 플레이어의 젖음과 체온도 날씨 상태와 함께 올바른 순서로 복원한다.

### 구현 내용

#### 1. 날씨 저장 데이터 확장

- 현재 날씨 저장 필드 추가
- 현재 날씨의 남은 지속 시간 저장 필드 추가
- 날씨 데이터 존재 여부를 확인하는 호환 필드 추가
- 기존 저장 버전 유지

#### 2. 날씨 상태 복원

- 저장된 날씨와 남은 지속 시간 복원
- 복원 시 무작위 날씨가 기존 값을 덮어쓰지 않도록 초기화 순서 보완
- 날짜와 시간을 먼저 적용한 뒤 날씨 상태 복원
- 복원 직후 날씨 HUD 갱신
- 날씨 변경 이벤트를 통해 파티클·안개·조명·환경음 재적용

#### 3. 플레이어 환경 상태 복원

- 저장된 젖음 수치 복원
- 저장된 체온 수치 복원
- 불러오기 직후 추위·저체온·더위·열사병 상태 효과 재적용
- 날씨와 플레이어 환경 상태가 함께 이어지도록 복원 순서 정리

#### 4. 이전 저장 파일 호환

- 날씨 데이터가 없는 기존 저장 파일 허용
- 기존 저장 파일을 불러올 때 현재 계절에 맞는 날씨 새로 생성
- 기존 위치·인벤토리·건축물·젖음·체온 데이터 유지
- 저장 데이터 버전을 변경하지 않고 호환 처리

#### 5. 저장 데이터 검증

- 저장된 날씨 값이 정의된 종류인지 검사
- 남은 날씨 시간이 유효한 양수인지 검사
- 숫자가 아니거나 무한대인 지속 시간 차단
- 저장 구조 검사 예제에 폭풍 날씨와 남은 시간 데이터 추가

### 날씨 저장 항목

| 항목 | 저장 내용 |
|---|---|
| 현재 날짜 | 현재 게임 날짜 |
| 현재 시각 | 현재 게임 시각 |
| 현재 날씨 | 맑음·흐림·비·눈·폭풍 |
| 남은 날씨 시간 | 현재 날씨가 유지될 게임 내 시간 |
| 젖음 | 플레이어의 현재 젖음 수치 |
| 체온 | 플레이어의 현재 체감 온도 |

### 테스트 결과

- 현재 날씨가 저장 데이터에 기록됨
- 현재 날씨의 남은 시간이 저장됨
- 불러오기 후 저장한 날씨가 동일하게 복원됨
- 날씨 남은 시간이 저장 지점부터 다시 진행됨
- 저장한 젖음과 체온이 정상적으로 복원됨
- 날씨 HUD가 복원된 상태로 갱신됨
- 파티클·안개·태양광·환경음이 복원된 날씨에 맞게 적용됨
- 체온 상태와 관련 불이익이 불러오기 직후 재적용됨
- 메인 메뉴의 이어하기에서도 환경 상태가 복원됨
- 날씨 데이터가 없는 이전 저장 파일도 정상적으로 불러와짐
- 저장 데이터 구조 검사 통과
- Unity Console 오류 없음

### 개발 결과

저장 시점의 날짜, 시간, 날씨, 날씨 남은 시간, 젖음과 체온을 하나의 환경 상태로 보존하도록 저장 시스템을 확장했다. 불러오기와 이어하기 후에도 날씨 연출과 플레이어 상태 효과가 저장 시점에 맞게 복구되며, 날씨 데이터가 없는 이전 저장 파일도 계속 사용할 수 있다.
