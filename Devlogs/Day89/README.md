# Project U 개발 일지

## 89일차 : 캐릭터 시트 기반 NPC 설정·대사·선물·일정 데이터와 한글 글꼴 추가

### 1. 개발 목표

89~94일차는 마을에 몬무스 NPC를 넣는 단계다. 첫날인 89일차에는 NPC를 화면에 세우기 전에 **NPC 설정 카드**를 만들었다.

이번 일차의 핵심 목표는 다음과 같다.

- 캐릭터 시트(Google Sheet) 35명을 게임 데이터로 가져오기
- 알파 마을에 배치할 대표 NPC 7명 선정
- 비어 있던 일정 · 대사 · 선물 반응 채우기
- 대사를 표시할 한글 글꼴 추가
- Game Data Registry와 전체 콘텐츠 검사에 NPC 추가

---

## 2. 캐릭터 시트 확인과 정리

| 문제 | 처리 |
| --- | --- |
| 선물 점수 `Loved / Liked / Neutral`이 `#ERROR!` | 매우 좋아함 +8, 좋아함 +4, 보통 +1 (싫어함 -5, 매우 싫어함 -10은 시트 값) |
| 35명 모두 위치 `area_tbd`, 일정 없음 | 위치 15곳과 대표 7명의 하루 일정 작성 |
| 대사가 캐릭터마다 1줄씩 | 대표 7명은 말투에 맞춰 19줄씩 추가, 나머지는 공통 대사 사용 |
| 선호 물건 대부분이 게임에 없음 (보석, 와인 등) | 게임 아이템·분류로 대신 연결 |
| 한글 글꼴 없음 | Noto Sans KR 글꼴 추가 |

- 시트의 몸무게·신체 치수와 저장용 기본값(`CharacterRuntimeState`)은 게임 설정에 쓰지 않아 가져오지 않았다.
- 시트 탭 이름에서 한글 이름과 영문 이름을 함께 가져왔다.

## 4. 데이터 구조

| 데이터 | 내용 |
| --- | --- |
| `NpcCharacterData` | ID · 이름 · 종족 · 직업 · 소개 · 외형 · 성격 · 말투 · 대표 색 · 역할 · 상호작용 · 상점/제작/영입 ID · 생일 · 집/일터 |
| `NpcGiftProfile` | 아이템별 선물 반응 5단계 (목록에 없으면 보통) |
| `NpcDialogueSet` | 처음 만남 · 인사 · 잡담 · 호감도 5단계 · 계절 · 날씨 · 선물 반응 · 생일 · 이벤트 대사 |
| `NpcScheduleData` | 요일 · 계절 · 날씨 조건별 하루 계획, 시각별 위치와 하는 일 |
| `NpcDatabase` | 전체 NPC · 일정 위치 · 호감도 규칙 (단계 기준 20/40/60/80, 선물 점수, 생일 3배, 하루 선물 1개) |
| `NpcTypes` | 역할 · 상호작용 · 호감도 단계 · 선물 반응 · 대사 종류 · 요일 · 계절 · 날씨 조건 |

- 요일은 1일차를 월요일로 치는 7일 주기다.
- 일정은 조건이 맞는 계획 중 우선순위가 가장 높은 것을 쓴다 (예: 밀키는 수요일이면 비가 와도 쉬는 날 일정).
- 인사·잡담 대사는 호감도 단계 조건을 둘 수 있다 (신뢰 이상에서만 나오는 인사 등).

| 파일 | 내용 |

- CSV를 고친 뒤 생성 도구를 다시 실행하면 반영된다.

## 6. 한글 글꼴

- Windows에 설치된 **Noto Sans KR** 가변 글꼴(SIL OFL 1.1)을 프로젝트에 복사하고 라이선스 파일을 함께 넣었다.
- 가변 글꼴의 기본 굵기는 Thin이라서, 이름 있는 굵기 번호로 **Regular**를 불러오도록 했다.
- 자주 쓰는 한글 2,350자 + 자모 + 영문·숫자·문장 부호 + 게임 대사 글자 = **2,513자**를 고정 Atlas 4장(1024×1024)에 담았다.
- TMP 공통 대체 글꼴(`TMP Settings`)에 등록해, 기존 영어 글꼴을 쓰는 UI에서도 한글이 표시된다.
- 필요한 글자가 바뀌지 않으면 다시 만들지 않고, 다시 만들 때도 기존 Asset 안의 내용만 바꿔 연결(GUID)을 유지한다.

## 7. 생성 도구와 검사

- 메뉴 : `Tools > Project U > Build Content > 7. NPC (Character Sheet + Dialogue + Gifts + Korean Font)`
- 원본 CSV → NPC 35명 · 선물 반응 · 대사 · 일정 · NpcDatabase → 한글 글꼴 → Game Data Registry 등록 순서로 실행한다.
- Game Data Registry에 NPC 분류(`char_` 접두사, 중복 검사)를 추가했다.
- `Validate All Content`에 추가한 검사
  - NPC : ID 규칙, 선물 반응(매우 좋아함·좋아함 필수), 대사 빠짐(처음 만남·인사·잡담·호감도 5단계·계절 4개·비/눈/폭풍·선물 5단계·생일), 상인의 상점 ID, 알파 NPC 7명·일정·위치, 한글 글꼴 글자·등록
  - 생활 연결 : NPC가 매우 좋아하는 선물을 게임 안에서 구할 수 있는지

## 9. 남은 문제

- NPC는 아직 화면에 나오지 않는다 (90일차 배치).
- 위치 15곳은 ID만 있고 Scene 표시 지점은 없다.
- 선호 물건 대부분은 게임 아이템으로 대신 연결했다. 꽃·꿀·보석 같은 선물용 아이템은 나중에 추가할 수 있다.
- 글꼴 파일(10MB)과 글꼴 Asset(약 9.5MB)이 저장소 용량을 차지한다.
