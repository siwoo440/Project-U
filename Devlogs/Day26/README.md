# 26일차 개발 일지

---

## 개발 주제

건축물 철거 및 재료 반환 시스템 구현과 플레이어 점프 판정 범위 수정

---

## 개발 목표

- 건축 모드에서 설치 모드와 철거 모드 전환
- 플레이어가 설치한 건축물 탐지 및 철거
- 철거 대상 시각적 강조
- 철거 시 사용 재료 일부 반환
- 인벤토리 공간 부족 시 철거 차단
- Terrain과 설치 건축물 위의 점프 지원
- `Interactable` 레이어 오브젝트 위의 점프 지원

---

## 구현 내용

### 1. 철거 모드 추가

- 건축 모드에서 `R` 키로 설치 모드와 철거 모드 전환
- 철거 모드 진입 시 설치 미리보기와 건축 그리드 숨김
- 철거 모드 종료 시 설치 미리보기와 건축 그리드 복구
- 철거 모드에서 설치·선택·회전 입력 차단

### 2. 철거 대상 탐지

- 화면 중앙에서 최대 건축 거리만큼 Raycast 실행
- `Structure` 레이어의 설치 건축물만 철거 대상으로 인식
- 자원, Terrain, 환경 오브젝트 등 일반 오브젝트 철거 방지
- `PlacedBuildObject`가 있는 건축물만 철거 허용

### 3. 철거 대상 강조

- 현재 바라보는 건축물에 노란색 반투명 재질 적용
- 다른 건축물을 바라보면 이전 대상의 원래 재질 복구
- 철거 모드 또는 건축 모드 종료 시 강조 상태 해제

### 4. 철거 재료 반환

- 설치에 사용한 `BuildRecipeData`를 건축물에 저장
- 철거 시 설정된 반환 비율에 따라 재료 반환
- 기본 반환 비율을 50%로 설정
- 반환 수량의 소수점 이하 값 버림
- 인벤토리 공간이 부족하면 반환 처리를 취소하고 건축물 유지
- 일부 재료만 먼저 반환된 경우 반환 내역을 되돌려 아이템 중복 방지

### 5. 건축 HUD 수정

- 설치 모드와 철거 모드의 현재 상태 표시
- 철거 대상 건축물 이름 표시
- 철거 시 반환되는 아이템과 수량 표시
- 설치·철거 모드 전환 및 조작키 안내 추가

### 6. 점프 판정 수정

- 건축 시스템 도입 후 `Terrain`이 `Ground` 레이어로 변경됐지만 기존 지면 판정 범위에 포함되지 않은 문제 확인
- `PlayerMovement`의 `Ground Layer Mask`에 실제 접지 가능한 레이어 추가
- Terrain 위에서 점프 가능
- 설치된 바닥 등 `Structure` 레이어 위에서 점프 가능
- 상호작용 가능한 오브젝트 위에서도 점프할 수 있도록 `Interactable` 레이어 추가
- 공중 연속 점프 차단 유지

---

## 점프 판정 레이어

| 레이어 | 용도 |
|---|---|
| `Default` | 기존 일반 바닥과 경사면 |
| `Ground` | Terrain과 지형 |
| `Structure` | 플레이어가 설치한 바닥과 건축물 |
| `Interactable` | 밟을 수 있는 상호작용 오브젝트 |

---

## 주요 입력

| 입력 | 기능 |
|---|---|
| `B` | 건축 모드 시작·종료 |
| `R` | 설치 모드·철거 모드 전환 |
| 좌클릭 | 건축물 설치 또는 철거 |
| 우클릭 / `ESC` | 건축 모드 종료 |
| `Q` / `E` | 설치 건축물 회전 |
| `Z` / `X` | 설치 건축물 변경 |
| `Space` | 점프 |

---

## 주요 수정 항목

- `BuildRecipeData.cs`
  - 철거 재료 반환 비율 추가
- `PlacedBuildObject.cs`
  - 설치에 사용한 건축 데이터 저장
  - 철거 대상 강조 및 원래 재질 복구 기능 추가
- `BuildPlacementController.cs`
  - 설치·철거 모드 전환 추가
  - 철거 대상 탐지와 제거 처리 추가
  - 재료 반환과 실패 시 복구 처리 추가
  - 철거 상태 HUD 갱신 추가
- `20_Gameplay.unity`
  - 철거용 재질과 `Structure Layer Mask` 연결
  - 플레이어의 `Ground Layer Mask` 수정
- 건축물 프리팹
  - 루트와 자식 오브젝트를 `Structure` 레이어로 통일

- 철거 시 설정된 비율만큼 재료 정상 반환
- 인벤토리 공간 부족 시 철거 차단 및 반환 내역 복구
- 자원과 일반 환경 오브젝트 철거 차단

## 완료 결과

잘못 설치한 건축물을 직접 제거하고 일부 재료를 회수할 수 있게 되어 건축 시스템의 수정 가능성과 편의성이 향상됐다. 지면 판정 레이어도 현재 월드 구조에 맞게 확장하여 Terrain, 설치 건축물, 상호작용 오브젝트 위에서 점프가 정상적으로 동작하도록 수정했다.
