## 17일차: 체력·굶주림 피해 및 사망 시스템 구현

### 개발 목표

플레이어의 체력 시스템을 추가하고, 허기가 0이 되면 굶주림 피해를 받도록 구현한다. 체력이 모두 소진되면 플레이 조작을 중지하고 사망 화면과 재시작 기능을 제공한다.

### 구현 내용

| 구분 | 구현 내용 |
|---|---|
| 체력 관리 | 최대 체력과 현재 체력 및 사망 상태 관리 |
| 공통 피해 처리 | 굶주림·적 공격·낙하·함정에 사용할 피해 함수 구성 |
| 체력 회복 | 이후 회복 아이템에서 사용할 체력 회복 함수 구성 |
| 굶주림 피해 | 허기가 0인 동안 일정한 간격으로 체력 감소 |
| 피해 중단 | 음식 섭취로 허기가 회복되면 굶주림 피해 중단 |
| 체력 HUD | 현재 체력을 게이지와 숫자로 표시 |
| 사망 판정 | 체력이 0에 도달하면 사망 상태 적용 |
| 조작 차단 | 사망 후 이동·카메라·상호작용·아이템 사용 중지 |
| 사망 화면 | 사망 안내와 재시작 버튼 표시 |
| Scene 재시작 | Retry 버튼으로 현재 Gameplay Scene 다시 불러오기 |

### 주요 변경 파일

| 파일 | 역할 |
|---|---|
| `PlayerHealth.cs` | 플레이어 체력·피해·회복·사망 상태 관리 |
| `StarvationDamage.cs` | 허기 0 상태의 주기적인 체력 피해 처리 |
| `HealthBarUI.cs` | 체력 게이지와 현재 체력 수치 표시 |
| `PlayerDeathUI.cs` | 사망 화면 표시, 조작 차단 및 Scene 재시작 |
| `20_Gameplay.unity` | 체력 HUD, 사망 화면 및 관련 컴포넌트 구성 |

### 개발 결과

- 플레이어가 최대 체력 100으로 시작한다.
- 허기가 0이 되면 일정한 간격으로 굶주림 피해를 받는다.
- 음식을 먹어 허기가 회복되면 굶주림 피해가 중단된다.
- 체력 HUD에서 현재 체력 상태를 확인할 수 있다.
- 체력은 0 아래로 감소하지 않는다.
- 체력이 0에 도달하면 플레이어가 사망한다.
- 사망 후 이동, 카메라 조작, 상호작용 및 아이템 사용이 차단된다.
- 사망 화면이 표시되고 마우스 커서가 활성화된다.
- Retry 버튼을 누르면 현재 Gameplay Scene이 재시작된다.
- 재시작 후 체력과 허기가 초기 상태로 복구된다.
