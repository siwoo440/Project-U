# Project U 개발 일지

---
## 15일차: 인벤토리 상세 UI 및 아이템 관리 기능 구현

### 개발 목표

기존 인벤토리를 핫바와 일반 보관 영역으로 분리하고, 아이템의 상세 정보를 확인하거나 제거·버리기할 수 있는 관리 기능을 구현한다.

### 구현 내용

| 구분 | 구현 내용 |
|---|---|
| 인벤토리 용량 | 전체 슬롯을 32칸으로 확장 |
| 슬롯 영역 | 상단 핫바 8칸과 하단 일반 인벤토리 24칸으로 분리 |
| 스크롤 기능 | 일반 인벤토리 슬롯 증가 시 세로 스크롤 지원 |
| 아이템 아이콘 | 등록된 아이콘 또는 분류별 대체 색상 표시 |
| 아이템 상세 정보 | 이름, 분류, 설명, 보유 수량과 최대 중첩 수량 표시 |
| 아이템 제거 | 선택한 아이템을 한 개씩 영구 제거 |
| 아이템 버리기 | 선택한 아이템을 플레이어 앞에 월드 아이템으로 생성 |
| 월드 아이템 | 버린 아이템의 종류와 수량을 유지하도록 초기화 기능 추가 |
| 팝업 조작 | `I` 키로 인벤토리를 열고 닫으며 `ESC` 키로 열린 창 닫기 |
| 게임 조작 처리 | 인벤토리가 열린 동안 플레이어 조작을 차단하고 마우스 커서 표시 |

### 주요 변경 파일

| 파일 | 역할 |
|---|---|
| `InventoryDetailUI.cs` | 선택한 아이템의 상세 정보와 버튼 처리 |
| `InventoryItemDropper.cs` | 인벤토리 아이템의 월드 드롭 처리 |
| `InventoryPopupController.cs` | 인벤토리 팝업과 ESC 입력 처리 |
| `InventorySlotView.cs` | 슬롯 아이콘과 선택 상태 표시 |
| `PlayerInventory.cs` | 32칸 슬롯 구성과 아이템 제거 기능 |
| `ItemIconUtility.cs` | 아이템 분류별 대체 아이콘 색상 제공 |
| `WorldItemPickup.cs` | 생성된 월드 아이템 데이터와 수량 초기화 |
| `WorldItemDrop.prefab` | 버린 아이템의 물리·상호작용 프리팹 |
| `20_Gameplay.unity` | 인벤토리 상세 UI와 스크롤 영역 배치 |

### 개발 결과

- 핫바와 일반 인벤토리가 하나의 팝업 안에서 구분된다.
- 슬롯이 늘어나도 일반 인벤토리 영역만 세로로 스크롤된다.
- 슬롯을 선택하면 아이템의 상세 정보가 표시된다.
- 선택한 아이템을 제거하거나 월드에 버릴 수 있다.
- 버린 아이템을 다시 상호작용하여 획득할 수 있다.
- 인벤토리가 열린 상태에서 `ESC` 키를 누르면 창이 닫힌다.
