# Project U 개발 일지

## 114일차 : 이웃끼리의 관계 (만나면 대화 · 대화 속 이웃 이야기)

### 1. 개발 목표

섬 NPC 35명이 모두 플레이어와만 이야기하고, 같은 광장에 서 있어도 서로 모르는 사람처럼 보였다. **이웃끼리의 관계**를 만들어 섬이 하나의 마을처럼 느껴지게 했다.

- 관계 있는 두 이웃이 같은 곳에서 만나면 서로 바라보며 **말풍선으로 몇 마디** 나눈다.
- 플레이어와 대화할 때 가끔 **관계 있는 이웃 이야기**를 꺼낸다.

이번에도 메뉴 없이 자동 적용으로 넣었다.

## 3. 만나면 대화 (`NpcBanterManager`)

- 조건 : 두 이웃이 **같은 일정 장소에 도착해 서 있고**(6m 안), 플레이어가 30m 안에 있을 때.
- 서로 바라보며(`NpcAgent.SetChatPartner`) 3.4초마다 번갈아 말풍선을 띄운다.
- 쌍마다 **하루 한 번**, 여러 쌍이 동시에 대화할 수 있다 (최대 4쌍).
- 플레이어와 대화 중 · 동료로 따라다니는 중 · 집 안 · 이동 중인 NPC는 끼지 않는다. 대화 도중 플레이어가 말을 걸거나 한쪽이 떠나면 멈춘다 (그날은 한 것으로 침).
- 분위기용이라 저장하지 않는다.

## 4. 대화 속 이웃 이야기 (`NpcDialogueSelector`)

- "대화하기" 순서가 나쁜 날씨 → 계절 → 호감도 단계 → 잡담 → **이웃 이야기** → 이벤트 대사로 바뀌었다.
- 예 : 하르카 "네리 예보는 잘 맞아! 내 코랑 같이 쓰면 안개 속에서도 안 헤매!"

114일차 Play 점검 내용

- 월요일 17시 반 습지 오두막 : 하르카 · 네리가 서로 바라보며(방향 일치 1.00) 대화 → 약 8초 뒤 끝, 같은 날 다시 하지 않음
- 멀리 있는 켄시아 · 사피라(사막)는 대화하지 않음
- 이웃 이야기가 대화하기 순서에 들어감
- 화요일 광장 : 네리와 대화 중이면 미오 · 네리는 기다림 → 창을 닫으면 시작 (같은 광장의 라그 · 란후아도 동시에 대화) → 미오에게 말을 걸면 멈춤
- 동료로 데려간 루네트는 끼지 않음 → 동료에서 풀려 일정 자리로 돌아가자 알리우네와 대화

점검 중 고친 것

- 처음에는 섬 전체에서 한 번에 한 쌍만 대화해, 광장에서 라그 · 란후아가 대화하면 미오 · 네리가 시작하지 못했다 → 여러 쌍 동시 대화로 바꿨다.
- 동료에서 막 풀린 NPC가 '도착해 서 있음'으로 보여 대화를 시작했다가 바로 끊겼다 → 두 NPC가 같은 일정 장소에 도착했을 때만 시작한다.

## 8. 남은 문제

- 말풍선의 긴 대사는 한 줄로 길게 보인다.
- 관계가 없는 이웃이 12명 있다.
- 35명 통합 점검(프레임 · 광장 붐빔 · 저장 크기)이 남았다.
