# Project U 개발 일지

## 120일차 : 동굴 몬스터와 첫 보스 (박쥐 · 거미 · 돌 골렘 · 수정 골렘)

### 1. 개발 목표

동굴은 넓어졌지만 **아무도 살지 않는 빈 굴**이었다. 광맥만 캐고 나오면 끝이었다.

- 동굴에 **몬스터 3종**을 넣어 광맥을 캐는 동안 긴장이 있게 한다.
- 가장 깊은 방에 **첫 보스(수정 골렘)** 를 세우고, **3단계로 변하는 싸움**을 만든다.
- 몬스터 모습을 **자세하게** 만든다 (날개막 · 꺾인 다리 8개 · 갈라진 돌몸 · 박힌 수정).
- 보스를 이기면 **수정 장비**를 만들 수 있게 하고, 깊은층 광맥이 더 빨리 되살아나게 한다.
- 추가로 플레이어 **스태미나를 두 배**로 늘린다 (칸은 100 그대로).

메뉴 없이 자동 적용(`120-cave-monster-items` · `120-cave-monsters` · `120-korean-name-fix` · `120-visual-part-fix`)으로 넣었다.

## 2. 자세한 몬스터 모델 (`StylizedModelLibrary.CaveMonsters`)

| 몬스터 | 만든 방식 |
| --- | --- |
| 박쥐 | 뼈대 3줄로 펼친 **날개막**(양면), 큰 귀 2개, 빛나는 눈, 발톱, 접힌 뒷발 |
| 동굴 거미 | **두 마디로 꺾인 다리 8개**, 눈 6개, 아래로 뻗은 독니와 독방울, 털 돋은 배 |
| 돌 골렘 | **갈라진 돌 몸통**(면마다 색이 다름), 이끼 조각, 등 돌기, 빛나는 눈, 굵은 팔다리 |
| 수정 골렘 | 돌 골렘 몸에 **어깨 · 등 수정 6개**, 가슴의 **수정 심장**, 수정 왕관, 빛나는 금 |
| 수정 조각 | 보스가 부르는 작은 수정 덩이 (다리 3개 · 빛나는 심) |
| 수정 문 | 보스 방을 막는 문 (수정 기둥 · 가로대 · 가운데 눈) |

- 돌 골렘과 수정 골렘은 **몸통 만드는 함수를 함께 쓴다**(`BuildGolemBody`). 수정 골렘은 여기에 수정 장식만 더한다.
- 몬스터·전리품·장비 모델 **12종**을 새로 등록했다 (박쥐 날개 · 독니 · 수정 심장 · 수정 검 · 수정 갑옷 · 날아가는 수정).
- 몬스터는 외형 카드(Visual Profile) 체계를 쓰지 않으므로, Prefab을 만들 때 카드 부품을 먼저 지운다(`RemoveVisualProfileParts`).

## 3. 어둠과 횃불 (`CaveMonsterSense`)

| 몬스터 | 체력 | 공격력 | 어두울 때 알아챔 | 횃불을 들면 | 사는 곳 | 수 |
| --- | --- | --- | --- | --- | --- | --- |
| 박쥐 | 30 | 6 | 8m | 18m | 입구층 (공중) | 17곳 |
| 동굴 거미 | 48 | 9 | 7m | 15m | 입구층 | 17곳 |
| 돌 골렘 | 130 | 18 | 9m | 16m | 깊은층 | 4곳 |
| 수정 골렘(보스) | 600 | 22 | 16m | 18m | 깊은층 가장 안쪽 | 1곳 |

- 멀리 있으면 몬스터는 **잠들어 있다**(전투 기능을 끈다). 0.3초마다 거리만 확인해서 가볍다.
- **횃불을 들면 두 배 가까이 멀리서 나를 본다.** 밝게 보는 대신 위험해지는 선택이 생겼다.
- 박쥐는 `CaveBatFlight`로 공중에서 위아래로 흔들리며 기우뚱 난다.
- 방마다 한 마리씩 놓아 동굴 전체에 **38마리**가 된다 (너무 붐비지 않게 조절).

## 4. 첫 보스 싸움 (`CaveBossController`)

| 단계 | 조건 | 하는 일 |
| --- | --- | --- |
| 1단계 | 시작 | 팔 휘두르기 (공격력 22 · 거리 3m) |
| 2단계 | 체력 66% 이하 | **수정 파편을 던진다** (원거리 공격 추가) |
| 3단계 | 체력 33% 이하 | **수정 조각 4마리를 부른다** |

- 보스 방 18m 안으로 들어가면 **수정 문이 닫히고** "수정 골렘이(가) 깨어났다!"가 뜬다.
- 방에서 **멀리(32m) 달아나면** 싸움이 끝나고 보스는 체력을 되찾는다. 다시 들어가면 처음부터.
- 이기면 문이 열리고 **수정 심장 1 · 다이아몬드 1~2 · 수정 3~5**가 떨어진다.
- 보상으로 **깊은층 광맥이 30% 빨리 되살아난다**(`GatherableResource.SetRespawnDelay`).
- 격파 여부를 저장한다 (`CaveBossSaveBridge` · `hasCaveBossData`). 한 번 이기면 다시 나오지 않는다.

## 7. 스태미나 2배 (`PlayerStamina`)

칸은 **100 그대로** 두고, **쓰는 양을 절반**으로 만들어 실제로 두 배 버티게 했다 (`capacityMultiplier = 2`).

| 항목 | 이전 | 지금 |
| --- | --- | --- |
| 계속 달리기 | 5초 | **10초** |
| 스태미나 20짜리 행동 | 5번 | **10번** |
| 최대치 표시 | 100 | 100 (그대로) |

- 달리기 · 헤엄 · 회피 · 공격 · 활 · 농사 도구 · 낚시까지 **스태미나를 쓰는 모든 곳**이 한 곳(`PlayerStamina`)을 지나가므로 한 번에 적용됐다.
- 체온 · 음식 효과 · 탈진(20 아래) 규칙은 그대로다. 저장 값도 그대로라 예전 저장도 그대로 열린다.

## 8. 한글 이름 목록 되살리기 (`ItemKoreanNameBuilder.FillMissing`)

119일차 아이템 **32개의 한글 이름 줄이 목록(csv)에서 사라져** "한글 이름이 없습니다" 오류가 났다.

- 사라진 32줄을 아이템에 저장된 이름으로 되살렸다 (목록 149줄 · 아이템 148종과 일치).
- 앞으로 또 사라지면 **자동 적용 때 스스로 메운다.** 아이템에는 이름이 있고 목록에만 없는 줄을 다시 써 넣는다.
- 확인용 단계 `120-korean-name-fix`를 자동 적용 목록에 넣었다.

## 9. 동물 Prefab 오류 고치기 (`ContentVisualPartCleaner`)

점검 중에 **야생동물이 나올 때마다 오류가 나고 있던 것**(동물 한 마리당 오류 1줄, 한 판에 26줄)을 찾았다. 118일차에 동물에서 외형 카드를 뗄 때 **지우는 순서가 틀려** 부품 두 개가 남아 있었다.

- 외형 카드 부품은 서로를 요구하므로 **바깥쪽부터** 지워야 한다 (자료 연결 → 카드 연결 → 카드 묶음 → 이름표).
- 순서를 고치고, 지우는 코드를 한 곳(`ContentVisualPartCleaner.RemoveParts`)으로 모아 동굴 몬스터도 같은 것을 쓰게 했다.
- 이미 만들어진 동물 Prefab 10개를 고치는 단계 `120-visual-part-fix`를 넣었다.
- **전체 콘텐츠 검사에 「외형 카드 부품」 항목을 새로 넣어** 앞으로 같은 실수가 바로 걸리게 했다.

| 한글 이름 자동 복구 점검 | **5/5 통과** (5줄을 지워도 스스로 되살림) |
| 예전 점검 27개 | 전부 통과 (모두 오류 로그 0) |
| 자동 적용 사슬 처음부터 | 16개 적용 · 문제 없음 (경고 0개) |
| 밸런스 | 동굴 몬스터 1분 19.5코인 (낚시 95코인의 21%) · 적 사냥 35.3 · 야생동물 35.5 |

120일차 Play 점검 내용

- 어두운 곳에서 12m 떨어진 박쥐는 나를 모르고, 5m로 가면 깨어나 달려온다
- 박쥐를 잡으면 박쥐 날개가 떨어진다
- 보스 방에 들어가면 수정 문이 닫히고 보스가 깨어난다
- 체력 49%에서 2단계가 되어 수정 파편을 던진다
- 체력 33% 아래에서 수정 조각 4마리를 부른다
- 이기면 문이 열리고 수정 심장이 떨어진다
- 깊은층 광맥 되살아나는 시간이 60초 → 42초로 줄어든다
- 저장하고 다시 불러와도 보스는 다시 나오지 않는다

점검 중 고친 것

- 적 ID가 외형 ID 규칙(`enemy_`)에 맞지 않았다 → 이름 규칙에 맞게 바꿨다.
- 방마다 두 마리는 너무 붐비고 수입도 많았다(1분 482코인) → 한 마리씩으로 줄이고 동굴 수입을 따로 세게 했다.
- 보스 탐지 거리가 낚시터 간격 규칙에 걸렸다 → 보스·수정 조각을 16~18m로 낮췄다.
- 사피라 의뢰 보상이 파는 값보다 낮았다 → 72 → 92코인.
- 몬스터 Prefab에 외형 카드 부품이 남아 데이터 점검에 걸렸다 → 카드 부품을 먼저 지우게 했다.
- 동굴 안으로 곧바로 옮기면 해안 보호가 플레이어를 밖으로 끌어냈다 → 점검이 동굴 입구를 거쳐 들어가게 고쳤다.
- 야생동물이 나올 때마다 오류가 한 줄씩(한 판 26줄) 찍히고 있었다 → 외형 카드 부품 지우는 순서를 고쳤다 (9번 항목).

## 11. 남은 문제

- **보스는 한 번 이기면 다시 나오지 않는다** (재도전이 없다).
- 몬스터가 **움직이는 동작이 없다** (날갯짓 · 다리 움직임 · 공격 자세).
- 보스 체력이 일반 적과 같은 작은 막대로만 보인다 (전용 보스 화면 없음).
- 동굴 전투 음악 · 몬스터 소리가 없다.
- 덫에 걸린 동물 상태가 아직 저장되지 않는다 (118일차에서 넘어온 문제).
