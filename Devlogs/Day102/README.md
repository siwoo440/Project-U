# Project U 개발 일지

## 102일차 : 2차 NPC 가게 · 제작 주문

### 1. 개발 목표

101일차에 섬에 자리 잡은 2차 NPC 7명에게 **가게**와 **제작 주문**을 붙였다. 이제 7명 모두 대화 창에 거래 버튼이 나오고, 상인 창에서 물건을 사고팔 수 있다. 6명은 재료와 수수료를 받고 그 자리에서 물건을 만들어 준다.

| NPC | 가게 | 대표 물건 | 제작 주문 |
| --- | --- | --- | --- |
| 벨라모르타 | 연금술 공방 | 활력 물약 | 약초 차 + 버섯 → 물약 |
| 아라크네 | 지하 공방 | 거미 실 · 천 모자 · 천 셔츠 | 풀 섬유 → 거미 실 → 모자 · 셔츠 |
| 미루 | 말랑 젤리 가게 | 달콤한 젤리 | 딸기 · 열매 + 물 → 젤리 |
| 카스미 | 사당 공양소 | 유부초밥 | 없음 (제작 역할 없음) |
| 세이라 | 해독제 서고 | 해독제 | 버섯 + 약초 차 → 해독제 |
| 피피 | 고철 폐품상 | 고철 부품 · 도끼 · 곡괭이 | 광석 + 돌 → 고철 부품 → 화살 · 작은 가방 |
| 사피라 | 사막 조제 천막 | 사막 연고 | 약초 차 + 풀 섬유 → 연고 |

## 3. 가게 7곳 (`NpcShops.csv` · `NpcShopStock.csv`)

- 영업 시간은 따로 정하지 않고 **NPC 하루 일정**을 따른다. 주인이 일터나 마을 광장에 있을 때만 문을 연다 (예 : 세이라는 도서관에 있을 때만).
- 가게마다 매일 파는 물건 3종 이상, 관계 단계로 잠긴 물건(호기심 · 신뢰), 가끔 들어오는 물건을 넣었다.
- 가게마다 사 주는 물건이 다르다 (벨라모르타 버섯 1.3배, 아라크네 풀 섬유 2배, 피피 돌 · 나무 1.5배 등).
- 캐릭터 말투대로 인사 3줄 · 마감 인사를 넣었다.
- 되팔기 검사 : 가장 싸게 살 수 있는 값이 판매 상자 · 다른 가게에 되파는 값보다 높아야 한다. 검사 중 카스미의 토마토가 너무 싸서 베로나 의뢰를 사서 전달하면 이익이 나는 것을 찾아 14 → 18코인으로 올렸다.

## 4. 제작 주문 (`NpcCraftBook` · `NpcCrafts.csv`)

- NPC마다 **제작 주문서**가 있다. 주문 하나는 결과 물건 · 수량 · 재료 · 수수료 · 필요 관계 단계로 이루어진다.
- 주문하면 재료와 수수료를 내고 그 자리에서 물건을 받는다. 관계 단계가 오르면 가게 할인율만큼 수수료도 싸진다.
- 주문 16개 : 2차 6명 15개 + 드라비아 2개 (호기심부터 쇠도끼, 처음부터 화살 20개)
- 신뢰 단계 대량 주문 : 물약 3개 · 연고 3개, 피피의 작은 가방(고철 부품 + 거미 실 + 풀 섬유)
- 안전 장치 : 영업 시간이 아니면 주문 불가, 코인이 모자라면 재료를 빼지 않음, 가방이 가득 차면 재료를 되돌림
- 재료를 가게에서 사서 맡겨도 이익이 나지 않는지 검사한다.

## 5. 상인 창 제작 탭 (`ShopPopupUI`)

- BUY · SELL 옆에 **CRAFT 탭**을 추가했다. 제작 주문서가 있는 가게에서만 보인다 (카스미 · 밀키 · 리첼은 숨김).
- 목록 : 결과 물건 · 결과 수량 · 재료 상태(MATERIALS READY / MISSING n) · 수수료, 잠긴 주문은 "'신뢰' 단계부터 주문할 수 있어요"
- 상세 : 재료마다 가진 수 / 필요 수 (모자라면 빨강), 수수료(할인 전 값에 줄), 주문 버튼 (CRAFT · 20)
- 제작 탭에서는 주인의 제작 한마디가 나온다 ("재료를 두고 가요. 달이는 건 제 몫이니까.").
- Tab 키 : 사기 → 팔기(가격표) → 제작 → 사기
- 탭 폭을 190 → 150으로 줄여 세 칸을 넣었다.

## 8. 남은 문제

- 루네트는 제작 역할이 있지만 상점이 없어 제작 탭을 쓸 수 없다. 상점 없는 제작 NPC용 창은 나중에 만든다.
- 87일차 판매 상자 Play 점검은 92일차에 가판대가 리첼 상점으로 바뀐 뒤로 씨앗 사기가 되지 않는다 (이번 변경 전과 결과 같음). 점검을 리첼 기준으로 고쳐야 한다.
- 2차 NPC 7명은 아직 의뢰 · 하트 이벤트가 없다.
- 제작은 한 번에 한 주문씩이다 (여러 번 반복 주문 없음).
