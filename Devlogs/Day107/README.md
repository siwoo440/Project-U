# Project U 개발 일지

## 107일차 : 구역을 섬 곳곳으로 넓히기 · 흙길 · 섬 전체 NavMesh · 먼 NPC 빠른 이동

### 1. 개발 목표

105일차에 섬이 지름 1.6km로 커졌지만, 100일차에 만든 여섯 구역은 모두 마을 바로 옆(가운데에서 약 100m)에 모여 있었다.

- 구역을 섬 곳곳의 어울리는 자리로 **통째로 옮겼다**.
- 마을에서 각 구역까지 **흙길과 표지판(거리 표시)** 을 냈다.
- NPC가 섬 어디든 걸어갈 수 있게 **NavMesh를 섬 뭍 전체**로 넓혔다.
- 멀리 사는 NPC가 일정에 늦지 않게, 플레이어에게 **안 보이는 동안 빠르게 이동**하게 했다.

실행 메뉴 : `22. Island Terrain` (지형 → 구역 → NPC 배치 → NavMesh → 수영까지 한 번에)

## 2. 새 구역 자리 (`IslandZoneLayout`)

섬 높이를 조사해서 완만한 땅을 골랐다. 방향은 예전 구역 방향과 비슷하게 맞췄다.

| 구역 | 예전 자리 | 새 자리 (가운데) | 터 높이 | 마을에서 흙길 |
| --- | --- | --- | --- | --- |
| 해안 · 부두 | 마을 동쪽 석호 (94, 4) | **동쪽 진짜 해변** (759, 4) | 0m | 약 710m |
| 설산 기슭 · 사당 | 마을 북쪽 (26, 100) | **북쪽 산 바로 아래** (0, 320) | 16m | 약 270m |
| 고대 폐허 | 마을 북서쪽 (-78, 78) | 북서쪽 들판 (-325, 325) | 13m | 약 390m |
| 깊은 숲 | 마을 서쪽 (-88, -32) | 서쪽 언덕 앞 (-330, 50) | 11m | 약 300m |
| 안개 습지 | 마을 남서쪽 (-60, -94) | 남서쪽 낮은 땅 (-320, -240) | 10m | 약 350m |
| 붉은 사막 | 마을 남동쪽 (78, -86) | 남동쪽 (436, -283) | 12m | 약 450m |

- 구역 코드는 예전 좌표("설계 좌표") 그대로 두고, 구역마다 정한 거리만큼 옮긴다.
  - 옮기는 것 : 소품, 집 7채, NPC 위치 27곳, 적 생성 지점 2곳, 지도 이름, 물가 검사.
- 옮긴 뒤 소품을 땅 높이에 맞춘다. 해안은 높이 0 그대로다.
- 바닥 칠하기(모래 · 눈 · 진흙 · 돌바닥 · 숲 흙)도 설계 좌표로 바꿔 계산해서 새 자리에 같은 모양으로 칠한다.

### 지형 다듬기 (섬 높이 = 자연 지형 + 구역 터 + 흙길)

- **구역 터** : 구역 크기의 타원 안은 평평하게 하고, 가장자리 40m는 자연 지형으로 부드럽게 잇는다.
- **해안 구역**
  - 설계 x 100(예전 바닷가)을 동쪽 물가에 맞췄다.
  - 뭍은 높이 0, 부두 앞은 배가 뜨는 깊은 물(수면 아래 약 2.4m)로 팠다.
- **흙길 6개 (총 2562m)**
  - 마을 표지판 → 예전 입구 → 새 입구로 이어진다.
  - 길 높이는 앞뒤 20m를 평균 내서 고르게 하고, 가장 가파른 곳을 10°로 제한했다.
  - 마을 평지(높이 0)는 건드리지 않는다.
- 석호는 헤엄치고 진주를 줍는 연못으로 남겼다. 부두가 떠난 자리에는 **작은 선착장과 작은 배**를 두었다.
- 마을 표지판에 거리를 적었다 (예 : "고대 폐허 → 390m").

## 3. 섬 전체 NavMesh

- 굽는 범위를 가운데 280m에서 **섬 뭍 전체 1800m**로 넓혔다.
- 수면 바로 위(-0.4m)부터만 굽는다. 바다 밑 · 석호 · 항구 물속은 걸을 수 없다.
- NavMesh 파일은 1.6MB로 작다 (넓은 들판은 큰 칸으로 만들어짐).
- 22번 메뉴 전체는 약 30 ~ 40초 걸린다.

---

## 4. 먼 NPC 빠른 이동 (`NpcAgent`)

게임 1시간 = 25초라서, NPC 걷는 속도(약 2.2m/s)로 450m를 가면 약 8시간이 걸린다.

| 상황 | 속도 |
| --- | --- |
| 플레이어에게서 60m보다 멂 (안 보임) | 걷기의 16배 (약 35m/s) |
| 보이는 곳에서 남은 길이 40m보다 긺 | 서둘러 걷기 (1.8배) |
| 가까운 곳 · 도착 직전 | 보통 걷기 |

- 아주 먼 길을 중간까지만 찾으면(부분 경로) 이어서 다시 찾고, 끝내 못 가면 목적지로 옮긴다.
- 일정 이동 시간 검사도 이 속도(플레이어가 한쪽 끝에 있다고 보고)로 계산한다.
  - 209구간 모두 제시간 안에 도착한다. 가장 먼 이동은 2.5시간 (미루 : 마을 광장 → 습지 집).

## 5. 검사

- 새 구역 검사 (`새 구역 · 특수 체형`)
  - 구역이 섬 자리로 옮겨졌는지
  - 구역 터 가운데가 평평한지 (가장 큰 차이 0.03m)
  - 내륙 구역이 바닷가에서 80m 넘게 떨어졌는지
  - 흙길 경사 15° 이하 (가장 가파른 곳 10°)
  - 석호 선착장이 있는지
  - 마을 → 새 입구 NavMesh 길이 이어지는지
- 무인도 검사 : NavMesh 범위가 섬 뭍 전체(수면 위)인지
