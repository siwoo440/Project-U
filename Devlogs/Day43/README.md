# 프로젝트 U 개발 일지

---

## 43일차 : 모닥불 열기 및 장비 방한 시스템 구현

### 개발 목표

42일차에 구현한 체온·저체온 시스템에 플레이어가 추위에 대응할 수 있는 수단을 연결했다. 기존 모닥불은 주변 열원으로 확장하고, 장착 장비에는 환경에 의한 체온 감소를 완화하는 방한 능력치를 추가했다.

### 구현 내용

- 장비 아이템 데이터에 `Cold Resistance Percent` 능력치 추가
- 장착 중인 모든 장비의 방한 능력치 합산
- 전체 방한 능력치를 최대 `80%`로 제한
- 장비 능력치 UI에 `COLD RESIST` 항목 표시
- 방한 능력치에 따라 계절·날씨·야간·젖음으로 발생하는 체온 감소량 완화
- 조리 중인 모닥불 주변 `4m` 범위에 열기 적용
- 모닥불 열기로 초당 체온 `4` 회복
- 열기 수신 중 저체온 피해 일시 정지
- 체온 HUD에 `WARMING` 상태와 전용 색상 표시
- 모닥불 선택 시 Scene View에 열기 범위 Gizmo 표시
- 기존 모닥불 조리 상태와 장비 저장·복원 구조 재사용

### 방한 장비 설정

| 장비 | 방한 능력치 |
|---|---:|
| 천 모자 | `10%` |
| 천 셔츠 | `25%` |
| 작업 모자 | `5%` |
| 소형 배낭 | `0%` |

천 모자와 천 셔츠를 함께 착용하면 전체 방한 능력치는 `35%`가 된다.

### 모닥불 열기 설정

| 항목 | 값 |
|---|---:|
| 열기 적용 반경 | `4m` |
| 초당 체온 회복량 | `4` |
| 열기 상태 문구 | `WARMING` |
| 열기 적용 조건 | 모닥불 조리 진행 중 |

### 테스트 결과

- 장비 착용과 해제 시 전체 방한 능력치 즉시 재계산
- 같은 추위 조건에서 방한 수치에 비례해 체온 감소 속도 완화
- 조리 중인 모닥불 범위 안에서 체온 회복
- 모닥불 범위 밖이나 조리 종료 후 열기 적용 중지
- 열기 수신 중 `WARMING` 문구와 전용 색상 표시
- 열기 수신 중 저체온 피해 정지
- 저장 데이터 불러오기 후 장비 방한 수치 정상 복원
- 조리 상태 복원 후 모닥불 주변 체온 회복 재개
- Console 오류 없음

### 완료 결과

플레이어는 계절·날씨·젖음으로 발생하는 추위에 방한 장비와 모닥불을 이용해 대응할 수 있게 되었다. 체온 감소, 장비 방한, 열기 회복, HUD 상태 표시가 하나의 생존 흐름으로 연결되었다.
