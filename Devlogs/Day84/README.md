# Project U 개발 일지

## 84일차 : 아이템 모델·아이콘·손에 든 외형 적용

### 1. 개발 목표

원래 84일차는 요리 콘텐츠였지만, 아이템 창에 그림이 없고 일부 아이템은 모델도 없어 이를 먼저 정리하였다.
모든 아이템이 가방(아이콘), 바닥(월드 아이템), 손(들고 있는 모습)에서 제 모양으로 보이게 하는 것이 목표이다.

조사 결과

| 문제 | 해당 아이템 | 증상 |
| --- | --- | --- |
| 아이콘 없음 | 39종 전부 | 가방·핫바·보관함·장비창에 분류 색 네모와 이름만 표시 |
| 바닥용 Prefab 없음 | 돌도끼, 곡괭이, 활, 화살, 구운 사과 | 버리거나 불러오면 기본 자루 모양 |
| Prefab 미등록 | 사과, 베리, 붕대, 천 모자, 셔츠, 작은 배낭, 작업 모자, 물병, 허브차, 철 도끼, 나무 | 버리거나 불러오면 기본 자루 모양 |
| 저폴리 모델 없음 | 구운 사과 | 모델 도감에 없음 |
| 손에 든 외형 없음 | 도구 5종을 제외한 33종 | 들어도 손에 아무것도 없음 (철 도끼는 돌도끼 모양) |

---

## 2. 모델 보강

| 모델 | 내용 |
| --- | --- |
| `item_baked_apple` | 나무 접시 위 구운 사과, 캐러멜과 김 |
| `item_arrow_bundle` | 끈으로 묶은 화살 세 개 |

- 새 색상 `AppleBaked`, `Caramel`을 추가하였다.
- 아이템 ID와 모델 ID 연결 표를 만들었다. 표에 없는 새 아이템은 등록된 바닥용 Prefab의 모델 기록을 사용한다.

---

## 3. 바닥용 Prefab과 등록

- 없던 5종은 기본 템플릿으로 새로 만들었다. (`Prefabs/Items/Day84`)
- 기존 Prefab이 있던 11종은 월드 아이템 Registry에 등록하였다.
- Registry 23개 → 39개. 이제 버리기·불러오기에서 모든 아이템이 제 모델로 나온다.
- 인벤토리 버리기 기능이 기본 자루 대신 아이템별 Prefab을 사용하도록 수정하였다.

버리기 테스트 중 발견한 기존 문제도 함께 고쳤다.

| 문제 | 원인 | 수정 |
| --- | --- | --- |
| 버린 아이템이 8~14m 굴러감 | 구 모양 충돌체가 앞으로 던져진 뒤 계속 구름 | 회전 고정, 질량과 무관한 속도로 던지기 |
| 연속으로 버리면 서로 튕겨 나감 | 같은 위치에 겹쳐 생성 | 생성 위치를 옆으로 조금 흩뜨림 |

## 4. 아이콘 자동 생성

```text
저폴리 모델 Prefab
→ 미리보기 전용 Scene에서 검은 배경 / 흰 배경으로 두 번 촬영 (512px)
→ 두 결과의 차이로 투명도 계산
→ 128px로 줄이고 옅은 그림자 추가
→ UI/Icons/Items/ICON_{아이템ID}.png 저장 → Sprite → ItemData.icon 연결
```

| 결정 | 이유 |
| --- | --- |
| 두 배경 촬영 | 렌더 파이프라인의 알파 출력과 무관하게 깔끔한 투명 배경 |
| 4배로 찍고 축소 | 가장자리를 부드럽게 |
| 꼭짓점 기준 화면 맞춤 | 모델 크기와 관계없이 칸에 꽉 차게 |
| 모델별 구도 | 도구·활은 대각선, 셔츠는 위에서, 물고기는 옆으로 누운 모델이라 위에서 촬영 |
| 한 번의 촬영 세션 | 미리보기 Scene을 반복해서 만들면 Batchmode에서 멈추는 문제가 있어, 촬영을 모두 끝낸 뒤 가져오기 |

## 6. 손에 든 외형

| 아이템 | 방식 |
| --- | --- |
| 돌도끼·곡괭이·괭이·물뿌리개·낚싯대 | 기존 전용 외형 |
| 활 | 새 전용 외형, 휜 몸체가 정면을 향함, 장전 중 시위에 화살 표시 |
| 그 밖의 33종 (철 도끼 포함) | `HeldItemVisuals` 목록, 처음 들 때 한 번 만들고 재사용 |

- 긴 도구는 돌도끼와 같은 자세로, 작은 아이템은 모델 중심을 손 기준점에 맞춘다.
- 크기는 종류별로 자동 계산한다. (음식·씨앗 0.2m, 장비 0.3m, 물고기 0.4m 등)

- 인벤토리 팝업의 장비 칸·제작 목록 글자가 36pt로 서로 겹쳐 보인다. (기존 Prefab 설정)
