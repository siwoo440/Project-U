# Project U 개발 일지

## 97일차 : 무기 외형 1인칭·3인칭 분리(돌도끼·활·휘두르기·장전 화살) 구현

### 1. 개발 목표

지금까지 손에 든 도구 모양은 몸 옆 거치대(ToolHolder)에 붙은 한 가지뿐이었다. 1인칭(V키)으로 바꾸면 몸 외형은 숨겨지지만, 도구는 몸 옆 자리에 그대로 있어서 화면에 제대로 보이지 않았다. 이번에는 무기 하나에 **3인칭(몸 옆) · 1인칭(화면 앞) 모양을 따로** 두고, 시점에 맞는 모양 하나만 보이게 했다. 먼저 돌도끼와 활에 적용했다.

- 무기 외형 설정(Visual Profile)에 3인칭 · 1인칭 위치 · 회전 · 크기 칸 추가
- 장착 외형이 시점에 따라 3인칭 · 1인칭 모양 전환
- 1인칭 휘두르기 · 활 장전 화살 따라가기
- 생성 메뉴(15번) · 검사

---

## 2. 무기 외형 설정 (`ContentVisualProfile` · Held Views)

| 칸 | 내용 |
| --- | --- |
| Use Held Views | 켜고 외형 모델(Visual Prefab)이 있으면 이 방식을 쓴다 |
| 3인칭 위치 · 회전 · 크기 | 몸 옆 도구 거치대(ToolHolder) 기준 |
| 1인칭 위치 · 회전 · 크기 | Camera 앞 무기 거치대(FirstPersonToolHolder) 기준 |

| 무기 | 외형 설정 | 모델 | 1인칭 |
| --- | --- | --- | --- |
| 돌도끼 (`tool_axe`) | `VP_Weapon_Axe` · `visual_weapon_axe` (96일차) | `LP_tool_stone_axe` | 화면 오른쪽 아래, 앞으로 38° 기울임, 크기 0.55 |
| 활 (`weapon_bow`) | `VP_Weapon_Bow` · `visual_weapon_bow` (새로 만듦) | `LP_tool_bow` | 화면 왼쪽 아래, 옆으로 14° 기울임, 크기 0.46 |

- 3인칭 값은 지금 몸 옆에 붙은 저폴리 모델(`AxeVisual` · `BowVisual`)의 위치를 그대로 읽어 와서, 3인칭 모습은 예전과 같다.
- 1인칭 값은 "잡는 곳 위치 + 기울기 + 크기"로 계산한다. 화면 캡처를 보고 처음 값(도끼 0.72 · 활 0.62)이 화면을 너무 가려서 한 번 줄였다.

## 3. 장착 외형 (`EquippedToolView`)

- 도끼 · 활을 들면 아이템 ID로 무기 외형 설정을 찾는다 (`tool_axe` → `visual_weapon_axe`, 96일차 규칙).
- 3인칭 : 몸 옆 거치대에 모델을 붙이고, 예전 전용 외형(`AxeVisual` · `BowVisual`)은 숨긴다.
- 1인칭 : Camera 앞 거치대에 모델을 붙이고 3인칭 모양은 숨긴다. V키로 시점을 바꾸면 바로 바뀐다.
- 1인칭 무기는 그림자를 끄고(공중에 뜬 그림자 방지) 충돌체를 없앤다.
- 모델은 처음 들 때 한 번만 만들고 다시 쓴다.
- 외형 설정이 없는 도구(곡괭이 · 괭이 · 물뿌리개 · 낚싯대)와 그 밖의 아이템은 예전 그대로다.

### 1인칭 휘두르기 (`ToolSwingAnimation`)

- 도끼를 휘두르면 1인칭 거치대도 같은 방향으로 돈다. 화면을 가리지 않게 3인칭 회전의 60%만 돌린다.

### 활 장전 화살

- 활을 당길 때 켜지는 장전 화살(`NockedArrow`)은 예전 `BowVisual`의 자식이라 새 활 외형에서는 보이지 않았다.
- 활 외형 설정을 쓰면 장전 화살을 보이는 활 모델로 옮겨 붙인다. 3인칭에서는 예전과 같은 자리(오차 0), 1인칭에서는 1인칭 활에 같은 상대 위치로 붙는다.
- 다른 아이템을 들면 원래 자리로 돌아간다.

## 4. 생성 도구 · 검사

- `Tools > Project U > Build Content > 15. Weapon Views (Axe + Bow 1st/3rd Person)`
  - 도끼 · 활 외형 설정(3인칭 · 1인칭) → 등록 목록 다시 모으기 → `Main Camera/FirstPersonToolHolder` 만들기 → 장착 외형 · 휘두르기 연출 · 장전 화살 연결 → 검사
  - 여러 번 실행해도 결과가 같다.
- `Validate All Content`에 **무기 외형** 검사를 추가했다.
  - 외형 설정 ID · 분류 · 모델 · 손 외형 켜짐 · 크기, 아이템 → 외형 설정 연결, 등록 목록
  - Scene : Camera 관리자 · 1인칭 거치대(Camera 아래) · 외형 설정 · 휘두르기 연출 · 장전 화살 연결
- 데이터 점검(96일차)이 장착 외형에 연결된 무기 외형 설정도 "쓰는 곳"으로 센다. "도끼 외형 설정을 쓰는 곳 없음" 경고가 사라졌다.

## 6. 남은 문제

- 1인칭 모양은 도끼 · 활만 있다. 곡괭이 · 괭이 · 물뿌리개 · 낚싯대 · 철 도끼는 1인칭에서 예전처럼 몸 옆 자리에 있다.
- 1인칭 무기는 벽에 가까이 가면 벽을 뚫고 보일 수 있다 (무기 전용 Camera 없음).
- 손 · 팔 모델이 없어 1인칭에서는 무기만 떠 있다.
- 활을 당길 때 활시위가 당겨지는 움직임은 없다 (장전 화살만 표시).
