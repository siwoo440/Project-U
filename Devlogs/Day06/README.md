# 프로젝트 U 6일차 개발 일지

---

## 개발 목표

월드의 아이템을 획득하여 보관할 수 있는 기본 인벤토리 시스템을 구현하고, 핫바와 전체 인벤토리 UI를 추가했다.

---

## 구현 내용

- `ItemData` 기반 아이템 데이터 구조 구현
- 인벤토리 슬롯 및 최대 중첩 처리 구현
- 전체 인벤토리 용량을 24칸으로 설정
- 월드 아이템 상호작용 및 획득 기능 구현
- 나무와 돌 테스트 아이템 추가
- 인벤토리 가득 참 처리 구현
- 화면 하단에 8칸 핫바 추가
- 전체 인벤토리의 1~8번 슬롯과 핫바 연동
- 숫자키 `1~8`과 숫자패드를 이용한 핫바 선택 구현
- 선택된 핫바 슬롯의 테두리 표시
- `I` 키를 이용한 전체 인벤토리 팝업 구현
- 팝업에 전체 인벤토리 24칸 표시
- 팝업이 열렸을 때 이동·카메라·상호작용 정지
- 팝업을 닫았을 때 기존 조작 상태 복구
- 아이템 획득 시 핫바와 인벤토리 UI 자동 갱신
- 동일 아이템의 최대 중첩 초과 시 새 슬롯 생성 확인

---

## 테스트 결과

- 나무와 돌 아이템 정상 획득
- 획득한 아이템의 수량 정상 표시
- 동일 아이템 최대 20개 중첩 확인
- 최대 중첩 초과 시 다음 슬롯 사용 확인
- 인벤토리가 가득 찬 경우 아이템이 제거되지 않는 것 확인
- 숫자키 `1~8` 핫바 선택 확인
- `I` 키 인벤토리 열기·닫기 확인
- 인벤토리 팝업 중 플레이어 조작 차단 확인
- 팝업 종료 후 플레이어 조작 복구 확인
- 핫바와 전체 인벤토리의 데이터 공유 확인
- Console Error 0개 확인

## 현재 제한 사항

- 인벤토리 데이터는 Scene을 다시 불러오면 초기화됨
- 선택한 아이템의 사용 및 장착 기능 미구현
- 슬롯 간 아이템 이동 기능 미구현
- 아이템 버리기 및 분할 기능 미구현
- 아이템 아이콘 표시 미구현
