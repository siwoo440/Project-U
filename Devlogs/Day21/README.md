# Project U 개발 일지

## 21일차 : 장비 착용·교체·해제 시스템 구현

### 개발 목표

인벤토리에서 장비 아이템을 선택해 지정된 장비 슬롯에 착용하고, 같은 부위의 장비를 교체하거나 슬롯을 눌러 해제할 수 있는 기본 장비 시스템을 구현했다.

### 구현 내용

- `PlayerEquipment`를 추가해 플레이어가 착용 중인 장비를 관리하도록 구성
- 머리, 몸, 다리, 신발, 가방 장비 슬롯 추가
- `ItemData`에 장비 분류와 착용 부위 정보 추가
- 인벤토리 상세 정보 UI에 `EQUIP` 버튼 추가
- 장비 아이템을 선택했을 때만 `EQUIP` 버튼 활성화
- 장착 시 인벤토리에서 아이템을 제거하고 지정된 슬롯에 표시
- 같은 부위의 장비 착용 시 기존 장비를 인벤토리로 반환하고 새 장비로 교체
- 장비 슬롯 클릭을 통한 장비 해제 기능 구현
- 인벤토리가 가득 찬 경우 장비 해제를 차단해 아이템 소실 방지
- 장비 아이콘과 이름이 장착 상태에 맞게 즉시 갱신되도록 처리
- 테스트용 모자 2종과 셔츠 1종의 아이템 데이터 및 획득 프리팹 추가

### 오류 수정

- `InventoryDetailUI`에 누락된 `PlayerEquipment`와 `EquipButton` 참조 추가
- `EQUIP` 버튼 클릭 시 `TryEquipFromInventory()`가 호출되도록 이벤트 연결
- 버튼 이벤트가 중복으로 남지 않도록 `OnDestroy()` 정리 처리 추가
- 모든 장비 슬롯이 공용 `EquipButton`을 해제 버튼으로 참조하던 연결 오류 수정
- 각 `EquipmentSlotUI`가 자기 오브젝트의 `Button`을 해제 버튼으로 사용하도록 변경
- `ItemData_ClothShirt`의 착용 부위를 `Body`로 지정
- 장비가 아니거나 착용 부위가 지정되지 않은 아이템의 장착 버튼 비활성화

### 테스트 내용

- `CLOTH CAP`의 머리 슬롯 장착 확인
- `WORK HAT` 장착 시 기존 모자가 인벤토리로 반환되는지 확인
- `CLOTH SHIRT`가 몸 슬롯에만 장착되는지 확인
- 머리와 몸 장비를 동시에 착용할 수 있는지 확인
- 장비 슬롯 클릭 시 해당 장비가 인벤토리로 돌아오는지 확인
- 빈 장비 슬롯 클릭 시 오류가 발생하지 않는지 확인
- 일반 아이템 선택 시 `EQUIP` 버튼이 비활성화되는지 확인
- 인벤토리가 가득 찬 상태에서 장비 해제가 차단되는지 확인
- 장착·교체·해제 과정에서 아이템 복제나 소실이 없는지 확인
- 기존 인벤토리, 핫바, 아이템 획득·버리기 기능이 유지되는지 확인
- Scene 재시작 후 장비 상태가 정상적으로 초기화되는지 확인

### 완료 결과

플레이어가 인벤토리에서 장비를 선택해 부위별 슬롯에 착용할 수 있으며, 동일 부위 장비 교체와 슬롯 클릭 해제가 가능해졌다. 인벤토리 공간 부족 상황에서도 장비가 사라지지 않도록 보호 처리를 적용했고, 기존 인벤토리 기능과 장비 UI가 함께 정상 작동하도록 연결을 정리했다.
