# 프로젝트 U 7일차 개발 일지

## 개발 목표

고정 슬롯 인벤토리와 핫바를 연동하고, 마우스 클릭과 드래그를 이용해 아이템 위치를 관리할 수 있는 기능을 구현했다.

## 구현 내용

- 24칸 고정 슬롯 인벤토리 구현
- 첫 8칸을 핫바 영역으로 사용
- 나머지 16칸을 일반 인벤토리 영역으로 분리
- 인벤토리 슬롯 클릭 선택 기능 구현
- 선택한 슬롯에 노란색 아웃라인 표시
- 빈 슬롯 이동, 다른 아이템 교환, 같은 아이템 중첩 구현
- 인벤토리와 화면 하단 핫바의 아이템 위치 동기화
- 핫바와 일반 인벤토리 사이의 양방향 아이템 이동 구현
- Alt 입력 중 마우스 커서 활성화
- Alt 입력 중 화면 하단 핫바 드래그 기능 구현
- UI의 `Raycast Target` 설정 수정
- 인벤토리 사용 슬롯 수와 아이템 목록 표시 개선

## 테스트 내용

- 슬롯 클릭과 선택 아웃라인 표시 확인
- 인벤토리 내부 아이템 이동 및 교환 확인
- 같은 아이템의 최대 수량 중첩 확인
- 핫바와 일반 인벤토리 간 이동 확인
- 두 핫바 UI의 실시간 동기화 확인
- Alt 입력 중 커서 및 핫바 조작 확인
- 빈 슬롯과 UI 외부 드롭 처리 확인

## GitHub 명령어

기존 `7일차 : 임시` 커밋을 현재 내용으로 덮어쓴다.

```bash
git add .
git commit --amend -m "7일차 : 인벤토리 드래그와 핫바 연동 구현"
git push --force-with-lease origin main
```

`main`이 아닌 다른 브랜치에서 작업했다면 마지막 명령어의 `main`을 현재 브랜치 이름으로 변경한다.
