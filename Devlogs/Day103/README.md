## 3. 2차 NPC 의뢰 · 하트 이벤트

- 의뢰 · 이벤트를 갖추는 NPC를 "1차 7명"에서 **1 · 2차 14명**으로 넓혔다 (`NpcDatabase.GetStoryCast` · `StoryReadyWave = 2`). 3차는 아직 이야기 차수가 아니라 검사에서 빠진다.
- `NpcQuests.csv` 의뢰 28개
  - 게시판 의뢰 21개 : 한 명당 3개, 모든 계절에 하나 이상 (벨라모르타 버섯, 피피 돌 · 광석, 사피라 물 등)
  - 특별 의뢰 7개 : 신뢰 단계 + 신뢰 이벤트 뒤에 열리고 가게 물건을 준다 (벨라모르타 물약 3개, 피피 물뿌리개, 세이라 해독제 3개 등)
  - 게시판 의뢰 보상은 필요 물건을 상점에서 사는 값보다 작게 맞췄다.
- `NpcEvents.csv` 하트 이벤트 21개 (호기심 · 신뢰 · 애정)
  - 장소 · 시간은 일정상 그 NPC가 있는 곳 (예 : 벨라모르타 호기심 = 공방 8~11시)
  - 애정 이벤트는 자기 가게 물건을 선물로 준다 (벨라모르타 물약 · 아라크네 셔츠 · 미루 젤리 · 카스미 유부초밥 · 세이라 해독제 · 피피 고철 부품 · 사피라 연고).

## 5. 87일차 판매 상자 점검 수정 (복사본 점검만)

- 원인 : 점검이 플레이어를 가판대에서 4.6m 떨어진 곳에 두고 상점을 열었다. 92일차부터 상점 주인이 리첼이라, 리첼과 4.5m보다 멀면 창이 바로 닫혀 씨앗을 살 수 없었다. 실제 게임은 1.8m 안에서만 말을 걸 수 있어 문제가 없다 (게임 코드 변경 없음).
- 점검을 리첼 기준 PASS / FAIL로 다시 썼다 : 가판대의 리첼 · 씨앗 3개 사기 · 코인 부족 · 가방 가득 · 재고 초과 · 팔기 탭(판매 상자 값의 80%) · 저장 · 마감 뒤 닫힘 · 다음 날 재고 · 여름 씨앗

## 7. 남은 문제

- 3차 7명은 아직 가게(마리엘) · 제작(알리우네) · 의뢰 · 하트 이벤트가 없다.
- 알리우네 · 루네트처럼 상점 없는 제작 NPC용 제작 창이 없다.
- 섬 NPC가 21명으로 늘었다. 창 없는 점검에서는 문제가 없지만 실제 화면 프레임은 확인이 필요하다.
- 하트 이벤트 선택지가 나올 때 캡처에서는 대사 칸이 비어 보였다 (글자가 한 글자씩 나오는 중). 실제 화면에서 확인이 필요하다.
