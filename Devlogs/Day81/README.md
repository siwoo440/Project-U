# Project U 개발 일지

## 81일차 : 작물 성장·계절·날씨·수확 구현

### 1. 개발 목표

80일차까지 밭을 만들고 씨앗을 심고 물을 줄 수 있었지만, 날짜가 바뀌어도 작물이 자라지 않았다.
81일차에는 농사 콘텐츠(79~81일차)의 마지막 단계인 성장과 수확을 구현하였다.

기획서 81일차 완료 기준:

```text
게임 시간과 물·계절·날씨 조건에 따라 준비한 작물이 단계별 외형으로 성장하고
완료 후 수확 아이템을 지급한다.
```

이번 일차의 핵심 목표는 다음과 같다.

- 날짜가 바뀔 때 물·계절 조건에 따른 작물 성장
- 여러 날을 건너뛸 때와 불러오기 후의 중복 성장 방지
- 폭풍 작물 피해와 시든 외형
- 다 자란 작물 수확, 수확량·씨앗 반환, 인벤토리 초과분 바닥 드롭
- 수확 가능 표시와 수확 알림
- Play 중 성장 확인용 테스트 메뉴
- Camera 줌 보조키를 Ctrl로 변경

---

## 2. 기획서 성장 규칙

| 항목 | 규칙 |
| --- | --- |
| 성장 일수 | 작물마다 다름 (감자 3일, 딸기 5일, 토마토 6일, 호박 7일, 겨울무 4일) |
| 성장 조건 | 물을 받은 날만 성장 |
| 비·폭풍 | 물 주기 생략 |
| 계절 | 특정 계절에만 성장 |
| 폭풍 | 낮은 확률로 작물 피해 |
| 수확량 | 최소~최대 사이 랜덤 |

## 3. 하루 성장 처리

```text
날짜 변경 (FarmManager.LateUpdate)
→ ProcessGrowth(오늘)
→ 각 FarmPlot.ProcessDays
   for 날짜 = lastGrowthDay ~ 오늘 - 1
      그날 물을 받았는가?  (lastWateredDay == 날짜)
      그날 계절이 맞는가?  (GetSeasonForDay)
      → 둘 다 맞으면 grownDays + 1
      → 성장 일수 도달 시 Ready
   lastGrowthDay = 오늘
```

| 결정 | 이유 |
| --- | --- |
| 날짜별 순회 | 수면 등으로 여러 날을 건너뛰어도 순서대로 계산 |
| `lastGrowthDay` 기록 | 저장·불러오기나 날짜 이벤트가 겹쳐도 같은 날을 두 번 계산하지 않음 |
| 물 기록은 마지막 날 하나 | 건너뛴 여러 날 중 물 받은 하루만 성장으로 인정 |
| `GetSeasonForDay` | `SeasonCycle`과 같은 규칙(28일 단위, 봄→여름→가을→겨울)으로 과거 날짜의 계절 계산 |

성장 단계 외형은 누적 성장 일수에 따라 바뀐다.

```text
감자 : 0일 흙더미 → 1일 새싹 → 2일 성장 → 3일 완성(수확 가능)
```

## 4. 폭풍 피해

| 항목 | 내용 |
| --- | --- |
| 판정 시점 | 최종 날씨가 폭풍일 때 |
| 판정 횟수 | 밭마다 하루 한 번 (`lastStormCheckDay`) |
| 확률 | 작물 데이터 `StormDamageChance` (호박 5%, 감자·딸기·겨울무 10%, 토마토 15%) |
| 결과 | `Withered` 상태, 갈색으로 처진 외형 |
| 정리 | 괭이를 들고 F → `F - CLEAR WITHERED STRAWBERRY` |

---

## 5. 수확

| 항목 | 내용 |
| --- | --- |
| 조건 | `Ready` 상태에서 F (손에 든 아이템과 관계없이 수확 우선) |
| 수확량 | `CropData.RollHarvestAmount` (최소~최대) |
| 씨앗 반환 | 30% 확률로 씨앗 1개 |
| 인벤토리 초과 | `WorldItemPickupRegistry`의 Pickup으로 밭 옆에 떨어뜨림 (`WorldItemDropContainer` 아래) |
| 수확 후 | `FarmingRulesData.KeepPlotAfterHarvest`에 따라 빈 밭 유지 |
| 알림 | `+2 POTATO`, `+1 SEED` 떠오르는 글자 |

76일차 `CombatDamagePopup`에 글자를 띄우는 `SpawnText`를 추가하여 피해 숫자 연출을 재사용하였다.

## 6. 수확 가능 표시

- `fx_ready_sparkle` : 황금색으로 빛나는 마름모 모델 (`ReadyGlow` 색상 추가)
- `FarmReadyMarker` : 밭 위에서 위아래로 떠다니며 회전 (밭마다 박자 분산)
- 밭 Prefab의 `ReadyMarker`는 기본 꺼짐이며 `Ready` 상태에서만 켠다.

## 7. 저장

| 변경 | 내용 |
| --- | --- |
| `FarmPlotSaveData.lastStormCheckDay` | 폭풍 판정 날짜 추가 (81일차 이전 파일은 0) |
| `SaveDataValidator` | 성장 처리 날짜·폭풍 판정 날짜 음수 검사 추가 |

불러오기 직후 날짜가 바뀌어도 `lastGrowthDay` 기준으로 처리하므로 중복 성장하지 않는다.

## 9. Camera 줌 보조키 변경

80일차에 휠을 핫바 이동에 사용하면서 Camera 줌을 Shift + 휠로 옮겼던 것을 **Ctrl + 휠**로 변경하였다.

| 입력 | 동작 |
| --- | --- |
| 휠 | 핫바 칸 이동 |
| Ctrl + 휠 | 3인칭 Camera 줌 (좌우 Ctrl) |

> 왼쪽 Ctrl은 회피 키와 같아 줌을 위해 누르는 순간 회피가 발생한다.
> 회피 키 변경 여부는 추후 결정한다. (오른쪽 Ctrl은 충돌 없음)

## 12. 정리

81일차에는 작물이 물·계절·날씨 조건에 따라 날짜별로 자라고,
다 자란 작물을 수확해 아이템을 얻는 농사 전체 흐름을 완성하였다.

```text
괭이로 밭 만들기 → 씨앗 심기 → 물 주기 → 날짜 경과·성장 → 수확 → 요리·판매 재료
```

82일차부터는 낚시 콘텐츠를 시작한다.
